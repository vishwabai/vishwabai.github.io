Neural Network Internals

Why activation functions unlock real intelligence

A single neuron is just a weighted sum — linear, boring, limited. Activation functions are what give networks the power to learn curves, spirals, and any pattern in between.

Section 01

What happens without an activation function?

Stack 100 linear neurons — you still just get a line. No matter how deep you go, a network with no activations collapses to a single linear equation. Watch it try to learn a curve.

Linear-only network vs real data
The collapse proof
Layer 1: a¹ = W¹x + b¹
Layer 2: a² = W²a¹ + b²

Substitute:
a² = W²(W¹x + b¹) + b²
   = (W²W¹)x + (W²b¹+b²)

= W_eff · x + b_eff // ONE layer
100 linear layers = exactly 1 linear layer. The network can only draw a straight line through your data, no matter how many neurons you add.
What you see above

The blue dots form a sine wave. The red line is the network's best attempt — it can only fit a straight line. No matter how long you train, it will never capture the curve. This is the fundamental limitation activations solve.

The data is y = sin(x). A linear network predicts y = ax + b. These are different function families — no amount of training closes the gap.
