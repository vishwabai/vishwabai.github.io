Linear Algebra

Every neural network is a chain of matrix multiplications. Understanding vectors, matrices, and decompositions is non-negotiable for ML.

Vectors & Dot Product

a · b = Σ aᵢbᵢ = |a||b|cos(θ) ← scalar; measures alignment ‖a‖ = √(a₁²+a₂²+…) ← L2 norm (Euclidean length) ‖a‖₁ = Σ|aᵢ| ← L1 norm (Manhattan; used in LASSO)

Matrix Multiplication

C = A·B where Cᵢⱼ = Σₖ Aᵢₖ·Bₖⱼ Shapes: (m×n)·(n×p) → (m×p) A linear layer: y = W·x + b where W ∈ ℝ^(d_out × d_in)

Eigenvalues & Eigenvectors

Av = λv ← v is unchanged in direction; only scaled by λ det(A − λI) = 0 ← characteristic equation; solve for eigenvalues

Eigendecomposition is behind PCA (principal directions = eigenvectors of the covariance matrix), spectral graph networks, and understanding what attention heads are actually doing.

SVD — Singular Value Decomposition

A = U · Σ · Vᵀ U: left singular vectors (column space) Σ: diagonal matrix of singular values σ₁ ≥ σ₂ ≥ … ≥ 0 V: right singular vectors (row space)

SVD is the engine of low-rank approximation (keep top-k singular values for compression), LoRA fine-tuning (learn a low-rank update ΔW = A·B), and the analysis of embedding spaces.

Important Matrix Properties for ML

TRANSPOSE
(AB)ᵀ = BᵀAᵀ
Used in backprop: gradient flows through transposed weight matrices
INVERSE
(AB)⁻¹ = B⁻¹A⁻¹
Normal equations: θ = (XᵀX)⁻¹Xᵀy — closed-form least squares
TRACE
tr(A) = Σ Aᵢᵢ = Σ λᵢ
Appears in Hutchinson's trace estimator for efficient gradient norms
DETERMINANT
det(A) = Π λᵢ
Volume scaling factor; det=0 means singular (not invertible)
RANK
rank(A) = # nonzero σᵢ
LoRA exploits low effective rank of weight updates
FROBENIUS NORM
‖A‖_F = √(Σᵢⱼ Aᵢⱼ²) = √(Σ σᵢ²)
Weight decay (L2 regularization) penalizes this
Chapter 02

Calculus & Derivatives

Backpropagation is applied chain rule. Every weight update is a gradient — a vector of partial derivatives telling us how the loss changes with each parameter.

Derivative Essentials

d/dx[xⁿ] = nxⁿ⁻¹ d/dx[eˣ] = eˣ d/dx[ln x] = 1/x d/dx[sin x] = cos x Chain rule: d/dx[f(g(x))] = f'(g(x))·g'(x) Product rule: d/dx[fg] = f'g + fg'

Gradient (multivariate derivative)

∇f(x) = [∂f/∂x₁, ∂f/∂x₂, …, ∂f/∂xₙ]ᵀ ← direction of steepest ascent Jacobian Jᵢⱼ = ∂fᵢ/∂xⱼ ← matrix of all partial derivatives Hessian Hᵢⱼ = ∂²f/∂xᵢ∂xⱼ ← matrix of second derivatives

Chapter 03

Probability Theory

ML is fundamentally probabilistic reasoning under uncertainty. Loss functions, generative models, and Bayesian methods all live here.

Core Rules

Sum rule: P(A) = Σᵦ P(A,B) ← marginalisation Product rule: P(A,B) = P(A|B)·P(B) ← joint = conditional × marginal Bayes' theorem: P(θ|D) = P(D|θ)·P(θ) / P(D) ← posterior ∝ likelihood × prior

Key Distributions

GAUSSIAN / NORMAL
p(x) = (1/√(2πσ²))·exp(−(x−μ)²/2σ²)
Default prior; CLT; noise model; VAE latent space
BERNOULLI
P(x) = pˣ(1−p)^(1−x), x∈{0,1}
Binary classification; sigmoid output models this
CATEGORICAL
P(x=k) = pₖ, Σpₖ=1
Multi-class classification; softmax outputs this
DIRICHLET
p(π|α) ∝ Πᵢ πᵢ^(αᵢ−1)
Prior over categorical distributions; LDA topic models
LAPLACE
p(x) = (1/2b)exp(−|x−μ|/b)
Prior implies L1/LASSO regularization; sparse solutions
BETA
p(x|α,β) ∝ x^(α−1)(1−x)^(β−1)
Conjugate prior for Bernoulli; Bayesian A/B testing

Chapter 04

Statistics for ML

Maximum Likelihood Estimation (MLE)

θ_MLE = argmax_θ log P(D|θ) = argmax_θ Σᵢ log p(xᵢ|θ) For Gaussian: MLE gives μ̂=sample mean, σ̂²=sample variance Cross-entropy loss = negative log-likelihood of the correct class

Bias–Variance Tradeoff

E[(ŷ−y)²] = Bias²[ŷ] + Variance[ŷ] + Irreducible noise Bias: error from wrong assumptions (underfitting) Variance: sensitivity to training data (overfitting) Regularization trades variance for bias

Regularization

L2 (Ridge / weight decay): L = L₀ + λ‖w‖² → shrinks weights uniformly L1 (LASSO): L = L₀ + λ‖w‖₁ → produces sparsity (zero weights) Elastic Net: L = L₀ + λ₁‖w‖₁ + λ₂‖w‖² Dropout: randomly zeros activations; equivalent to ensemble

Central Limit Theorem

As sample size n→∞, the distribution of the sample mean approaches Normal(μ, σ²/n) — regardless of the original distribution. This justifies Gaussian noise assumptions and confidence intervals used in model evaluation.

Chapter 05

Optimization

Training a neural network is solving a high-dimensional, non-convex minimization problem. Every optimizer is a different strategy for descending a loss landscape.

Gradient Descent Family

SGD: w ← w − η·∇L(w) Momentum: v ← βv − η·∇L; w ← w + v RMSProp: v ← βv + (1−β)·(∇L)²; w ← w − η·∇L/√(v+ε) Adam: m ← β₁m + (1−β₁)·∇L ← first moment (mean) v ← β₂v + (1−β₂)·(∇L)² ← second moment (variance) m̂ = m/(1−β₁ᵗ) ← bias correction v̂ = v/(1−β₂ᵗ) ← bias correction w ← w − η·m̂/(√v̂+ε) ← update; β₁=0.9, β₂=0.999, ε=1e-8

Convexity

f is convex if: f(λx+(1−λ)y) ≤ λf(x)+(1−λ)f(y) for all λ∈[0,1] Convex → any local minimum is global minimum Neural networks are NOT convex — but local minima often generalize well

‖∇f(x)−∇f(y)‖ ≤ L‖x−y‖
Guarantees GD converges with η ≤ 1/L
STRONG CONVEXITY
f(y)≥f(x)+∇f(x)ᵀ(y−x)+μ‖x−y‖²/2

SADDLE POINTS

BATCH SIZE EFFECT
σ²_grad ∝ 1/B
Large batch → sharp minima; small batch → flat minima (better generalization)
Chapter 06

Information Theory

Information theory gives us a principled language for uncertainty, compression, and learning. Shannon entropy is the backbone of every loss function in classification.

Entropy & Cross-Entropy

Shannon entropy: H(P) = −Σᵢ P(i) log₂ P(i) ← bits; max when uniform Cross-entropy: H(P,Q) = −Σᵢ P(i) log Q(i) ← classification loss KL divergence: D_KL(P‖Q) = Σᵢ P(i) log(P(i)/Q(i)) = H(P,Q)−H(P) Mutual information: I(X;Y) = H(X)−H(X|Y) = D_KL(P(X,Y)‖P(X)P(Y))

Cross-entropy loss IS the negative log-likelihood of the correct class. KL divergence measures how much information is lost when Q approximates P.

KL Divergence in ML

VAE (ELBO)
L = E[log p(x|z)] − D_KL(q(z|x)‖p(z))
Forces latent space toward Gaussian prior; enables generation
RLHF / PPO
L += −β·D_KL(π_θ‖π_ref)
Keeps fine-tuned model close to reference; prevents reward hacking
KNOWLEDGE DISTIL.
L = α·H(y,p_s) + (1−α)·D_KL(p_t‖p_s)
Student learns from teacher's soft probability distributions
DIFFUSION MODELS
L = Σ D_KL(q(x_t|x_{t-1})‖p_θ)
Each denoising step minimises KL between forward/reverse processes

Mutual Information & Self-Supervised Learning

I(X;Y) = H(X) − H(X|Y) ← how much knowing Y reduces uncertainty about X Contrastive learning (SimCLR, CLIP) maximises I(view₁; view₂) InfoNCE loss ≈ lower bound on mutual information (van den Oord 2018)
Chapter 07

Graph Mathematics

Graph Neural Networks (GNNs) like GCN, GAT, and GraphSAGE rely on spectral graph theory and matrix representations of graphs.

Graph Representations

Adjacency matrix A: Aᵢⱼ = 1 if edge (i,j) exists Degree matrix D: Dᵢᵢ = Σⱼ Aᵢⱼ (diagonal) Laplacian L: L = D − A ← captures graph structure Norm. Laplacian: L̃ = D⁻¹ᐟ²·L·D⁻¹ᐟ² ← eigenvalues ∈ [0,2]

GCN Layer (Kipf & Welling, 2017)

H⁽ˡ⁺¹⁾ = σ(D̃⁻¹ᐟ²·Ã·D̃⁻¹ᐟ²·H⁽ˡ⁾·W⁽ˡ⁾) Ã = A + I (self-loops added) D̃ᵢᵢ = Σⱼ Ãᵢⱼ (degree with self-loops) Each layer aggregates 1-hop neighbourhood features

Graph Attention (GAT)

eᵢⱼ = a([W·hᵢ ‖ W·hⱼ]) ← attention coefficient αᵢⱼ = softmax_j(LeakyReLU(eᵢⱼ)) h'ᵢ = σ(Σⱼ αᵢⱼ·W·hⱼ) ← weighted neighbourhood aggregation

Random Walks & PageRank

PageRank: r = d·A·D⁻¹·r + (1−d)/N·1 Solved as principal eigenvector of the transition matrix Node2Vec / DeepWalk: random walks → skip-gram → node embeddings
Chapter 08

Numerical Methods & Stability

Theory is one thing; making algorithms run stably in float32 on real hardware is another. These techniques prevent the silent disasters (NaN, exploding gradients) that kill training runs.

Log-Sum-Exp Trick

log Σᵢ exp(xᵢ) = c + log Σᵢ exp(xᵢ−c) where c = max(xᵢ) Prevents overflow in softmax; used in all deep learning frameworks softmax_stable(x) = exp(x−max(x)) / Σ exp(xᵢ−max(x))

Gradient Clipping

if ‖g‖ > threshold: g ← g · threshold/‖g‖ Prevents exploding gradients in RNNs and transformers PyTorch: torch.nn.utils.clip_grad_norm_(params, max_norm=1.0)

Numerical Differentiation

Forward diff: f'(x) ≈ (f(x+h)−f(x))/h O(h) error Central diff: f'(x) ≈ (f(x+h)−f(x−h))/(2h) O(h²) error ← prefer this Used in gradient checking to verify backprop implementations
