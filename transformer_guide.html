What is a token?

Before anything else — text must become numbers. Tokens are the atoms of language for AI.

Click a word to see how it gets tokenized
Common words stay whole. Rare or long words get sliced into sub-pieces. Each piece gets a unique integer ID.
characters
"cat"=3 units. "unbelievable"=12 units. Sequences get very long. Context fills up fast.
subwords ✓ used by GPT-4
"unbelievable"=["un","believ","able"]=3 tokens. Sweet spot of vocab size and length.
whole words
Needs 500K+ vocab. Unknown words fail. Can't handle typos or new names.
So what? GPT-4 uses 100K tokens. "strawberry" = ["straw","berry"] — that's why it can't count letters in it. The model never sees individual characters, only token chunks.

Embeddings — giving words meaning as vectors

Each token ID maps to a list of numbers. That list encodes meaning. Similar words end up near each other.

Click a word to see its 4 dimensions (simplified)
Real models use thousands of dimensions. These 4 give the intuition.
The famous analogy: king − man + woman ≈ queen
These relationships emerge automatically from training on text. Nobody programmed them in. Meaning = geometry in high-dimensional space.
So what? The model never "understands" words as humans do. It learns that certain number patterns co-occur. Similar meanings = nearby vectors.

Attention — every word looks at every other word

The core idea: every word simultaneously "votes" on which other words matter most to it.

Attention as a party — click a word to see who it's listening to
Each word is a person. The thicker the connection, the more attention.
Click any word to see its attention pattern.
Q — query
What am I looking for?

So what? Every token influences every other token in one step. The model learns which words to pay attention to purely from training data.

Multi-head attention — 8 experts in parallel

Instead of one attention computation, run 8 in parallel. Each head learns a different type of relationship.

Multi-head as a prism — one signal split into specialist beams
Hover any beam to see what that head specialises in.
why multiple heads?
A sentence has syntax, semantics, coreference, subject-verb links — all simultaneously. One head can only learn one pattern well.
how they combine
Concat all head outputs → multiply by W_O. Each head contributes its speciality to the final representation.
So what? Nobody tells each head what to learn. They self-organise during training. Research (2022) shows 70% of heads can be pruned with <1% quality loss — the remaining 30% are critical.

Residual connections — making 96-layer networks trainable

Add the input to the output of every layer. This one idea lets you train very deep networks.

Residual stream as a river with a bypass canal
The main river (gradient) gets blocked by each layer. The bypass canal always stays open — gradient always flows.
Dam blockage: 80%
So what? Without residuals, gradient shrinks by ~0.7× per layer. After 96 layers: 0.7^96 ≈ 0.000000003. Effectively zero. With residuals: gradient = 1 + local_gradient. Always strong. All layers train simultaneously.

Layer normalisation — keeping numbers stable across 96 layers

Without normalisation, values explode or vanish after a few layers. Click through the 3 wash cycles.

LayerNorm as a washing machine
Dirty values come in — all different sizes. Three steps later: everything centered at zero with consistent spread.

Feed-forward network — where facts are stored

After attention mixes tokens, each token passes through a small neural network. This is where world knowledge lives.

FFN as a jukebox — input pattern selects a memory record
W1 rows are tone arms — each listens for a pattern. When it fires, W2 column plays its song (outputs the associated fact).
So what? The FFN makes up ~2/3 of all transformer parameters. Research (Geva et al. 2021) showed W1 rows = keys, W2 columns = values. Model editing targets specific W1/W2 weight pairs to update facts without retraining.

KV cache — why inference is fast

Store past tokens' Keys and Values so you never recompute them. Each new token only needs one forward pass.

KV cache as a library
Past books stay shelved. Only the new word needs a new book computed. Press generate to watch tokens get cached.
2024 innovations: PagedAttention (vLLM) eliminates memory fragmentation — 3-24× throughput. KV cache quantization (INT4) halves memory. Prefix caching hits 40-90% cache rates in production APIs.

Scaling laws — why bigger models keep winning

Loss decreases predictably as you increase parameters, data, or compute — following a power law.

Scaling laws as a rocket launch
More compute = higher orbit = lower loss = smarter model. Drag to explore where your model would sit.
your compute:
Chinchilla (2022)
Optimal: 20 tokens per parameter. GPT-3 (175B, 300B tokens) was massively undertrained. 70B trained on 1.4T tokens outperformed it.
2024 update
Llama 3 8B trained on 15T tokens (1875×!). Why? Inference efficiency — a smaller overtrained model costs less to run in production.
