Chapter 01

Combinatorics & Counting

Counting is the bedrock of complexity analysis, attention masking, tokenization, and the design of efficient data structures for ML pipelines.

Fundamental Counting

Permutations:  P(n,k) = n!/(n−k)!        ← ordered selection of k from n
Combinations:  C(n,k) = n!/(k!(n−k)!)    ← unordered; "n choose k"
Multinomial:   n!/(k₁!k₂!…kₘ!)           ← distribute n into m groups
Stirling 2nd:  S(n,k) = k-partition of n-set   ← cluster assignments

Pascal's identity: C(n,k) = C(n−1,k−1) + C(n−1,k)
Binomial theorem: (x+y)ⁿ = Σₖ C(n,k) xᵏ yⁿ⁻ᵏ

Counting in ML

VOCABULARY SIZE
C(|vocab|, context)
Number of distinct n-grams; motivates subword tokenization — BPE merges C(V,2) candidate pairs per iteration
ATTENTION MASK
C(n,2) = n(n−1)/2
Causal mask zeros out exactly this many upper-triangle entries in the n×n attention matrix
DATA AUGMENTATION
P(n,k) combinations
Number of distinct augmented samples from k transforms applied in order to n base images
BEAM SEARCH
O(|V|^T · B)
Beam search explores B×|V| expansions per step over T steps; combinatorial explosion motivates pruning strategies

Generating Functions

Ordinary GF:  F(x) = Σₙ aₙxⁿ   ← encode sequence {aₙ} as coefficients
Exponential GF: F(x) = Σₙ aₙxⁿ/n!
Convolution of GFs → counting paths; used in dynamic programming proofs
e.g. # ways to tile 1×n board with 1×1 and 1×2 tiles → F(x) = 1/(1−x−x²) → Fibonacci

Pigeonhole & Birthday Problem

Pigeonhole:  n+1 items into n bins → ≥1 bin has ≥2 items
Birthday:   P(collision in k draws from n) ≈ 1 − e^(−k²/2n)
Hash collisions in embedding lookup tables
Approximate Nearest Neighbour (ANN) — collision probability in LSH
LSH collision prob: P(h(x)=h(y)) = 1 − θ(x,y)/π   ← for angular hashing

Entropy from Combinatorics

Boltzmann: S = k_B · log W   ← W = # microstates (multinomial coefficient)
Shannon: H = log C(n; n·p₁,…,n·pₖ)/n ≈ −Σ pᵢ log pᵢ   ← large n limit

Game Theory

GANs, RLHF, multi-agent systems, and mechanism design are all game-theoretic problems. Nash equilibria define what "trained" means in adversarial settings.

Normal Form Games

Game G = (N, {Sᵢ}, {uᵢ})
  N = set of players
  Sᵢ = strategy set for player i
  uᵢ: S₁×…×Sₙ → ℝ = payoff function

Nash Equilibrium: s* such that for all i:
  uᵢ(sᵢ*, s₋ᵢ*) ≥ uᵢ(sᵢ, s₋ᵢ*) for all sᵢ ∈ Sᵢ
← no player benefits from unilateral deviation
Every finite game has ≥1 Nash Equilibrium (Nash 1950, fixed-point theorem)

GAN as a Zero-Sum Game

min_G max_D  V(D,G) = E_{x~p_data}[log D(x)] + E_{z~p_z}[log(1−D(G(z)))]
← Generator minimises; Discriminator maximises
Nash eq: G(z) ~ p_data, D(x) = 1/2 everywhere
In practice: non-saturating loss  max_G E[log D(G(z))]  avoids vanishing gradients
Wasserstein GAN: replaces JS divergence → Lipschitz-constrained critic

Extensive Form & RLHF

Sequential game tree: nodes = states, edges = actions
Subgame Perfect Equilibrium (SPE): Nash in every subgame
← RLHF PPO optimises for SPE in the human-AI interaction game

Mechanism Design (inverse game theory): design rules so agents' self-interest
aligns with the desired outcome. Used in:
  - Auction mechanisms for ad placement (Vickrey-Clarke-Groves)
  - RLHF reward modelling as mechanism for human preferences
  - Cooperative AI alignment

Multi-Agent RL Math

Stochastic game: (N, S, {Aᵢ}, T, {rᵢ})
  T(s'|s,a₁,…,aₙ): transition; rᵢ(s,a,s'): reward for agent i

Correlated Equilibrium:  E[uᵢ(σ)] ≥ E[uᵢ(δᵢ∘σ)]  for all deviations δᵢ
← weaker than Nash; easier to learn via regret minimisation
Regret:  R_T = max_a Σₜ r(a,·) − Σₜ r(aₜ,·)
No-regret algorithms (EXP3, hedge): R_T/T → 0; converge to correlated eq.

Bandit Problems

K-armed bandit: choose arm aₜ ∈ {1…K}, receive reward rₜ ~ p(·|aₜ)
Regret: R_T = T·μ* − Σₜ μ(aₜ)   ← gap from optimal arm
UCB1:   aₜ = argmax_a [μ̂_a + √(2ln(t)/nₐ)]
← optimism in the face of uncertainty; R_T = O(√(KT ln T))
Thompson Sampling: sample θₐ ~ Beta(αₐ,βₐ); pick argmax_a θₐ
← Bayesian; empirically optimal; regret O(√(KT ln K))
Contextual bandits → policy gradient; LinUCB → linear reward models
Chapter 03

Functional Analysis

Neural networks are functions mapping functions. Functional analysis provides the rigorous language for Hilbert spaces (kernel methods), operator theory (attention as operators), and universal approximation theorems.

Normed Spaces & Completeness

Normed space:  (V, ‖·‖) — vector space with a norm
Banach space:  complete normed space (every Cauchy seq converges)
Hilbert space: complete inner product space  ⟨·,·⟩
  ‖f‖² = ⟨f,f⟩,  Cauchy-Schwarz: |⟨f,g⟩| ≤ ‖f‖·‖g‖
L²(ℝ): square-integrable functions → Hilbert space → Fourier analysis lives here
ℓ²: square-summable sequences → parameter space of neural networks

Reproducing Kernel Hilbert Spaces (RKHS)

RKHS ℋ_κ with kernel κ(x,y):
  ∀x: f(x) = ⟨f, κ(x,·)⟩_ℋ   ← reproducing property
  κ is PSD: Σᵢⱼ cᵢcⱼ κ(xᵢ,xⱼ) ≥ 0  for all {cᵢ}, {xᵢ}
Mercer's theorem: κ(x,y) = Σᵢ λᵢ φᵢ(x)φᵢ(y)  (if κ is PSD continuous)

Common kernels:
  RBF/Gaussian:  κ(x,y) = exp(−‖x−y‖²/2σ²)
  Polynomial:    κ(x,y) = (xᵀy + c)^d
  Neural tangent: κ(x,y) = E_{W}[⟨∇_W f(x),∇_W f(y)⟩]  ← infinite-width NN

Neural Tangent Kernel (NTK)

As width → ∞, training dynamics of a neural net become linear:
  f(x,θ) ≈ f(x,θ₀) + ⟨∇_θ f(x,θ₀), θ−θ₀⟩
  Kernel: Θ(x,x') = ⟨∇_θ f(x), ∇_θ f(x')⟩
At infinite width: Θ stays constant during training → exact solution:
  f(x,∞) = κ(x,X)[κ(X,X)+λI]⁻¹ y   ← kernel regression!
Explains: lazy training regime, generalisation, feature learning limitations

Operators & Spectral Theory

Linear operator T: ℋ₁ → ℋ₂;  ‖T‖ = sup_{‖x‖=1} ‖Tx‖
Compact operator: maps bounded sets to precompact sets
Attention head = linear operator on the sequence space
Spectral radius: ρ(A) = max|λᵢ| → controls gradient norms in recurrent nets
Singular value decomp: T = UΣVᵀ (for compact operators, countably many σᵢ)
Hilbert-Schmidt norm: ‖T‖_HS = √(Σᵢ σᵢ²) = √(tr(TᵀT))

Universal Approximation Theorems

Cybenko (1989):  Single hidden layer + sigmoid can approximate any
  continuous f: [0,1]^n → ℝ to arbitrary precision.
Barron (1993):   Functions with bounded Fourier spectrum can be approximated
  with O(1/n) L² error using n neurons — no curse of dimensionality.
Depth separation: Some functions need exponential width if shallow
  but polynomial width if deep. Depth buys exponential expressivity.
Transformer UAT: Transformers are Turing-complete (Pérez 2019);
  2-layer transformers approximate any sequence-to-sequence function.

Markov Chains & Reinforcement Learning Math

RL is sequential decision-making under uncertainty. The math: Markov Decision Processes, Bellman equations, and policy gradient theorems.

Markov Chains

Markov property: P(Sₜ₊₁|S₀,…,Sₜ) = P(Sₜ₊₁|Sₜ)
Transition matrix P: Pᵢⱼ = P(Sₜ₊₁=j|Sₜ=i), row-stochastic
Stationary distribution: π = πP,  Σᵢ πᵢ = 1
Ergodic chain: irreducible + aperiodic → unique stationary π
Mixing time: τ_ε = min{t: ‖P^t(x,·)−π‖_TV ≤ ε}
Fast mixing → good replay buffer coverage in RL
Spectral gap: 1−|λ₂(P)| controls mixing time

MDP & Bellman Equations

MDP = (S, A, P, R, γ)
  S: state space   A: action space   γ: discount factor ∈ [0,1)
  P(s'|s,a): transition   R(s,a): expected reward

Value function:  V^π(s) = E_π[Σₜ γᵗ Rₜ | S₀=s]
Q-function:     Q^π(s,a) = E_π[Σₜ γᵗ Rₜ | S₀=s, A₀=a]

Bellman Expectation:
  V^π(s) = Σₐ π(a|s)[R(s,a) + γ Σₛ' P(s'|s,a) V^π(s')]

Bellman Optimality:
  V*(s) = max_a [R(s,a) + γ Σₛ' P(s'|s,a) V*(s')]
  Q*(s,a) = R(s,a) + γ Σₛ' P(s'|s,a) max_a' Q*(s',a')

Policy Gradient Theorem

∇_θ J(θ) = E_{τ~π_θ}[Σₜ ∇_θ log π_θ(aₜ|sₜ) · Qᵗ]
← gradient of expected return w.r.t. policy parameters

REINFORCE:  Qᵗ = Gₜ = Σₖ γᵏ Rₜ₊ₖ   ← Monte Carlo return
Actor-Critic: Qᵗ = Q_w(sₜ,aₜ)   ← learned critic reduces variance
Advantage:  Aᵗ = Q(s,a) − V(s)   ← baseline; zero-mean; lower variance
GAE-λ:      Â^λ = Σₗ (γλ)ˡ δₜ₊ₗ  where δₜ = rₜ+γV(sₜ₊₁)−V(sₜ)

PPO clip:   L = E[min(rₜ(θ)Aₜ, clip(rₜ(θ),1−ε,1+ε)Aₜ)]
  rₜ(θ) = π_θ(a|s)/π_θ_old(a|s)   ← importance sampling ratio

TD Learning & Temporal Difference

TD(0):  V(sₜ) ← V(sₜ) + α[rₜ + γV(sₜ₊₁) − V(sₜ)]
  δₜ = rₜ + γV(sₜ₊₁) − V(sₜ)  ← TD error (prediction error signal)
Q-learning: Q(s,a) ← Q(s,a) + α[r + γ max_a' Q(s',a') − Q(s,a)]
SARSA (on-policy):  uses Q(s',a') with a'~π instead of max
TD(λ):  eligibility traces eₜ = γλeₜ₋₁ + ∇V(sₜ)
         Δw = α·δₜ·eₜ   ← credit assignment across many steps

PAC-Bayes & Generalisation Theory

How do we prove that a trained model will generalise? PAC-Bayes theory gives non-vacuous bounds that actually apply to modern neural networks.

PAC Learning Framework

Goal: with probability ≥ 1−δ, learn h with L(h) ≤ ε (generalisation error)
Sample complexity: n ≥ (1/ε)[ln|H| + ln(1/δ)]  ← finite hypothesis class
VC dimension d: size of largest shattered set
  n ≥ O((d + ln(1/δ))/ε)   ← PAC sample complexity via VC dim
VC(half-spaces in ℝᵈ) = d+1;  VC(depth-k ReLU nets) = O(WL log W)

PAC-Bayes Bound (McAllester 1999)

For any prior P over hypotheses, posterior Q, with prob ≥ 1−δ:
L(Q) ≤ L̂(Q) + √[(D_KL(Q‖P) + ln(n/δ)) / (2n)]
L(Q): expected true risk under Q
L̂(Q): empirical risk under Q
D_KL(Q‖P): how far posterior is from prior
Catoni variant:  L(Q) ≤ (1/(1−e^(−λ/n)))[L̂(Q) + (D_KL(Q‖P) + ln(1/δ))/λ]
Optimise λ for tightest bound; gives non-vacuous bounds on real nets!

Rademacher Complexity

Rademacher complexity: ℛₙ(F) = E_{x,σ}[sup_{f∈F} (1/n) Σᵢ σᵢf(xᵢ)]
  σᵢ ∈ {±1} uniformly random (Rademacher variables)

Measures how well F can fit random labels
Generalisation: L(f) ≤ L̂(f) + 2ℛₙ(F) + √(ln(1/δ)/2n)

For linear classifiers: ℛₙ(F) ≤ Λ·B/√n  ← Λ=weight norm, B=data norm
For neural nets: ℛₙ ≤ O(√(Π‖Wₗ‖_F · L/n))  ← product of layer norms

Double Descent & Modern ML

Classical U-curve: test error = bias² + variance
Modern regime (n < p): test error descends again after interpolation threshold
Interpolation threshold:  p ≈ n  (# params ≈ # samples)
Over-parametrised models implicitly regularised by:
  - SGD noise (finds flat minima)
  - Early stopping  
  - Max-margin implicit bias of gradient descent on separable data
Benign overfitting: perfect train fit + good generalisation in high dimensions
  when data has low-dimensional signal + isotropic high-dim noise

Random Matrix Theory

The weight matrices of neural networks are random matrices — initialised randomly and shaped by SGD. RMT explains initialisation schemes, spectral dynamics, and why deep nets train at all.

Wigner Semicircle Law

Symmetric random matrix W ∈ ℝ^(n×n), Wᵢⱼ ~ N(0,1/n):
Empirical spectral distribution → semicircle as n→∞:
  ρ(λ) = (2/π) √(1−λ²)  for λ ∈ [−1,1]
Bulk of eigenvalues lies in [−2σ, 2σ] where σ² = variance of entries
Largest eigenvalue → 2σ (edge of spectrum)

Marchenko-Pastur Law

Rectangular X ∈ ℝ^(n×p), iid N(0,1/n), ratio β = p/n:
Eigenvalue density of XᵀX → Marchenko-Pastur distribution:
  ρ(λ) = (1/2πβλ) √((λ₊−λ)(λ−λ₋))
  λ± = (1 ± √β)²   ← bulk support edges
Signal eigenvalues outside bulk → detected structure (BBP transition)
Application: explain variance of gradient noise; analyse attention matrices

Weight Initialisation — RMT Derivation

Xavier / Glorot init: W ~ U[−√(6/(nᵢₙ+nₒᵤₜ)), √(6/(nᵢₙ+nₒᵤₜ))]
Derivation: keep Var[output] = Var[input] through each layer
  Var[y] = nᵢₙ · Var[w] · Var[x] = 1  ⟹  Var[w] = 1/nᵢₙ

Kaiming / He init:  W ~ N(0, 2/nᵢₙ)
For ReLU: signal passes through half the neurons on average → factor of 2
  Var[y] = (nᵢₙ/2) · Var[w] · Var[x] = 1  ⟹  Var[w] = 2/nᵢₙ

Spectral norm init: normalise W so ‖W‖₂ = 1  ← stable at initialisation

Free Probability

Free probability = non-commutative probability theory for large random matrices
Free cumulants replace classical cumulants
R-transform: R_{A+B}(z) = R_A(z) + R_B(z)  if A,B are "free"
Predicts spectral distribution of A+B or AB without knowing off-diagonal entries
Application: predict signal propagation through random ReLU networks;
  analyse effective rank of weight matrices during training

Tensor Calculus

Modern deep learning is tensor computation. Understanding index notation, contraction, and tensor decomposition enables architectural innovation and computational efficiency.

Tensors as Multilinear Maps

Tensor T of order (p,q): multilinear map  V*^p × V^q → ℝ
  T^{i₁…iₚ}_{j₁…jq}   ← components in a basis

Einstein summation:  repeated indices are summed
  Cᵢₖ = Aᵢⱼ Bⱼₖ   ← matrix multiply
  tr(A) = Aᵢᵢ      ← trace (contract with δᵢⱼ)
  c = aᵢbᵢ         ← dot product
  Cᵢⱼₖₗ = AᵢⱼBₖₗ   ← outer product
  y = "ij,j->i"(W,x) ← einsum notation used in PyTorch/JAX

Tensor Decompositions

CP (CANDECOMP/PARAFAC):
  T ≈ Σᵣ aᵣ ⊗ bᵣ ⊗ cᵣ   ← sum of rank-1 tensors; minimal r = rank
  Used to compress weight tensors; equivalent to factorised attention

Tucker decomposition:
  T ≈ G ×₁ U₁ ×₂ U₂ ×₃ U₃  ← core tensor + factor matrices
  Each mode projected to lower dim; generalises matrix SVD

Tensor Train (TT / MPS):
  T[i₁,…,iₙ] = G₁[i₁] · G₂[i₂] · … · Gₙ[iₙ]
  Gₖ are 3-order tensors (cores) of bond dimension χ
  Exponential compression: χⁿ → n·χ² parameters
  Used in: TT-decomp of embedding layers; quantum ML (MPS ≡ TT)

Covariant Derivatives & Parallel Transport

Covariant derivative: ∇_v T = ∂T/∂v + Γ * T
← how a tensor changes along a manifold direction v
Parallel transport:  move vector along curve without rotation relative to manifold
Path-dependent on curved spaces → key insight behind geometric deep learning
Application: normalisation layers must respect the geometry of the parameter manifold
  (Riemannian batch norm, SPD manifold layers)

Automatic Differentiation — Forward vs Reverse Mode

Computation graph: nodes = operations, edges = data flow
Forward mode AD:  propagate tangents ẋ = dx/dp from input to output
  Cost: O(n_params) passes for full gradient  ← good for Jacobian-vector products
Reverse mode AD:  propagate adjoints from output backward (backprop)
  Cost: O(1) pass for full gradient           ← optimal for scalar loss
Jvp (forward):  d/dt f(x+tv)|_{t=0}  ← directional derivative
Vjp (reverse):  vᵀ J_f(x)             ← backprop; transpose Jacobian
JAX exposes both: jax.jvp(), jax.vjp(), jax.jacfwd(), jax.jacrev()
Mixed mode:  Hessian = jacfwd(jacrev(f))  ← cost O(n) not O(n²)

Convex Analysis & Duality

While neural networks are not convex, loss functions, constraints, and regularisers often are. Convex duality underpins SVMs, sparse recovery, and theoretical analysis of implicit bias.

Convex Functions & Subdifferentials

f convex ⟺ f(λx+(1−λ)y) ≤ λf(x)+(1−λ)f(y)  ∀λ∈[0,1]
Subdifferential: ∂f(x) = {g : f(y) ≥ f(x) + gᵀ(y−x)  ∀y}
  Generalises gradient to non-smooth functions (ReLU, L1 penalty)
  ∂|x| = {−1} if x<0, [−1,1] if x=0, {1} if x>0
Proximal operator: prox_{λf}(v) = argmin_x {f(x) + (1/2λ)‖x−v‖²}
  prox_{λ‖·‖₁}(v)ᵢ = sign(vᵢ)·max(|vᵢ|−λ, 0)   ← soft thresholding

Fenchel-Legendre Duality

Conjugate function: f*(y) = sup_x {yᵀx − f(x)}
e.g. (½‖x‖²)* = ½‖y‖²  (self-conjugate)
   (‖x‖₁)* = δ_{‖y‖∞≤1}  (indicator of ‖·‖∞ ≤ 1 ball)
Fenchel-Young inequality: f(x) + f*(y) ≥ xᵀy  (equality iff y ∈ ∂f(x))
Biconjugate: f** = conv(f)  ← convex hull / tightest convex lower bound
Application: derive dual SVM, LASSO, and contrastive losses from primal

Lagrangian Duality

Primal:  min_x f(x)  s.t. gᵢ(x) ≤ 0,  hⱼ(x) = 0
Lagrangian: L(x,μ,ν) = f(x) + Σᵢ μᵢgᵢ(x) + Σⱼ νⱼhⱼ(x)
Dual function: d(μ,ν) = inf_x L(x,μ,ν)   ← always concave!
Weak duality:   d* ≤ p*  always
Strong duality:  d* = p*  when Slater's condition holds (strictly feasible)

KKT conditions (necessary + sufficient under convexity + Slater):
  ∇_x L = 0  (stationarity)
  gᵢ(x*) ≤ 0  (primal feasibility)
  μᵢ ≥ 0      (dual feasibility)
  μᵢgᵢ(x*) = 0  (complementary slackness)

Mirror Descent & Bregman Divergences

Bregman divergence: D_φ(x,y) = φ(x) − φ(y) − ⟨∇φ(y), x−y⟩
  φ=½‖·‖²  → squared Euclidean distance
  φ=Σxᵢ log xᵢ  → KL divergence (for probability vectors)
Mirror descent:  xₜ₊₁ = argmin_x {ηₜ⟨∇f(xₜ),x⟩ + D_φ(x,xₜ)}
When φ = negative entropy → multiplicative weights / exponentiated gradient
Natural gradient = mirror descent with φ = KL divergence
Online learning: regret of mirror descent ≤ D_φ(x*,x₁)/η + η·Σ‖∇fₜ‖²
