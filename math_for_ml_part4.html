Large Deviation Theory Rare Events

LDT characterises the probability of events far from the mean — exponentially small. The rate function I(x) describes how unlikely each deviation level is.

-- Cramér's theorem: for iid Xᵢ with MGF M(t) < ∞ P(X̄ₙ ≥ x) ≍ e^(-n·I(x)) as n→∞ I(x) = sup_t { tx - log M(t) } -- rate function -- Legendre-Fenchel transform of log-MGF -- Sanov's theorem: P(empirical dist ≈ Q) ≍ e^(-n · D_KL(Q‖P)) -- KL divergence = rate function for distributions! -- → generalisation error bounded by KL (PAC-Bayes)
Extreme Value Theory Tail Behaviour

EVT studies the distribution of maxima. The GEV distribution describes the limit of normalised maxima — relevant for rare catastrophic events in ML systems.

-- Fisher-Tippett-Gnedenko theorem: P((max Xᵢ - bₙ)/aₙ ≤ x) → GEV(x; μ,σ,ξ) -- Three universality classes: Gumbel (ξ=0): light tails (Normal, Exponential) Fréchet (ξ>0): heavy tails (Pareto, Cauchy) Weibull (ξ<0): bounded tail (Beta, Uniform) -- Pickands-Balkema-de Haan: -- Exceedances above high threshold → GPD
Delta Method — Variance of Transformed StatisticsStatistical Inference

If √n(X̄-μ) → 𝒩(0,σ²), then √n(g(X̄)-g(μ)) → 𝒩(0, [g'(μ)]²σ²). The delta method propagates uncertainty through nonlinear transforms — essential for confidence intervals on model predictions.

PAC-Bayes Bounds Tightest Generalisation

PAC-Bayes combines Bayesian priors with PAC learning to give the tightest known generalisation bounds for neural networks. The bound holds for all posteriors Q simultaneously, with high probability over training data.

-- McAllester's PAC-Bayes bound: E_{h~Q}[R(h)] ≤ E_{h~Q}[R̂(h)] + √( (D_KL(Q‖P) + log(n/δ)) / (2n-1) ) -- Q: posterior (data-dependent), P: prior (data-free) -- Tighter than VC bounds for overparameterised nets! -- Catoni bound (exponential tail): R(Q) ≤ (1-e^-λ)^-1 ( E_Q[R̂] + (D_KL(Q‖P)+log(1/δ))/λn ) -- λ > 0 trade-off parameter -- Flatness ↔ generalisation (sharpness-aware minimisation): -- PAC-Bayes with Gaussian Q around θ: KL(Q‖P) ≈ ‖θ‖²/(2σ²) + sharpness term -- SAM: min max_{‖ε‖≤ρ} L(θ+ε) → flatter minima

Random Matrix Theory

The eigenvalue statistics of large random matrices follow universal laws. These govern the initialisation of neural networks, the spectrum of the Hessian, and the signal-to-noise ratio in high-dimensional regression.

Empirical Spectral Distribution — Marchenko-Pastur LawLive Simulation

The Marchenko-Pastur law describes the limiting eigenvalue distribution of (1/n)XᵀX when X ∈ ℝⁿˣᵖ has iid entries. It depends only on the aspect ratio γ = p/n. Click to regenerate.

n (samples): 200 γ = p/n: 0.5

Wigner's Semicircle Law GOE/GUE

For a symmetric random matrix with iid entries (GOE), the empirical spectral distribution converges to a semicircle as n→∞. This is the universal law for symmetric random matrices.

-- Wigner matrix: W = (X + Xᵀ)/√(2n) -- X: iid entries with mean 0, variance 1 -- Limiting ESD: semicircle on [-2, 2] ρ_sc(x) = √(4-x²) / (2π) |x| ≤ 2 -- Universality: holds for ANY entry distribution -- (with finite variance) -- Tracy-Widom distribution: fluctuations of λ_max -- P((λ_max - 2)/n^(-2/3) ≤ s) → F_TW(s)
Neural Network Initialisation Glorot / He

RMT explains why weight initialisation matters. The singular values of the weight matrix determine signal propagation. Correct scaling keeps activations in a healthy range through depth.

-- Glorot (Xavier) init: Var(W) = 2/(nᵢₙ + nₒᵤₜ) -- Keeps Var(output) ≈ Var(input) for linear nets -- He init (for ReLU): Var(W) = 2/nᵢₙ -- ReLU halves variance → double to compensate -- Free probability (Voiculescu): -- Free convolution of spectral distributions -- S(W₁W₂) = S(W₁) ⊗_free S(W₂) -- Predicts singular value spectrum after composition -- Edge of chaos: signal = noise at depth L -- χ = σ_w²·E[φ'(z)²] = 1 (mean field theory)
Hessian Spectrum & Loss Landscape Bulk + Outliers
-- Hessian at a deep net minimum: H = Σᵢ ∇²lᵢ -- Bulk spectrum: Marchenko-Pastur (noise) -- Outlier eigenvalues: signal (curvature of useful features) -- BBP phase transition (Baik-Ben Arous-Péché 2005): -- Add rank-1 spike to Wigner matrix: A = W + θ·vvᵀ -- If θ ≤ 1: λ_max = 2 (spike invisible in bulk) -- If θ > 1: λ_max = θ + 1/θ (spike pops out!) -- Implication for SAM / adaptive learning rates: -- Focus on outlier eigenvalues (sharp directions) -- Adam's 2nd moment ≈ estimates these eigenvalues -- Gradient noise ∝ bulk; signal ∝ outliers

-- MDP: (𝒮, 𝒜, P, R, γ) — state, action, transition, reward, discount -- Bellman optimality equation: V*(s) = max_a [ R(s,a) + γ Σ_{s'} P(s'|s,a) V*(s') ] Q*(s,a) = R(s,a) + γ Σ_{s'} P(s'|s,a) max_{a'} Q*(s',a') -- 𝒯 is a γ-contraction: ‖𝒯V - 𝒯V'‖_∞ ≤ γ‖V-V'‖_∞ -- Value iteration converges: ‖Vₜ - V*‖_∞ ≤ γᵗ‖V₀-V*‖_∞
Policy Gradient Theorem REINFORCE

The policy gradient theorem gives an exact expression for ∇_θ J(π_θ) without needing to differentiate through the environment dynamics.

∇_θ J(π_θ) = E_{τ~π_θ}[ Σₜ ∇_θ log π_θ(aₜ|sₜ) · Gₜ ] -- Gₜ = Σₖ γᵏ rₜ₊ₖ (return from step t) -- With baseline b(s): ∇_θ J = E[ Σₜ ∇_θ log π_θ(aₜ|sₜ) · (Gₜ - b(sₜ)) ] -- Baseline reduces variance, keeps unbiased -- Actor-critic: b(s) = V_φ(s) (critic estimate) -- A(s,a) = Q(s,a) - V(s) (advantage function)
Trust Region & PPO Stability

Unconstrained policy gradient can take steps that collapse performance. TRPO constrains the KL divergence. PPO clips the probability ratio — a practical approximation.

-- TRPO: max_θ E[π_θ(a|s)/π_θ_old(a|s) · A(s,a)] s.t. E[D_KL(π_old‖π_θ)] ≤ δ -- PPO (clipped surrogate): L^CLIP = E[min(rₜ·Aₜ, clip(rₜ, 1-ε, 1+ε)·Aₜ)] rₜ = π_θ(aₜ|sₜ)/π_θ_old(aₜ|sₜ) -- ε=0.2: prevents large updates implicitly -- GRPO (DeepSeek): removes value net, uses group norm
RLHF — Mathematical Foundation LLM Alignment
1
Reward model from preferences (Bradley-Terry)
P(y₁ ≻ y₂ | x) = σ(r(x,y₁) - r(x,y₂)) = exp(r₁)/(exp(r₁)+exp(r₂)). Train r_θ by cross-entropy on human preference pairs: max E[log σ(r_θ(x,y_w) - r_θ(x,y_l))].
2
KL-constrained optimisation
max_π E_{x~D, y~π}[r(x,y)] - β·D_KL(π‖π_ref). The KL penalty prevents the policy from collapsing to reward-hacking mode sequences.
3
Closed-form optimal policy
π*(y|x) = π_ref(y|x) · exp(r(x,y)/β) / Z(x). Optimal policy is the reference scaled by exponentiated reward, normalised. Z(x) is intractable → needs RL approximation.
4
DPO — Direct Preference Optimisation
Substitutes the optimal policy into the Bradley-Terry model to eliminate r(x,y) entirely: max E[log σ(β·log(π_θ(y_w|x)/π_ref(y_w|x)) - β·log(π_θ(y_l|x)/π_ref(y_l|x)))]. Trains the LLM directly on preferences without a separate reward model.
PAC-MDP Sample Complexity Exploration
-- E³ algorithm: ε-optimal policy in poly steps -- Sample complexity: Õ(|𝒮|²|𝒜|/((1-γ)⁴ε²)) (Kakade 2003) -- Regret bounds (tabular MDP): -- UCB-VI: R_T ≤ Õ(√(H³|𝒮||𝒜|T)) -- H = horizon, T = total steps -- Exploration-exploitation tradeoff: -- Optimism in the face of uncertainty (OFU) -- Thompson sampling: posterior over MDPs -- Information-theoretic lower bound: Ω(√(|𝒮||𝒜|T)) -- Linear MDP (generalisation): P(s'|s,a) = φ(s,a,s')ᵀμ*, R(s,a) = φ(s,a)ᵀθ* -- LSVI-UCB: R_T ≤ Õ(d√H³T) (d = feature dim)

Steerable CNNs & Harmonic Analysis SE(2) Equivariance

Fast Multipole Method & Structured Computation O(n log n)

FMM approximates matrix-vector products for matrices with low-rank off-diagonal structure in O(n log n). This exploits the same hierarchical structure as the FFT — and connects to efficient attention.

-- Hierarchical matrix (H-matrix): K[I,J] ≈ UV^T (low-rank for well-separated I,J) -- FMM: O(n log n) matvec for kernel matrices -- Butterfly factorisation: F_n = (I_{n/2}⊗F_{n/2}) · B (Cooley-Tukey FFT) -- Monarch matrix: H-matrix for GPU-efficient matmul -- Hyena operator: long convolution via FFT -- H3 / Mamba: structured state space (diagonal A)
Numerical Linear Algebra for Eigenproblems QR Algorithm

The QR algorithm is the standard method for computing all eigenvalues. It iteratively applies QR decompositions until the matrix converges to Schur form.

-- QR algorithm: A₀ = A A_k = Q_k R_k -- QR decomposition A_{k+1} = R_k Q_k -- swap order! -- A_k → upper triangular (Schur form) -- Diagonal entries → eigenvalues -- Convergence: O(|λ₂/λ₁|^k) for largest -- With shifts: cubic convergence in practice -- Implicitly shifted QR: O(n²) per iteration

07 — Advanced Optimisation

Advanced Optimisation

Interior point methods, semidefinite programming, Frank-Wolfe, mirror descent, and the geometry of constrained optimisation — beyond gradient descent.

Mirror Descent — Bregman Divergence GeometryGeneralised GD

Mirror descent generalises gradient descent using a Bregman divergence D_Ψ. Different choices of the mirror map Ψ give different algorithms: GD (Ψ=‖·‖²), exponentiated GD (Ψ=entropy), and more.

Mirror map Ψ:
-- Mirror descent update: θₜ₊₁ = argmin_θ { ⟨∇f(θₜ), θ⟩ + (1/η) D_Ψ(θ, θₜ) } -- Bregman divergence: D_Ψ(x,y) = Ψ(x)-Ψ(y)-⟨∇Ψ(y),x-y⟩ -- Ψ=‖x‖²/2 → D_Ψ=‖x-y‖²/2 → standard GD -- Ψ=Σxᵢlogxᵢ → D_Ψ=KL(x‖y) → EGD on simplex -- Regret: Σₜ f(θₜ)-f(θ*) ≤ D_Ψ(θ*,θ₁)/η + η/2 Σₜ‖∇f‖²_*
Semidefinite Programming SDP

SDP optimises a linear objective over the cone of PSD matrices. More expressive than LP. Used in approximation algorithms, MAXCUT, and relaxations of NP-hard graph problems.

-- Primal SDP: min tr(CX) s.t. tr(AᵢX) = bᵢ, X ⪰ 0 -- X ⪰ 0: X is positive semidefinite -- Dual SDP: max bᵀy s.t. C - Σᵢ yᵢAᵢ ⪰ 0 -- Interior-point: O(n^3.5) per iteration -- MAXCUT: SDP gives 0.878-approx (Goemans-Williamson) -- ML applications: kernel learning, metric learning -- Nuclear norm min (matrix completion): SDP relaxation
Frank-Wolfe & Conditional Gradients Projection-Free

Frank-Wolfe avoids projection onto a constraint set — instead solves a linear subproblem over the constraint. Ideal for sparse solutions and nuclear norm constraints (matrix completion).

-- Frank-Wolfe (conditional gradient): sₜ = argmin_{s∈𝒞} ⟨∇f(xₜ), s⟩ -- LMO xₜ₊₁ = (1-γₜ)xₜ + γₜsₜ -- γₜ = 2/(t+2) → O(1/T) convergence -- Advantage: LMO often cheaper than projection -- Sparse solutions: iterates are convex combos of vertices -- Nuclear norm ball: LMO = top singular vector pair -- Atomic norm: FW gives structured sparsity
Sharpness-Aware Minimisation (SAM) — Loss GeometryFlat Minima

SAM finds parameters where the loss is uniformly low in a neighbourhood — flat minima that generalise better. It solves a minimax: min_θ max_{‖ε‖≤ρ} L(θ+ε).

-- SAM objective: min_θ max_{‖ε‖≤ρ} L(θ+ε) -- Perturbation ε* = ρ · ∇L(θ)/‖∇L(θ)‖ (first-order approx) -- Update: θ ← θ - η·∇L(θ+ε*) -- Two gradient computations per step vs one for SGD -- PAC-Bayes connection: L_SAM ≈ max sharpness in ball → bound on KL(Q‖P) -- Flatness: λ_max(H(θ)) small → better PAC-Bayes bound -- m-SAM, GSAM, ASAM: variants for efficiency

Hebbian Learning & Oja's Rule Unsupervised

"Neurons that fire together wire together." Hebbian learning is the biological basis for unsupervised feature learning. Oja's rule adds normalisation to prevent weight explosion.

-- Hebbian update: ΔW = η · y · xᵀ (y = Wx: output) -- Unstable: ‖W‖ → ∞ without normalisation -- Oja's rule (stable PCA!): ΔW = η · (y·xᵀ - y²·W) -- Convergence: W → first principal component -- Biologically plausible PCA -- BCM rule (Bienenstock-Cooper-Munro): ΔW = η · y · (y - θ_M) · x -- θ_M = sliding threshold → LTP/LTD -- Emergence of orientation selectivity
Predictive Coding Hierarchical Inference

Predictive coding (Rao & Ballard) posits that the brain minimises prediction errors hierarchically. Each layer predicts the layer below; only errors propagate upward. This is mathematically equivalent to variational inference.

-- Generative model: xₗ = f_θ(μₗ₊₁) + εₗ -- Minimise free energy F: F = Σₗ εₗᵀ Σₗ⁻¹ εₗ + log|Σₗ| -- Prediction error: εₗ = xₗ - f_θ(μₗ₊₁) -- Inference: dμ/dt = -∂F/∂μ -- Learning: dθ/dt = -∂F/∂θ -- PC ≡ backprop (Millidge 2021): same fixed points

Cross-Entropy Loss — Mathematical Foundation Language Modelling
-- Negative log-likelihood (next token prediction): L(θ) = -1/T Σₜ log p_θ(xₜ | x₁,…,xₜ₋₁) -- = cross-entropy H(p_data, p_model) -- = H(p_data) + D_KL(p_data ‖ p_model) [data entropy + KL] -- Perplexity: PPL = 2^(L) = exp(L) (in nats) -- Bits per byte (bpb): L / log(2) / avg_bytes_per_token -- Softmax numerics: p_θ(xₜ=k) = exp(zₖ) / Σⱼ exp(zⱼ) -- log-sum-exp trick: subtract max for stability -- Label smoothing: q = (1-ε)·one_hot + ε/|V| -- → regularises model, prevents overconfidence -- Z-loss (PaLM): adds Σ exp(zₖ)² penalty -- Prevents logit explosion, improves numerical stability
Gradient Clipping Stability

Gradient clipping prevents catastrophic parameter updates. Global norm clipping is mathematically clean: it rescales the entire gradient vector to have norm ≤ c.

-- Global norm clipping: g ← g · min(1, c/‖g‖) -- Preserves direction, scales magnitude -- c typically 1.0–5.0 for LLMs -- Why it works: bounded update radius -- ‖θₜ₊₁ - θₜ‖ = η·‖g‖ ≤ η·c -- Prevents spikes due to rare sequences -- Adaptive clipping: per-layer thresholds
Weight Decay — L2 or Decoupled? AdamW

Standard Adam + L2 regularisation ≠ AdamW. The adaptive learning rate in Adam scales the weight decay, making it effectively much smaller for weights with large gradients. AdamW decouples them.

-- Adam + L2: update w = w - α(g/√v̂ + λw) -- Effective decay: λ/√v̂ (varies per weight!) -- AdamW (Loshchilov 2019): w ← w · (1 - αλ) -- direct weight decay w ← w - α · m̂/√v̂ -- Adam step -- Uniform decay: λ same for all weights -- Equivalence to L2 only for SGD, not Adam -- λ ≈ 0.01–0.1 for LLMs; schedules it too
