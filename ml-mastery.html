CH.00

What is Machine Learning?

Teaching computers to learn patterns from data — without being explicitly programmed for every rule.

🗂️

Data

Examples the model learns from. The raw material of every ML system.

🧮

Algorithm

The learning process — how the model adjusts itself to fit the data.

🧠

Model

The learned function f(x)→y that makes predictions on new unseen data.

The Core Idea
Traditional: Rules + Data → Output
Machine Learning: Data + Output → Rules (Model)
ML inverts traditional programming — the model discovers rules automatically from examples.
Showing raw data — no model yet
Supervised LearningPattern Recognition Feature SpaceDecision Boundary
Theory & Math Deep-Dive▼

Intuition

Traditional programming: you write the rules. ML: you show examples and the computer discovers the rules itself.

Analogy

Teaching a child to recognise dogs. You don't give them a rule book listing every breed's exact measurements. You show them 1,000 labelled photos and their brain finds the patterns automatically. ML does the same, just with math instead of neurons.

The formal goal: find a function f that maps inputs X to outputs Y, by minimising some measure of error on training data, in a way that also works on new, unseen data (generalisation).

The Core Math

Formal objective
f* = argmin over f in H of (1/n) sum_i L(yi, f(xi)) + lambda * Omega(f)
H = hypothesis class (set of all functions we consider). L = loss function. Omega = regulariser. lambda = trade-off.
1
(x1,y1), (x2,y2), ..., (xn,yn)
Training data: n examples. xi is the input (features), yi is the target (label). We never see the true distribution, only these samples.
2
L(y, yhat) = penalty for predicting yhat when truth is y
Common choices: squared error (yi - yhati)^2 for regression; cross-entropy -y*log(yhat) for classification. The loss defines what "wrong" means.
3
Empirical Risk = (1/n) sum L(yi, f(xi))
Average loss on training data. Minimising this is "fitting the training set." But we really want low loss on new data, that's the generalisation gap.

Expert Must-Know

The IID assumption: ML assumes training and test data are drawn independently from the same distribution. Violating this (covariate shift, concept drift) is the number one cause of production failures.
No Free Lunch Theorem: No single algorithm is best for all problems. Every algorithm makes assumptions (inductive biases). Understanding those biases is what separates engineers from practitioners.
Statistical Learning Theory: The generalisation gap is bounded by model complexity (VC dimension) and sample size. More complex model means tighter fit to training data but higher risk of not generalising.

Watch Out For

  • Data leakage: test set information sneaking into training (e.g. normalising on the full dataset before splitting)
  • Label leakage: target variable's future information included as a feature
  • Survivorship bias: training data only reflects "successful" outcomes

Types of Machine Learning

Three fundamental learning paradigms, each suited to different problem structures and data availability.

🏷️

Supervised Learning

Learn a mapping from labeled input–output pairs. Goal: predict output for new inputs.

🔍

Unsupervised Learning

Find hidden structure in unlabeled data. Goal: discover clusters, patterns, representations.

🎮

Reinforcement Learning

Agent learns by interacting with environment, maximizing cumulative reward signals.

RegressionClassification ClusteringDimensionality Reduction Policy LearningReward Maximization
Theory & Math Deep-Dive▼

Intuition

Supervised: Teacher provides correct answers. Model learns input to output mapping. Used when you have labelled historical data.

Unsupervised: No teacher. Model finds hidden structure in the data itself, clusters, patterns, latent dimensions.

Reinforcement: Agent takes actions in an environment, receives rewards, learns a policy to maximise long-term return. No dataset, experience is generated by interaction.

The Math

Supervised, conditional density
Learn: P(Y | X) then predict E[Y|X] or argmax P(Y=c|X)
Unsupervised, joint density
Learn: P(X) then find clusters, anomalies, or latent Z where X = g(Z) + noise
Reinforcement Learning, Bellman equation
V*(s) = max_a [ R(s,a) + gamma * sum_s' P(s'|s,a) V*(s') ]
V*(s) = optimal value of state s. gamma = discount factor (0 to 1). R = immediate reward. The agent optimises future discounted reward.

Expert Must-Know

Semi-supervised learning: Uses a small labelled set plus large unlabelled set. Often better in practice because labelling is expensive. Key idea: unlabelled data reveals the input distribution P(X).
Self-supervised learning: Creates supervision from the data itself (e.g. predict next word, reconstruct masked patches). Foundation of GPT, BERT, MAE. Dominant paradigm in modern deep learning.
Multi-task learning: Train one model on multiple related tasks simultaneously. Shared representations generalise better. Regularisation effect: forces the model to learn broadly useful features.

Fit a line (or hyperplane) to data by minimizing the sum of squared prediction errors.

Minimize this to find the best-fitting line.

Intuition

Draw the best possible straight line (or flat plane in multiple dimensions) through your data so that the average squared distance from each point to the line is minimised.

Analogy

Imagine hanging rubber bands from each data point down to a line on the floor. The "best fit" line is where the total elastic energy (sum of squared band lengths) is lowest.

The Math, Step by Step

1
Model: yhat = w*x + b = X*theta
yhat is the prediction. w (weight/slope) says "how much does y change per unit of x?". b (bias/intercept) is the value when x=0. In matrix form with theta=[b, w1, w2,...], X has a column of 1s for the bias.
2
Loss: MSE = (1/n) sum_i (yi - yhati)^2 = (1/n)||y - X*theta||^2
We square the errors so negatives don't cancel positives, and large errors are penalised more heavily (squaring amplifies them).
3
Normal Equation: theta* = (X^T X)^-1 X^T y
Take derivative of MSE w.r.t. theta, set to zero, solve. This gives the exact closed-form solution, no iteration needed! But O(d^3) to invert the matrix, so gradient descent is used for large d.
4
R-squared = 1 - SS_res/SS_tot = 1 - sum(yi-yhati)^2 / sum(yi-ybar)^2
Proportion of variance explained by the model. R2=1: perfect fit. R2=0: model no better than predicting the mean. R2 less than 0: model is WORSE than just predicting the mean, a red flag.
Geometric Interpretation
yhat = X(X^T X)^-1 X^T y = H*y
H is the "hat matrix", a projection onto the column space of X. Linear regression literally projects y onto the subspace spanned by your features.

Expert Must-Know

Gauss-Markov theorem: Under assumptions (linearity, exogeneity, homoscedasticity, no perfect multicollinearity), OLS is BLUE, Best Linear Unbiased Estimator. Violating assumptions means biased or inefficient estimates.
Assumptions to check: (1) Linearity of relationship. (2) Homoscedasticity: constant error variance, plot residuals vs fitted. (3) Independence of errors. (4) Normality of errors (for inference, not prediction). (5) No multicollinearity: VIF greater than 10 is a problem.
MLE connection: Minimising MSE equals maximising likelihood under Gaussian noise model yi = f(xi) + noise, noise~N(0,sigma^2). If noise is non-Gaussian, MSE is no longer optimal.

Watch Out For

  • Extrapolation: Linear models are dangerous outside the training range
  • Influential points: A single outlier can shift the entire regression line (check Cook's distance)
  • Multicollinearity: Highly correlated features make individual coefficient estimates unstable, their sum is stable but each individually is not
  • (X^T X) singular: Happens when features are linearly dependent. Ridge regression (add lambda*I) fixes this.

Theory & Math Deep-Dive▼

Intuition

Imagine you're blindfolded on a hilly landscape and want to reach the lowest valley. You can only feel the slope under your feet. The strategy: always take a small step in the direction that goes downhill. Repeat until the ground feels flat. That's gradient descent.

Analogy, The Ski Slope

The loss function is the landscape. Parameters theta are your position. The gradient tells you which direction is steepest uphill. Step in the opposite direction. Alpha (learning rate) controls how big each step is: too large means overshoot and bounce around; too small means take forever.

The Math

1
Gradient: grad J(theta) = [ dJ/dtheta1, dJ/dtheta2, ... ]
The gradient is a vector pointing in the direction of steepest INCREASE of J. Each component says "if I increase thetai slightly, how much does J increase?" We want to DECREASE J, so we step in the negative direction.
2
Update: theta = theta - alpha * grad J(theta)
Alpha is the learning rate (step size). This single line is the entire update rule. The minus sign moves us DOWNHILL. The gradient magnitude scales the step: large gradient means big step, small gradient means tiny step.
3
For MSE loss: grad J(theta) = -(2/n) X^T (y - X*theta)
Derivative of (1/n)||y-X*theta||^2 w.r.t. theta. At minimum: X^T(y-X*theta)=0, which is the normal equation again, gradient descent converges to the same solution.
Variants, which to use?
Batch GD: gradient over ALL n samples, stable, O(n) per step SGD: gradient over 1 sample, noisy, fast, escapes local minima Mini-batch: gradient over B samples, best of both worlds (B=32 to 256)
Modern deep learning uses mini-batch SGD. The noise from small batches acts as implicit regularisation and helps escape sharp minima, leading to flatter, more generalisable solutions.
Convergence rate (convex loss)
J(theta_k) - J(theta*) is at most O(1/k) [sublinear for GD]
For strongly convex losses (e.g. Ridge regression): O(rho^k) exponential convergence where rho depends on the Lipschitz constant and strong convexity constant.

Expert Must-Know

Learning rate selection: The optimal learning rate is bounded by the Lipschitz constant (largest eigenvalue of the Hessian). In practice: use learning rate finders, warmup schedulers, or adaptive methods (Adam).
Loss landscape is NOT convex for deep nets: But empirically, gradient descent finds good solutions anyway. Key insight (Goodfellow, 2015): in high dimensions, saddle points are exponentially more common than local minima, and they're harmless because at least one direction goes downhill.
The condition number problem: If loss contours are elongated ellipses (different curvature in different directions), gradient descent zigzags. This is why Adam's per-parameter learning rates are so powerful, they effectively rescale the geometry.

Connections

  • Gradient descent on MSE loss is equivalent to OLS normal equation solution (if run to convergence)
  • Add L2 penalty, get Ridge regression (gradient has extra 2*lambda*theta term)
  • SGD with momentum approximates second-order optimisation (Newton's method) at much lower cost
  • Natural Gradient Descent: precondition by Fisher information matrix, invariant to parameterisation

Logistic Regression

Binary classification by squashing a linear combination through a sigmoid to output probabilities.

Sigmoid Function
σ(z) = 1 / (1 + e⁻ᶻ) where z = w·x + b
Output is P(y=1|x) — probability of belonging to the positive class.
Two classes visible — model not trained yet
Hover over the scatter plot to see P(class=blue | x)
Binary Cross-Entropy LossDecision Boundary @ P=0.5 Probabilistic OutputLinear Classifier
Theory & Math Deep-Dive▼

Intuition

Logistic regression answers: "what is the probability that this input belongs to class 1?" It's linear regression's output squashed through a sigmoid so it always outputs a value between 0 and 1.

The Key Insight

You can't directly model probability with linear regression, it could predict values above 1 or below 0. The trick: model the LOG-ODDS (logit) linearly, then convert back to probability. Log-odds can be any real number; probability must be in [0,1].

The Math

1
Odds ratio: odds = P(y=1) / P(y=0)
If 3 out of 4 patients have a disease: odds = 3/1 = 3. Probability = 3/4 = 0.75. Odds range from 0 to infinity, which is still problematic.
2
Log-odds (logit): log(p / (1-p)) = w^T x + b
Taking the log of odds gives a value in (-infinity, +infinity). Now we can model it linearly! This is the "logistic" in logistic regression.
3
Solving for p: sigma(z) = 1 / (1 + e^-z) where z = w^T x + b
Invert the log-odds equation. The sigmoid function squashes any real number z to (0,1). Positive z means P close to 1. Negative z means P close to 0. z=0 means P=0.5 (decision boundary).
4
Loss: BCE = -(1/n) sum [yi log(phati) + (1-yi) log(1-phati)]
Derived from Maximum Likelihood Estimation. When y=1: penalise -log(phat), large penalty if we predicted low probability. When y=0: penalise -log(1-phat). This is the cross-entropy loss. It's convex, one global minimum.
Multiclass, Softmax
P(y=c | x) = exp(wc^T x) / sum_j exp(wj^T x)
Generalises sigmoid to K classes. Also called multinomial logistic regression. Loss becomes categorical cross-entropy.

Expert Must-Know

Logistic regression is a linear classifier: The decision boundary is always a hyperplane. If your data isn't linearly separable in feature space, you need feature engineering, kernels, or a non-linear model.
Class imbalance: With 95% negative class, a model predicting all-negative gets 95% accuracy but 0% recall on positives. Always check AUC-ROC, not just accuracy. Use class_weight='balanced' or adjust the decision threshold (not always 0.5).
Calibration: Logistic regression outputs are well-calibrated probabilities (unlike SVM scores or tree probabilities). This matters in medical/financial applications where P(y=1)=0.7 should really mean 70% probability.
Interpretability: Coefficient wj means: a one-unit increase in feature j multiplies the ODDS by e^wj, holding other features constant. Sign of w tells you direction; magnitude tells you strength.

Decision Trees

Recursively partition the feature space using axis-aligned splits, maximizing information gain at each node.

Gini Impurity (split quality)
Gini = 1 − Σ pᵢ²
pᵢ = fraction of samples of class i in a node. Gini = 0 means a pure node.
Max Depth: 3 Press Grow Tree to watch splits form
✅

Pros

Interpretable, no feature scaling needed, handles non-linear boundaries, works with mixed data types.

⚠️

Cons

Prone to overfitting (especially deep trees), high variance — small data changes drastically alter the tree.

Theory & Math Deep-Dive▼

Intuition

A flowchart that makes decisions by asking yes/no questions about features. Each split divides the data into increasingly pure subgroups. Predict by following the rules from root to leaf.

Analogy, 20 Questions

Like playing "20 Questions." Each question splits the possibility space. A good first question (high information gain) halves the space, "Is it alive?" eliminates half of all objects. A bad question gives little information, "Is it exactly 5.3cm?" tells you almost nothing.

The Math, Information Theory

1
Entropy: H(S) = -sum_c pc log2(pc)
Entropy measures "impurity" or "uncertainty." H=0: all samples same class (pure node). H=1 (for binary): 50-50 split (maximally uncertain). We want to find splits that REDUCE entropy.
2
Information Gain: IG = H(parent) - sum (|child|/|parent|)*H(child)
How much entropy do we remove with this split? Weighted by the fraction of samples in each child. We pick the split (feature + threshold) with maximum IG.
3
Gini: G(S) = 1 - sum_c pc^2
Alternative to entropy. Computationally cheaper (no log). G=0: pure. G=0.5: maximum impurity for binary class. CART (scikit-learn's default) uses Gini.
Regression Trees, Variance Reduction
Split quality = Var(parent) - [|left|/n * Var(left) + |right|/n * Var(right)]
For continuous targets: minimise weighted variance of child nodes. Equivalent to minimising MSE within each leaf.

Expert Must-Know

Decision trees are PIECEWISE CONSTANT: They partition feature space into axis-aligned rectangles, predicting a constant value in each. They cannot extrapolate beyond training range and struggle with diagonal boundaries.
Pruning: Grow a full tree then remove nodes where the improvement in held-out performance doesn't justify the complexity. Cost-complexity pruning minimises (error + alpha * number of leaves).
Feature importance: Gini importance is biased toward high-cardinality features, use permutation importance instead for unbiased estimates.
CH.06

Random Forests

An ensemble of decision trees trained on random data subsets, voting together for robust predictions.

Ensemble Prediction
ŷ = mode{ T₁(x), T₂(x), ..., Tₙ(x) }
Each tree Tᵢ trained on a bootstrap sample + random feature subset. Majority vote wins.
Trees: 5 Watch the trees vote on a test sample
Bagging (Bootstrap Aggregating)Feature Randomness Low VarianceReduces Overfitting
Theory & Math Deep-Dive▼

Intuition

Instead of one deep tree that memorises training data, train hundreds of shallow trees, each on a different random subset of data and features. Each tree is "weak" individually but together they vote. Diverse independent errors cancel; shared signal reinforces.

Wisdom of Crowds

Ask 1 expert: might be wrong. Ask 100 independent experts: the average is almost always better. Key: independence. If all experts read the same report, their errors correlate and don't cancel. Bagging creates independence by training each tree on a different random sample.

The Math, Why Averaging Reduces Variance

1
Var(average of n iid variables) = sigma^2/n
If each tree has variance sigma^2 and they're uncorrelated, averaging n of them reduces variance by n. But trees trained on the same data ARE correlated, so we don't get full 1/n reduction.
2
Var(average) = rho*sigma^2 + (1-rho)*sigma^2/n
rho = average pairwise correlation between trees. If rho=0: variance = sigma^2/n. If rho=1: variance = sigma^2 (no gain). Random feature selection decreases rho, more variance reduction.
3
Bootstrap: sample n points WITH replacement from n training points
Each bootstrap sample contains about 63.2% unique points. The remaining about 36.8% are never seen by that tree, these are "out-of-bag" (OOB) samples, used for free validation.
Bias-Variance for Ensembles
Bias[RF] is about equal to Bias[single tree] (same structure) Var[RF] is much less than Var[single tree] (averaging effect)
Random forests reduce variance without increasing bias. They are NOT better than single trees on simple problems, the benefit scales with complexity and noisiness of the data.

Expert Must-Know

Key hyperparameters: (1) n_estimators: more is always better, just slower. (2) max_features: sqrt(p) for classification, p/3 for regression. (3) max_depth: None (full trees) is usually fine, bagging controls overfitting. (4) min_samples_leaf: increasing reduces variance.
Feature importance pitfall: RF feature importance is biased toward high-cardinality features. Always use permutation importance or SHAP for reliable importance estimates.
Extremely Randomised Trees (Extra-Trees): Instead of finding the best split, pick a random split threshold. Even more variance reduction, less computation. Often matches RF performance, trains 2-5x faster.

K-Nearest Neighbors

"You are your neighbors." Classify a point by majority vote of its K nearest training examples.

Euclidean Distance
d(p,q) = √( Σᵢ (pᵢ − qᵢ)² )
Find the K points with smallest distance to query, then take majority class vote.

Click on the plot to classify any point with K-NN
Theory & Math Deep-Dive▼

Intuition

The simplest possible classifier: "show me your neighbors and I'll tell you who you are." No explicit training, just memorise the entire dataset. At prediction time, find the K most similar training examples and take a majority vote.

The Math

Euclidean distance (most common)
d(p, q) = sqrt[ sum_i (pi - qi)^2 ]
Mahalanobis distance (accounts for correlations)
d(p, q) = sqrt[ (p-q)^T Sigma^-1 (p-q) ]
Sigma = covariance matrix. Mahalanobis normalises for scale and accounts for correlations between features. Much better when features have different units or are correlated.
Curse of Dimensionality
As d increases: ratio of max/min distance approaches 1
In high dimensions, all points become roughly equidistant. A nearest neighbor in 1,000 dimensions may be no more similar to the query than a random point. KNN degrades severely above about 20 dimensions.

The optimal K balances bias and variance. K=1: zero training error, high variance (overfit). K=n: predict always the majority class, high bias (underfit). Odd K avoids ties for binary classification.

Expert Must-Know

Always normalise features: Euclidean distance is scale-sensitive. A feature ranging 0-1,000 will dominate one ranging 0-1. Use StandardScaler or MinMaxScaler before KNN.
KD-trees and Ball-trees: Naive KNN is O(nd) per query. KD-trees reduce this to O(log n) in low dimensions. Ball-trees work better in higher dimensions. scikit-learn chooses automatically based on d.
Weighted KNN: Weight each neighbor by 1/d^2 (inverse squared distance). More robust to irrelevant neighbors and K selection. Almost always better than unweighted voting.
CH.08

Support Vector Machines

Find the hyperplane that maximizes the margin between classes — robustness through geometry.

Optimization Objective
maximize 2 / ‖w‖ subject to yᵢ(w·xᵢ + b) ≥ 1
Support vectors are the training points closest to the hyperplane — they define the margin.
Press to animate margin maximization
📐

Maximum Margin

SVM finds the widest possible "street" between classes, giving the best separation and generalization.

🔮

Kernel Trick

Map data to higher dimensions implicitly (RBF, polynomial) to separate non-linearly separable classes.

Theory & Math Deep-Dive▼

Intuition

Find the widest possible "street" (margin) between two classes. The decision boundary runs down the centre of this street. Wider street means more confident separation means better generalisation.

Analogy

Imagine separating red and blue marbles on a table by placing a ruler between them. You want the ruler to be as far from both groups as possible, maximum safety margin. The marbles closest to the ruler are the "support vectors."

The Math

1
Decision boundary: w^T x + b = 0 (hyperplane)
w is the normal vector (perpendicular to the boundary). Distance from any point x to the boundary = |w^T x + b| / ||w||. We label x as +1 if w^T x + b is at least 1, -1 if at most -1.
2
Margin width = 2 / ||w||
The "+1 hyperplane" is w^Tx+b=1 and the "-1 hyperplane" is w^Tx+b=-1. Distance between them = 2/||w||. Maximising this means minimising ||w||^2, a quadratic optimisation problem.
3
Primal: minimize (1/2)||w||^2 subject to yi(w^Txi+b) >= 1
Subject to all points being correctly classified with margin at least 1. For non-separable data (soft margin): add slack variables and penalise with parameter C.
4
Kernel trick: K(xi,xj) = phi(xi)^T phi(xj)
The dual problem only needs dot products between points. Replace these with a kernel function K that implicitly computes dot products in a high-dimensional space phi(x). Common kernels: RBF, polynomial.
Hinge Loss (equivalent formulation)
L = sum max(0, 1 - yi(w^Txi+b)) + lambda*||w||^2
Hinge loss is 0 when correctly classified with margin at least 1, and linear in the violation otherwise.

Expert Must-Know

C parameter: Small C means wider margin, more misclassifications allowed (high bias/low variance). Large C means narrow margin, fewer misclassifications (low bias/high variance). C is the inverse of regularisation strength.
gamma (RBF kernel): Controls the radius of influence of each support vector. Small gamma means smooth boundary. Large gamma means wiggly boundary, may overfit.
SVMs scale poorly: O(n^2 to n^3) training complexity. For n greater than 100k samples, switch to LinearSVC or SGDClassifier with hinge loss. SVMs shine on small high-dimensional datasets (text, genomics).

Partition unlabeled data into K clusters by iteratively assigning points and moving centroids.

Theory & Math Deep-Dive▼

Intuition

Partition unlabelled data into K groups so that similar points end up together. Like organising a messy room, you don't have predefined categories, you discover them by putting similar things near each other.

The Math

Objective (Within-Cluster Sum of Squares, Inertia)
minimize sum_k sum_{i in Ck} ||xi - muk||^2
Find K centroids and assignments that minimise total squared distance from each point to its cluster centre. NP-hard in general, but the Lloyd algorithm (E to M alternation) converges to a local minimum.
E
Assign: ci = argmin_k ||xi - muk||^2
Each point takes the nearest centroid as its cluster label. This is the "Expectation" step, hard assignment.
M
Update: muk = (1/|Ck|) sum_{i in Ck} xi
Move each centroid to the mean of its assigned points. This minimises WCSS for fixed assignments. WCSS decreases or stays same at every step, guaranteed convergence (but to local minimum).
K-means++ Initialisation
P(x chosen as next centroid) is proportional to d(x, nearest existing centroid)^2
Choose centroids spread out in the data. Provably gives O(log K) approximation to optimal. Dramatically reduces sensitivity to initialisation. Default in scikit-learn.

Expert Must-Know

Choosing K, Elbow method: Plot WCSS vs K. Find the "elbow" where adding more clusters gives diminishing returns. Also use Silhouette score: measures cohesion vs separation. Score near 1 means well-separated clusters.
K-means limitations: (1) Assumes spherical clusters of similar size, use DBSCAN or GMM for arbitrary shapes. (2) Sensitive to outliers, K-medoids is robust. (3) Requires K in advance, DBSCAN doesn't. (4) Euclidean distance biased by scale, always normalise first.
K-means is a special case of EM: Hard assignments are E-step with 0/1 responsibilities. Centroid update is M-step. GMM (Gaussian Mixture Model) is the soft, probabilistic version.

Naive Bayes

Apply Bayes' theorem with the "naive" assumption that features are conditionally independent given the class.

Bayes' Theorem
P(C|x) ∝ P(x|C) · P(C)
Gaussian NB: P(xᵢ|C) = N(xᵢ; μ_C, σ²_C) — each feature modeled as a Gaussian per class.
Click on the x-axis to classify a point
Click on the x-axis to see class probabilities for any value
Theory & Math Deep-Dive▼

Intuition

Use Bayes' theorem to flip the question: instead of "P(class | features)?" ask "P(features | class)?" which is easier to estimate. The "naive" part: assume all features are independent given the class.

Spam Filter Example

"Free money now" gives P(spam | these words) proportional to P("free"|spam) times P("money"|spam) times P("now"|spam) times P(spam). Each word contributes independently. Even if the independence assumption is wrong, the model often works well in practice.

The Math

1
Bayes' Theorem: P(C|x) = P(x|C)*P(C) / P(x)
Posterior = likelihood times prior, divided by evidence. P(x) is the same for all classes, so we can ignore it for classification, just compare P(x|C)*P(C) across classes.
2
Naive independence: P(x|C) = product_j P(xj|C)
If features are independent given the class, the joint probability is just the product of individual probabilities. This turns an intractable joint distribution into n simple 1D distributions.
3
Gaussian NB: P(xj|C) = N(xj; muj_c, sigmaj_c)
For continuous features, model each P(xj|C) as a Gaussian with mean and std estimated from training data. For text (counts), use Multinomial NB. For binary features, use Bernoulli NB.
Log-sum trick (numerical stability)
argmax_C [ log P(C) + sum_j log P(xj|C) ]
Multiplying many small probabilities underflows to 0. Work in log space instead, sums are numerically stable.

Expert Must-Know

Laplace smoothing: If a word never appears in training emails, P(word|spam)=0 and the entire product becomes 0. Solution: add pseudocount to every count.
When independence assumption helps: With small training data and many features, naive Bayes outperforms logistic regression because it has lower variance.

Intuition

Bias = systematic error from wrong model assumptions (e.g. fitting a straight line to curved data). Variance = sensitivity to training data (a different training set gives a very different model). You can't reduce both simultaneously, reducing one usually increases the other.

The Archer Analogy

High bias, low variance: arrows clustered together but far from the bullseye, consistent but systematically wrong. Low bias, high variance: arrows near the bullseye on average but scattered widely, correct direction but unreliable. Ideal: arrows clustered at the bullseye.

The Decomposition

MSE decomposition (key result)
E[(y - fhat(x))^2] = Bias[fhat(x)]^2 + Var[fhat(x)] + sigma^2
Expected MSE = (systematic error)^2 + (random fluctuation) + (irreducible noise). sigma^2 = inherent noise in y, cannot be reduced regardless of model.
1
Bias[fhat(x)] = E[fhat(x)] - f(x)
How far is the average prediction from the true function? High-degree polynomial: bias is near 0. Linear model on curved data: high bias. Bias is fixed, it doesn't go away with more data if the model is fundamentally wrong.
2
Var[fhat(x)] = E[(fhat(x) - E[fhat(x)])^2]
How much does the prediction vary across different training sets? High-degree polynomial: high variance. Linear model: low variance. Variance decreases with more training data.
Double Descent (modern DL insight)
Classical: U-shaped test error curve as model size increases Modern: second descent when model is massively overparameterised
Neural networks with more parameters than training samples can still generalise well. The regularisation comes from SGD, architecture, and implicit biases of gradient descent.

Expert Must-Know

Diagnosing from learning curves: If train and val error are BOTH high, that's high bias (underfitting). If train error is low but val is high, that's high variance (overfitting). If both are acceptable but equal, that's a good fit.
Regularisation effect: L2 regularisation (Ridge) adds bias but reduces variance. This is always beneficial when variance dominates, which is most practical settings with limited data.

Precision = TP / (TP + FP) means "of my positives, how many are real?"

Intuition

High-dimensional data often lies near a lower-dimensional structure. PCA finds the directions (principal components) along which data varies the most, then projects everything onto those directions, keeping the most information while using fewer numbers.

The Shadow Analogy

Imagine 3D objects casting a 2D shadow on the floor. The shadow loses one dimension but retains most shape information if you position the light well. PCA finds the optimal "light position", the projection that casts the least-distorted, most-informative shadow.

The Math

1
Centre data: Xtilde = X - mu (subtract column means)
PCA finds directions of maximum variance. Variance is defined relative to the mean. If you don't centre, PC1 will just point toward the mean, meaningless.
2
Covariance matrix: C = (1/n) Xtilde^T Xtilde
Cij = how much features i and j vary together. Diagonal = variance of each feature. Positive Cij: features tend to increase together. Negative: one increases as the other decreases.
3
Eigendecomposition: C = Q*Lambda*Q^T
Eigenvectors of C are the principal components (directions of maximum variance). Eigenvalues = variance explained by each PC. Sort by descending eigenvalue to get PC1 (max variance), PC2 (second most), etc.
4
Project: Z = Xtilde * Qk (keep top k eigenvectors)
Z is the low-dimensional representation. Choosing k: keep enough PCs to explain 95% of total variance.
Equivalence to SVD (numerically preferred)
Xtilde = U*Sigma*V^T then PCs = columns of V, scores = U*Sigma
SVD is numerically more stable than eigendecomposition of X^TX, especially when d is much greater than n.

Expert Must-Know

Standardise before PCA: If features have different scales (e.g. age in years, income in dollars), variance is dominated by the large-scale feature. Standardise (zero mean, unit variance) first.
PCA for noise reduction: In low-signal-to-noise data, small eigenvalues correspond to noise. Projecting to top k PCs removes noise dimensions.
Limitations: PCA only captures LINEAR structure. If data lies on a curved manifold, Kernel PCA, Isomap, or UMAP are needed. Also assumes Gaussian distributions, outliers can distort PCs significantly.

CH.16

Neural Network — Forward Pass

Information flows layer by layer: weighted sum of inputs → activation function → next layer's input.

Layer Computation
a⁽ˡ⁾ = σ(W⁽ˡ⁾ · a⁽ˡ⁻¹⁾ + b⁽ˡ⁾)
W = weight matrix, b = bias, σ = activation function (ReLU, Sigmoid, Tanh...)
Activation: Press Forward Pass to animate signal propagation
⚡

ReLU: max(0, z)

Most common hidden-layer activation. Fast, sparse, avoids vanishing gradients. But can "die" (z always negative).

🌊

Sigmoid: 1/(1+e⁻ᶻ)

Squashes output to (0,1). Good for binary output layers. Suffers from vanishing gradients in deep nets.

〰️

Tanh: (eᶻ−e⁻ᶻ)/(eᶻ+e⁻ᶻ)

Zero-centered, outputs (−1,1). Better than sigmoid for hidden layers but still vanishing gradient issues.

Theory & Math Deep-Dive▼

Intuition

Layer by layer transformations. Each layer takes the previous layer's representation, applies a learned linear transformation (matmul), adds a bias, then applies a non-linear squishing function (activation). Deep stacking lets the network learn hierarchical features.

The Detector Hierarchy

Layer 1 detects edges. Layer 2 combines edges into shapes. Layer 3 combines shapes into object parts. Layer 4 combines parts into objects. Each layer builds on the previous, just like how you first learn letters, then words, then sentences, then meaning.

The Math

Layer computation
z(l) = W(l) a(l-1) + b(l) then a(l) = sigma(z(l))
W(l) is the weight matrix. b(l) is the bias vector. sigma is the activation function applied elementwise. Each neuron computes a weighted sum of inputs plus bias, then squashes it.
Universal Approximation Theorem
For any small error, there exists a single hidden layer NN that approximates any continuous function on a compact set
BUT the required width may be exponentially large. Deeper networks can approximate the same functions with exponentially fewer parameters. This is WHY depth matters, it's computationally efficient.

Expert Must-Know

Weight initialisation matters enormously: All-zero weights mean all neurons learn the same thing (symmetry problem). Random N(0,1) means activations explode or vanish. Xavier init and He init are designed to keep variance stable across layers.
Activation functions: Sigmoid/Tanh lead to vanishing gradients for deep nets. ReLU can have dead neurons. Leaky ReLU / ELU fix dead neurons. GELU (used in Transformers) is smooth and works best in practice.
Width vs Depth: Both increase capacity. Depth is more parameter-efficient for complex functions. Residual connections (ResNet) solve the vanishing gradient problem for very deep networks by providing gradient highways.
CH.17

Backpropagation

Chain rule applied backwards through the network — computing how much each weight contributed to the error.

Chain Rule (Gradient Flow)
∂L/∂W⁽ˡ⁾ = δ⁽ˡ⁾ · (a⁽ˡ⁻¹⁾)ᵀ where δ⁽ˡ⁾ = (W⁽ˡ⁺¹⁾ᵀ δ⁽ˡ⁺¹⁾) ⊙ σ'(z⁽ˡ⁾)
Gradients flow from output back to input. Each layer's gradient is a product of upstream gradients × local derivative.
Step ①: Run forward pass first
1

Forward Pass

Compute activations through all layers, storing them for the backward pass.

2

Compute Loss

Compare final output to target. Loss = (ŷ − y)². Compute output layer error δ = ∂L/∂a.

3

Propagate Gradients Back

Use chain rule to pass δ backwards, computing ∂L/∂W for each weight matrix.

4

Update Weights

Apply gradient descent: W ← W − α · ∂L/∂W. Repeat for many mini-batches.

Theory & Math Deep-Dive▼

Intuition

During the forward pass, we compute the error. Backpropagation answers: "how much did each weight contribute to this error?" Using the chain rule, we propagate gradients backwards from output to input, computing the gradient for every weight.

The Chain Rule Intuition

"If changing gear ratio by 1% changes wheel speed by 5%, and changing wheel speed by 1% changes fuel efficiency by 2%, then changing gear ratio by 1% changes fuel efficiency by 10%." Backprop chains these partial derivatives all the way from loss to every parameter.

The Math

1
Output error: delta(L) = dL/da(L) times sigma'(z(L))
For MSE loss and sigmoid output, this combines the prediction error with the local slope of the activation function. This is the "local error signal" at the output layer.
2
Propagate back: delta(l) = (W(l+1)^T delta(l+1)) times sigma'(z(l))
Receive error from the layer above (multiplied by its transpose weights), then scale by how sensitive this layer's activation was.
3
Weight gradient: dL/dW(l) = delta(l) times (a(l-1))^T
The gradient w.r.t. a weight matrix is the outer product of the error signal and the input activations. Large error times large activation equals large gradient (this weight should change a lot).
Vanishing Gradient Problem
sigma'(z) of sigmoid is at most 0.25, so gradient shrinks by at least 75% per layer L layers deep: gradient becomes effectively 0
ReLU: sigma'(z)=1 for z greater than 0, gradient passes through unchanged. This is the PRIMARY reason ReLU replaced sigmoid/tanh in deep networks.

Expert Must-Know

Automatic differentiation: Autograd (PyTorch/TensorFlow) builds a computational graph and applies exact chain rule, efficient cost for forward plus backward pass.
Gradient clipping: Exploding gradients happen in RNNs. Fix: clip gradient norm to a threshold. Standard practice for any sequence model.
ResNet skip connections: The identity path lets gradient flow directly without vanishing. This is why ResNets can be 100+ layers deep.

Regularization — L1 & L2

Penalize large weights to prevent overfitting. The geometry of the penalty determines which weights survive.

Regularized Loss Functions
L2 (Ridge): J + λΣwᵢ² → shrinks all weights toward zero evenly
L1 (Lasso): J + λΣ|wᵢ| → drives some weights exactly to zero (sparse)
L1's diamond constraint creates sparse solutions. L2's circular constraint smoothly shrinks all weights.
λ (strength): 0.00 Drag λ slider to shrink weights — compare L1 vs L2
💎

L1 (Lasso) — Sparse

Diamond constraint. The optimal point touches a corner → one weight goes exactly to zero. Natural feature selection.

⭕

L2 (Ridge) — Dense

Circular constraint. The optimal point is on the circle's edge — all weights shrink proportionally, none zero out.

Theory & Math Deep-Dive▼

Intuition

Add a penalty to the loss function for large weights, this forces the model to keep weights small and spread the explanatory power across many features, preventing any one feature from dominating and causing overfitting.

The Math, Bayesian Interpretation

1
L2 (Ridge): J = MSE + lambda*sum wi^2
Equivalent to MAP estimation with Gaussian prior on weights. The regulariser says: "I believe weights are probably small, penalise me for making them large."
2
L1 (Lasso): J = MSE + lambda*sum |wi|
Equivalent to MAP with Laplace prior. The sharp peak at 0 of the Laplace distribution encourages EXACTLY zero weights, automatic feature selection.
3
Elastic Net: J = MSE + lambda1*sum|wi| + lambda2*sum wi^2
Combines L1 (sparsity) and L2 (handles correlated features). L1 alone struggles when features are correlated, it picks one arbitrarily. Elastic Net selects the group.
Ridge solution, SVD perspective
Ridge shrinks SVD components proportionally based on singular value size
Small singular values (noisy directions) are shrunk most. Large ones (informative directions) are preserved. This is the "regularisation as noise filtering" view.

Expert Must-Know

L2 never produces exactly zero weights (smooth penalty at 0). L1 produces sparse solutions (the optimal solution likely sits at a corner where some coordinates are exactly 0).
Regularisation approximates early stopping: Stopping gradient descent early has a similar effect to L2 regularisation. Both prevent weights from growing too large.
Regularisation path: As lambda increases from 0 to infinity, Lasso shrinks one weight at a time to exactly zero. Plotting all weight values vs lambda reveals which features are most important.

A learning curve shows how model performance changes as you add more training data. It diagnoses your model: are you underfitting (need better model), overfitting (need more data or regularisation), or well-tuned?

Statistical Learning Theory

PAC Learning Bound
With high probability, true risk is at most empirical risk plus an error term that shrinks as 1/sqrt(n)
More samples n gives a tighter bound. More complex model (larger hypothesis class) gives a looser bound.
VC Dimension bound
Error term scales roughly as sqrt[ VC(H) * log(n/VC(H)) / n ]

Isolation Forest — Anomaly Score

E[h(x)] = avg path length to isolate x. Anomalies are isolated in fewer splits → score → 1. Normal → score → 0.

Random recursive splits. Anomalies are isolated faster (fewer splits needed) since they lie far from the data density.

Statistical Methods

Z-score (Gaussian assumption), IQR (box plots), Mahalanobis distance for multivariate data.

Theory & Math Deep-Dive▼

Intuition

Most data is "normal." Anomalies are rare points that don't fit the pattern. The insight of Isolation Forest: anomalies are easier to isolate, it takes fewer random splits to separate an outlier from the crowd than to separate a typical point from its dense neighbourhood.

The Math

Isolation Forest anomaly score
s(x,n) = 2^(-E[h(x)] / c(n))
E[h(x)] = average path length to isolate x. c(n) = expected path length for n points (normalisation). Score near 1 means anomaly (isolated quickly). Score near 0.5 means normal.
Statistical Methods, Z-score
z = (x - mu) / sigma then anomaly if |z| > 3
Assumes Gaussian distribution. For multivariate data: Mahalanobis distance follows a chi-squared distribution, used to set a statistically grounded threshold.

Expert Must-Know

Isolation Forest hyperparameters: contamination (expected fraction of anomalies), max_samples (number of points per tree), n_estimators (100 usually sufficient).
One-Class SVM: Learns a tight boundary around normal data. Better than Isolation Forest when anomalies cluster in known regions. But doesn't scale beyond about 50k samples.
Autoencoders for anomaly detection: Train on normal data. At inference: reconstruction error is the anomaly score, anomalies are reconstructed poorly because the model has never seen them.

Intuition

t-SNE answers: "if I project 1,000-dimensional data to 2D, can I arrange points so that points that were close in 1,000D are still close in 2D?" It prioritises preserving local structure (nearby neighbours) over global structure.

The Math

Intuition

After each round, misclassified examples get a higher weight, they're "harder" and the next learner must focus on them. Easy examples become less important. The final prediction combines all learners weighted by their accuracy.

The Math

1
Error: epsilon_t = sum_i wi times indicator(ht(xi) is wrong)

AdaBoost is sensitive to noisy data: Mislabelled points get exponentially increasing weights, they dominate later learners, causing overfitting.
Stumps (depth-1 trees) are the canonical weak learners: AdaBoost with stumps is provably a margin-maximising classifier, related to SVMs.

🐢

SGD + Momentum

Accumulates velocity. Reduces oscillation along steep dimensions. β=0.9 is typical.

🚀

Adam

Combines momentum (first moment) + RMSprop (second moment). Adaptive, robust — default choice for deep learning.

Theory & Math Deep-Dive▼

Intuition

Momentum: like a ball rolling downhill, it builds up speed in consistent directions and doesn't bounce back from small bumps. Adam: keeps a separate running average of past gradient sizes for each parameter, giving large learning rates to parameters with small gradients and small learning rates to those with large gradients.

The Math

SGD with Momentum
vt = beta1*v_{t-1} + (1-beta1)*gt then theta_t = theta_{t-1} - alpha*vt
vt is an exponential moving average of gradients. beta1=0.9 means 90% old momentum, 10% new gradient. Reduces oscillation along steep dimensions.

Tracks bias-corrected first moment (mean) and second moment (variance) of gradients theta_t = theta_{t-1} - alpha * mhat_t / (sqrt(vhat_t) + epsilon)
First moment is direction (gradient mean). Second moment is scale (gradient variance). Default hyperparameters work well across most problems.

Expert Must-Know

Adam doesn't always generalise better than SGD: SGD with momentum plus good LR schedule often achieves better final accuracy on image classification. Adam converges faster but to sharper minima.
Learning rate warmup: Start with tiny lr, ramp up for the first few steps, then decay. Prevents early divergence when gradients are chaotic.
AdamW: Decouples weight decay from the gradient update. Always use AdamW over Adam when regularising.

Batch Normalization

Normalize layer inputs across the mini-batch to stabilize training, allow higher learning rates, and act as mild regularization.

BN Transform
x̂ᵢ = (xᵢ − μ_B) / √(σ²_B + ε)  →  yᵢ = γ·x̂ᵢ + β
μ_B, σ²_B = mini-batch mean/variance. γ, β = learned scale and shift. At inference: use running stats.

⚡

🌊

Smoother Gradients

🛡️

Mild Regularization

The noise from batch statistics acts like dropout — reduces overfitting slightly.

Intuition

As data passes through layers of a neural network, the distribution of activations shifts and changes, each layer receives inputs with a moving mean and variance. This "internal covariate shift" slows training. BatchNorm re-centres and re-scales after each layer, stabilising the distribution.

The Math

BN transform (training)

Expert Must-Know

BN placement: Originally after linear layer, before activation. Modern practice varies, sometimes omitted in favour of Layer Norm.
Layer Norm vs Batch Norm: BN normalises over the BATCH dimension (fails for batch size 1). Layer Norm normalises over the FEATURE dimension (works for any batch size). Transformers use Layer Norm.
BN as loss landscape smoother: The real reason BN works isn't eliminating covariate shift, it smooths the loss landscape, allowing larger learning rates without divergence.
CH.25

Dropout

Randomly zero out neurons during training, forcing the network to learn redundant representations that generalize better.

Dropout Mask
ã = a ⊙ m, mᵢ ~ Bernoulli(1−p) (training)
ã = (1−p)·a (inference — expectation scaling)
p = dropout rate (typically 0.2–0.5). Dropped neurons contribute 0. At inference, scale by (1−p).
Dropout rate p: 0.40 Each forward pass uses a different random subnetwork
Theory & Math Deep-Dive▼

Intuition

Randomly zero out neurons during each training step. This forces every neuron to learn features independently, it can't rely on specific other neurons always being there. The result: a more robust network where many different sub-networks learn the task.

The Math

Training, Inverted Dropout
Generate random mask with keep probability (1-p), apply to activations, then scale up by 1/(1-p)
Scaling by 1/(1-p) during training keeps expected activation constant, no need to scale at inference.
Dropout as ensemble
2^n possible subnetworks (n = number of units). Dropout trains all simultaneously with shared weights.
At inference with p=0: equivalent to taking the geometric mean prediction over all subnetworks. This explains why dropout works: it's ensembling without the exponential cost.

Expert Must-Know

Dropout rates: Dense layers: p=0.5. Convolutional layers: p=0.1-0.2. Input layer: p=0.1-0.2. Too much dropout causes underfitting. Too little causes overfitting.
Monte Carlo Dropout: Apply dropout at INFERENCE time with multiple forward passes, get different predictions, use variance as uncertainty estimate. Simple Bayesian deep learning with zero architecture changes.
Dropout plus BatchNorm equals problematic: Dropout causes variance mismatch between train and inference for BN statistics. Either don't use both, or apply dropout AFTER BN.

Attention Mechanism

Let every position in a sequence directly attend to every other — the foundation of Transformers and modern LLMs.

Scaled Dot-Product Attention
Attention(Q,K,V) = softmax(QKᵀ / √dₖ) · V
Q=queries, K=keys, V=values. Scale by √dₖ prevents softmax saturation. Output = weighted sum of values.

Self-AttentionMulti-Head O(n²) complexityFoundation of Transformers
Theory & Math Deep-Dive▼

Intuition

Each position in a sequence can "look at" every other position directly. The mechanism: each token creates three vectors, a Query ("what am I looking for?"), a Key ("what do I contain?"), a Value ("what do I contribute?"). Attention score = how well my Query matches your Key. Final output = weighted sum of all Values.

The Search Engine Analogy

Query = your search terms. Keys = document titles. Values = document content. Attention scores = relevance scores. Output = weighted summary of relevant documents. Unlike a database, queries, keys, and values are all learned from data.

The Math

Scaled Dot-Product Attention
Attention(Q,K,V) = softmax(Q K^T / sqrt(dk)) * V
Scale factor prevents dot products from growing large, which would cause a very peaked softmax and vanishing gradients. Complexity is quadratic in sequence length.
Multi-Head Attention
Project Q,K,V into several subspaces (heads), compute attention in each, concatenate results
Each head can specialise: one attends to syntax, another to semantics, another to position. Critical for Transformer performance.

Expert Must-Know

Positional encoding: Self-attention is permutation-invariant. Without positional info, word order is lost. Add sinusoidal or learned position embeddings before attention.
Linear attention: The quadratic bottleneck blocks very long sequences. Flash Attention achieves the same result with far less memory by tiling computation.
Cross-attention vs Self-attention: Self-attention: Q,K,V all from the same sequence. Cross-attention: Q from decoder, K,V from encoder. This is how the decoder reads the encoder in translation models.

Feature Selection

Remove irrelevant and redundant features to reduce overfitting, speed up training, and improve model interpretability.

Compare three feature selection strategies
📊

Filter Methods

Score features independently of model. Chi-squared, mutual information, correlation. Fast but ignores feature interactions.

🔄

Wrapper Methods

Use model performance to evaluate subsets. RFE, forward/backward selection. Accurate but computationally expensive.

🧮

Embedded Methods

Feature selection during model training. Lasso (L1), tree importance. Best of both worlds — fast and model-aware.

Theory & Math Deep-Dive▼

Intuition

Not all features are useful. Irrelevant features add noise, increase computation, and worsen generalisation. Feature selection identifies which features carry useful signal for predicting the target.

The Math

Mutual Information (filter method)
I(X;Y) = H(Y) - H(Y|X)
How much does knowing X reduce uncertainty about Y? I=0 means X and Y are independent (useless feature). Unlike correlation, captures non-linear relationships.
LASSO path (embedded method)
As lambda decreases from infinity, features enter the model one by one in order of importance
The LARS algorithm computes the full LASSO regularisation path efficiently. The order features enter the path reveals their relative importance.

Expert Must-Know

Permutation importance (most reliable): After fitting a model, randomly shuffle one feature column at a time. Measure performance drop. Model-agnostic, no bias toward high-cardinality features.
Recursive Feature Elimination (RFE): Fit model, remove weakest feature, refit, repeat. Computationally expensive but considers feature interactions. Prefer RFECV with cross-validation.

SHAP Values

Explain any model's predictions using Shapley values from game theory — the only attribution method with theoretical guarantees.

Shapley Value
φᵢ = Σ_{S⊆F\{i}} |S|!(|F|−|S|−1)!/|F|! · [f(S∪{i}) − f(S)]
Average marginal contribution of feature i across all possible feature coalitions S.
See how each feature pushes the prediction up or down
Theory & Math Deep-Dive▼

Intuition

SHAP explains INDIVIDUAL predictions: "for THIS specific patient, why did the model predict high risk?" It answers by asking: how much did each feature change the prediction compared to the average prediction (baseline)?

Game Theory Basis

Imagine features as players in a cooperative game where the "payout" is the model's prediction. Shapley value = fair share for each player, the average marginal contribution of each player across all possible teams (all subsets of features).

The Math

Shapley value, exact formula
phi_i = average marginal contribution of feature i across all possible feature subsets
For many features, this requires evaluating the model on an exponential number of subsets. In practice, approximate with TreeSHAP (exact for trees), KernelSHAP (model-agnostic), or DeepSHAP (for NNs).
Shapley axioms, why it's the ONLY fair attribution
(1) Efficiency: attributions sum to prediction minus baseline (2) Dummy: unused feature gets zero attribution (3) Symmetry: equal contributors get equal attribution (4) Additivity: attributions for combined models add up correctly

Expert Must-Know

SHAP vs LIME: LIME locally approximates the model with a linear surrogate. SHAP has theoretically grounded axioms and global consistency. SHAP is almost always preferred.
SHAP interaction values: How much do two features interact in their contribution? Only TreeSHAP computes these exactly. Identifies synergistic and antagonistic feature pairs.

Class Imbalance

When classes are skewed (e.g. 95% negative, 5% positive), a naive model just predicts majority class and looks "accurate".

SMOTE — Synthetic Minority Over-sampling
x_new = x_i + λ · (x_nn − x_i), λ ~ Uniform(0,1)
x_nn = a random k-nearest neighbor of x_i. Interpolates in feature space to create realistic synthetic samples.
Ratio: 10% Highly imbalanced dataset — apply resampling
Theory & Math Deep-Dive▼

Intuition

When 95% of data is class 0 and 5% is class 1, a model that always predicts class 0 achieves 95% accuracy but is useless. The model needs to be explicitly told that minority-class errors cost more, or given more minority examples to learn from.

The Math

SMOTE, Synthetic Minority Over-sampling Technique
x_new = xi + lambda*(x_neighbor - xi), where lambda is random between 0 and 1
Generates synthetic samples along line segments between minority-class points and their nearest neighbours. Creates realistic-looking samples rather than just duplicating.
Class-weighted loss
Minority class gets a higher weight in the loss function
Gradients from minority errors are scaled up, model learns to prioritise them. Equivalent effect to oversampling, computationally cheaper.
Focal Loss
FL = -(1-pt)^gamma * log(pt)
Downweights easy examples more than hard ones. The model automatically focuses on misclassified examples without resampling. State of the art for object detection.

Expert Must-Know

Never oversample before cross-validation: SMOTE on the full training set before CV leaks information. Always resample INSIDE the CV loop.
Threshold adjustment: Often the simplest fix. Instead of 0.5, use the threshold that maximises F1 or satisfies your precision-recall trade-off. No resampling needed.

Gaussian Processes

A non-parametric Bayesian model that places a prior over functions — giving a posterior distribution (mean + uncertainty) after observing data.

GP Posterior
μ(x*) = k(x*,X) · K⁻¹ · y
σ²(x*) = k(x*,x*) − k(x*,X) · K⁻¹ · k(X,x*)
k = RBF kernel: exp(−||x−x'||²/2l²). More data → tighter uncertainty bands.
Length scale: 0.20 Click on the canvas to add observations — watch uncertainty shrink
Theory & Math Deep-Dive▼

Intuition

A GP is a probability distribution OVER FUNCTIONS. Before seeing any data, you have a "prior", a belief about what functions look like (e.g. smooth, wiggly). After seeing data points, your "posterior" is updated, the function must pass near those points, and uncertainty is reduced near observations.

Weather Analogy

You know the temperature at 3 weather stations. Between stations, you're uncertain, but nearby stations constrain your estimate. Far from any station, uncertainty is high. Near a station, uncertainty is low. The covariance function (kernel) encodes how quickly correlation decays with distance.

The Math

GP prior and posterior
f follows a GP prior with mean function and covariance kernel After observing data, f follows a GP posterior with updated mean and covariance
RBF (Squared Exponential) Kernel
k(x,x') = sigma_f^2 * exp(-||x-x'||^2 / 2*l^2)
sigma_f^2 is output variance. l is length scale, controls smoothness. Large l means very smooth functions; small l means wiggly functions. Both are learned by maximising the marginal likelihood.

Expert Must-Know

Hyperparameter learning: Maximise the marginal likelihood w.r.t. kernel hyperparameters using gradient ascent. This automatically finds the right length scale and noise level from data, no cross-validation needed.
GP for Bayesian optimisation: The standard surrogate in BO is a GP because it gives both a prediction (mean) and uncertainty (variance) at every point, exactly what acquisition functions need.

Theory & Math Deep-Dive▼

Intuition

Time series data has temporal order, the future can't influence the past. This breaks standard ML assumptions: you can't randomly shuffle rows, you can't use future values as features, and you must validate in chronological order.

The Math

Stationarity (key requirement)
Weak stationarity: constant mean over time, and covariance depends only on the lag, not on the actual time

Transformers End-to-End

The full encoder-decoder architecture behind translation, summarisation, and every modern LLM — self-attention, cross-attention, and feed-forward blocks stacked into a pipeline.

Full Transformer Block
x = x + MultiHeadAttn(LN(x))
x = x + FFN(LN(x))
LN = Layer Norm. Residual connections around both sub-layers. FFN = two linear layers with a non-linearity (usually GELU) in between, expanding to 4x the model dimension and back.
Encode the source sentence, then decode token by token
Encoder: bidirectionalDecoder: causal mask Cross-Attention bridges themAutoregressive generation
Theory & Math Deep-Dive▼

Intuition

The Transformer has two halves. The Encoder reads the entire source sentence at once and builds a rich representation of it (it can look both forward and backward — bidirectional). The Decoder generates the output one token at a time, only allowed to look at tokens it has already generated (causal/masked), while also peeking at the encoder's representation via cross-attention.

The Translator Analogy

Imagine a human translator. First they read the WHOLE source sentence to understand it fully (encoder, bidirectional). Then they write the translation one word at a time, only knowing the words they've already written so far (decoder, causal), while constantly glancing back at the original sentence for reference (cross-attention).

The Math

1
Encoder: self-attention with NO mask, sees the full sequence
Every encoder token can attend to every other encoder token, in both directions. Output: a contextualised representation for each source token.
2
Decoder self-attention: causal mask sets attention score to -infinity for future positions
Before applying softmax, future positions get -infinity so their attention weight becomes exactly 0 after softmax. This prevents the decoder from "cheating" by looking at words it hasn't generated yet.
3
Cross-attention: Query from decoder, Key and Value from encoder output
This is how the decoder "reads" the source sentence while generating. Each decoder position asks: "which source words are relevant to generating my next word?"
4
Output: softmax over vocabulary, pick highest probability token (or sample)
The final linear layer projects the decoder's hidden state to vocabulary size. Greedy decoding picks the argmax each step; beam search keeps multiple candidate sequences for better quality.

Expert Must-Know

Encoder-only vs Decoder-only vs Encoder-Decoder: BERT is encoder-only (great for understanding tasks: classification, NER). GPT is decoder-only (great for generation, uses causal masking throughout). T5/original Transformer is encoder-decoder (great for sequence-to-sequence: translation, summarisation).
Why GPT-style models dominate now: Decoder-only models can be trained with a single simple objective (predict next token) on massive unlabelled text, and the same architecture does both understanding AND generation. This simplicity scales better than encoder-decoder setups.
KV-cache for fast inference: During autoregressive generation, recompute only the new token's Query, but cache Keys and Values from all previous tokens. This avoids redundant computation — the single biggest practical speedup for LLM serving.
Teacher forcing during training: Feed the TRUE previous tokens (not the model's own predictions) as decoder input during training, so all positions can be computed in parallel. At inference, you must use the model's own predictions step by step (no ground truth available) — this train/inference mismatch is called "exposure bias."
CH.38

Diffusion Models

Gradually destroy an image with noise, then train a network to reverse the process one small step at a time — generating new images by denoising from pure noise.

Forward Process (fixed, adds noise)
x_t = sqrt(alpha_t)·x_0 + sqrt(1-alpha_t)·epsilon,   epsilon~N(0,I)
Reverse Process (learned, removes noise)
x_{t-1} = (1/sqrt(a_t))·(x_t − (1−a_t)/sqrt(1−ābar_t)·epsilon_theta(x_t,t)) + noise
epsilon_theta = neural network trained to predict the noise that was added. Sampling = repeatedly removing predicted noise, walking from pure static to a coherent image.
Watch a simple pattern destroyed by noise, then reconstructed
Theory & Math Deep-Dive▼

Intuition

Imagine slowly adding static to a photograph until it's pure noise — that's easy, you can do it in one formula. Diffusion models train a neural network to do the REVERSE: given a noisy image, predict what noise was added, then subtract a small amount of it. Repeat this hundreds of times starting from pure random noise, and you arrive at a brand new, coherent image.

The Sculptor Analogy

A sculptor starts with a rough block of marble (pure noise) and removes material bit by bit, guided by a mental image of the final statue. Each small chip removed (denoising step) reveals more of the final form. The "mental image" is the model's learned understanding of what real images look like.

The Math

1
Forward (fixed): x_t = sqrt(abar_t)*x_0 + sqrt(1-abar_t)*epsilon
abar_t = product of noise schedule up to step t, shrinking from 1 to near 0. At t=0: pure image. At t=T: pure noise. This formula lets us jump DIRECTLY to any noise level without simulating every intermediate step — crucial for efficient training.
2
Training objective: minimise ||epsilon − epsilon_theta(x_t, t)||^2
Pick a random timestep t and a random noise sample, create the noisy image, then train the network to predict exactly that noise. Remarkably simple loss — just MSE between true and predicted noise.
3
Reverse (learned): iteratively remove a small predicted amount of noise, T times
Starting from pure noise x_T, repeatedly: predict the noise, subtract a scaled portion of it, add a small amount of fresh random noise back (for stochasticity), and move to x_{t-1}. After T steps, arrive at a realistic image x_0.
Classifier-Free Guidance (text-to-image control)
epsilon_guided = epsilon_uncond + w*(epsilon_cond − epsilon_uncond)
Train the model both with and without the text conditioning. At sampling time, exaggerate the difference (w greater than 1) to push generation more strongly toward the text prompt. This is the "prompt adherence" knob in tools like Stable Diffusion.

Expert Must-Know

DDPM vs DDIM sampling: DDPM (original) needs many steps (often 1000) and is stochastic. DDIM reformulates sampling to be deterministic and allows skipping steps — 20-50 steps can produce comparable quality, the key speedup that made diffusion models practical for real-time-ish use.
Latent diffusion (Stable Diffusion): Running diffusion directly on pixel space is expensive. Instead, compress the image into a small latent space with a VAE encoder first, run the entire diffusion process there, then decode back to pixels. This is what made high-resolution image generation computationally feasible.
Why diffusion beats GANs for diversity: GANs can suffer from "mode collapse" (generating only a few types of outputs). Diffusion models, by directly modelling the data distribution through a stable likelihood-based objective, tend to capture the full diversity of the training distribution more reliably.
CH.39

Variational Autoencoders

Compress data into a smooth, structured latent space where every point decodes to something realistic — enabling generation by sampling new latent points.

Reparameterisation Trick
z = mu + sigma ⊙ epsilon,   epsilon~N(0,I)
Lets gradients flow through the sampling step. Encoder outputs mu and sigma (not z directly) — the randomness is isolated in epsilon, which has no parameters to learn.
ELBO Loss
L = Reconstruction Loss + KL( N(mu,sigma) ‖ N(0,I) )
Reconstruction term: decoder must rebuild the input accurately. KL term: latent distribution must stay close to a standard Gaussian — this keeps the latent space smooth and continuous.
Encode points into 2D latent space, then sample/interpolate
Theory & Math Deep-Dive▼

Intuition

A normal autoencoder compresses data to a single point in latent space and back. The problem: the latent space has "gaps" — most points you'd pick at random decode to garbage, because the encoder only ever needs to map training points to SOME location, with no constraint on how those locations are organised. A VAE instead encodes each input to a small CLOUD (a Gaussian distribution) rather than a point, and forces all these clouds to overlap and stay close to a standard normal distribution — this makes the latent space smooth and "fillable," so any random point you sample decodes to something realistic.

The Filing Cabinet Analogy

A normal autoencoder is like filing each document into one specific drawer slot — between slots, there's nothing. A VAE blurs each document across a small neighbourhood of drawers, and forces all neighbourhoods to overlap throughout the whole cabinet. Now, reaching into ANY drawer (even ones with no exact training document) gives you something that resembles a real document.

The Math

1
Encoder outputs mu(x) and sigma(x) — the parameters of a Gaussian, not a point
Instead of "where is this point in latent space?", the encoder answers "what REGION of latent space does this point plausibly belong to?" mu = centre of the region, sigma = how spread out it is.
2
Reparameterisation: z = mu + sigma * epsilon, where epsilon ~ N(0,I)
We need to sample z from the Gaussian to feed into the decoder, but sampling is not differentiable — gradients can't flow through a random sampling operation. The trick: move the randomness into epsilon (which doesn't depend on any learnable parameter), so mu and sigma remain part of a normal differentiable computation graph.
3
Loss: Reconstruction term + KL(N(mu,sigma) || N(0,I))
Reconstruction term (usually MSE or cross-entropy) ensures the decoder can rebuild the input from z — it must carry real information. The KL term is a "leash" pulling every encoded distribution toward a standard normal — this is what prevents gaps from forming and keeps the whole latent space densely usable.
KL divergence for two Gaussians (closed form)
KL = 0.5 * sum( sigma^2 + mu^2 − 1 − log(sigma^2) )
This has an exact, simple closed-form expression when both distributions are Gaussian — no sampling or approximation needed to compute this part of the loss, which makes VAEs efficient to train.

Expert Must-Know

Posterior collapse: If the decoder is powerful enough, it can learn to ignore z entirely and the encoder distribution collapses to match the prior exactly (KL term → 0) — the model becomes a poor generator because z carries no information. Mitigations: KL annealing (slowly ramp up the KL weight during training), or use a less powerful decoder.
Beta-VAE: Multiply the KL term by a weight beta greater than 1 to force more disentangled, interpretable latent dimensions — each dimension tends to capture one independent factor of variation (e.g. one dimension purely controls rotation, another purely controls colour). Trade-off: higher beta usually hurts reconstruction quality.
VAE vs GAN vs Diffusion for generation quality: VAEs tend to produce blurrier samples because MSE reconstruction loss averages over plausible outputs. GANs are sharper but less stable to train and less diverse. Diffusion models currently give the best combination of sample quality and diversity, at the cost of slow (multi-step) sampling.

Graph Neural Networks

Extend neural networks to graph-structured data — each node updates its representation by aggregating information from its neighbours, layer after layer.

Message Passing (GCN layer)
h_v^(l+1) = sigma( W · AGGREGATE({h_u^(l) : u in N(v)} ∪ {h_v^(l)}) )
N(v) = neighbours of node v. AGGREGATE is typically mean or sum. Each layer lets information travel one hop further — after L layers, a node "sees" its L-hop neighbourhood.

Theory & Math Deep-Dive▼

Intuition

Some data isn't a neat grid (images) or sequence (text) — it's a network of connected entities: social networks, molecules, road maps, citation networks. A GNN lets every node "talk to" its neighbours and update its own representation based on what it hears. Stack several layers, and information ripples outward — after 2 layers, a node knows about its neighbours' neighbours, without ever needing a fixed input size or ordering.

The Gossip Analogy

Imagine everyone at a party only talks to people standing next to them. After one round of conversation, you know a bit about your immediate neighbours. After two rounds, since your neighbours already talked to THEIR neighbours, you indirectly learn about people two people away. Each "round" is one GNN layer.

The Math

1
Aggregate: m_v = AGGREGATE({h_u : u in neighbours of v})
Collect feature vectors from all neighbouring nodes. AGGREGATE must be a function that gives the same result regardless of neighbour ORDER (permutation invariant) — mean, sum, and max are the common choices.
2
Update: h_v^(new) = sigma(W * [h_v^(old), m_v])
Combine the node's own previous representation with the aggregated neighbour message, pass through a learned weight matrix and activation. This is structurally similar to a normal neural network layer — the difference is WHAT gets fed in (a variable-size, unordered set of neighbours).
3
GAT (Graph Attention): weight each neighbour's message by a learned attention score
Instead of treating every neighbour equally (plain mean), GAT learns which neighbours matter more for a given node — analogous to self-attention, but restricted to actual graph edges rather than all pairs.
Over-smoothing (a key failure mode)
As layers L → large, all node representations converge toward the same value
With too many message-passing layers, information from far-away nodes dilutes everything into an indistinguishable average — similar in spirit to how a very deep CNN without skip connections degrades. Most practical GNNs use only 2-4 layers.

Expert Must-Know

Transductive vs Inductive: Transductive GNNs (original GCN) are trained on a fixed graph and can't generalise to new, unseen nodes/graphs. GraphSAGE and GAT are inductive — they learn aggregation FUNCTIONS rather than fixed per-node parameters, so they generalise to entirely new graphs at inference time.
Graph-level tasks need pooling: For tasks like "predict if this molecule is toxic" (whole-graph prediction, not per-node), you need a readout/pooling step after message passing — sum, mean, or a learned attention-weighted pooling over all final node embeddings.
Scalability: Real-world graphs (social networks) can have billions of edges — loading the full neighbourhood for every node is infeasible. GraphSAGE samples a FIXED number of neighbours per node per layer, trading some accuracy for massive scalability.

Contrastive Learning (SimCLR / CLIP)

Learn representations by pulling similar pairs together and pushing dissimilar pairs apart in embedding space — no labels required, just pairs that "should" be similar.

InfoNCE Loss (SimCLR)
L = −log[ exp(sim(zi,zj)/τ) / Σk exp(sim(zi,zk)/τ) ]
zi,zj = embeddings of two augmented views of the SAME image (positive pair). zk ranges over all other images in the batch (negatives). τ = temperature, controls how peaked the distribution is.

Theory & Math Deep-Dive▼

Intuition

What if you could train a powerful image (or text) understanding model WITHOUT any labels at all? Contrastive learning's trick: take one image, create two different "views" of it (e.g. crop, rotate, change colours), and train the model to recognise that these two views are "the same thing" — while treating every other image in the batch as "a different thing." No human ever had to write a single label.

The Fingerprint Analogy

Imagine you're learning to recognise people by their handwriting alone, without names. You're shown two samples from the SAME person (maybe written on different days) and many samples from OTHER people. You learn to pull the same person's samples close together in your mental "handwriting space" and push different people's samples apart — purely from the structure of "same vs different," never from explicit names.

The Math

1
Create two augmented views of the same image: x_i and x_j
Apply random crop, colour jitter, blur, flip. The model should learn representations that are invariant to these — a cat is still a cat whether cropped, rotated, or recoloured slightly.
2
Encode both views: z_i = f(x_i), z_j = f(x_j), normalise to unit length
f is typically a CNN or Vision Transformer followed by a small projection head. Normalising to unit vectors means similarity reduces to cosine similarity — just the angle between vectors matters, not magnitude.
3
InfoNCE loss: −log[ exp(sim(zi,zj)/tau) / sum_k exp(sim(zi,zk)/tau) ]
This is literally a softmax classification loss where the "correct class" is the positive pair (zj) among all other samples in the batch (negatives, zk). Minimising it directly increases similarity with the true positive and decreases similarity with everything else simultaneously.
CLIP — cross-modal contrastive learning
Positive pair = (image, its caption). Negative = (image, any other caption in the batch)
Same InfoNCE-style loss, but now between two DIFFERENT modalities (image encoder and text encoder) instead of two augmented views of one image. After training on hundreds of millions of image-caption pairs scraped from the web, CLIP can classify images into ANY category just by comparing to a text description — zero-shot classification without ever being trained on those specific labels.

Expert Must-Know

Batch size matters enormously: More negatives per batch means a harder, more informative contrastive task. SimCLR showed clear performance gains scaling batch size into the thousands; MoCo solves the same problem more memory-efficiently using a momentum-updated queue of past negatives instead of requiring a literally huge batch.
Temperature (tau) controls hardness: Low tau makes the softmax very peaked — the loss focuses almost entirely on the hardest negative (the one most similar to the positive). Too low can destabilise training; too high gives a weak, uninformative gradient signal.
Why this matters for foundation models: Contrastive pretraining (SimCLR for vision, CLIP for vision-language) produces representations that transfer remarkably well to downstream tasks with very little labelled fine-tuning data — this is precisely the mechanism behind modern "foundation models" that power zero-shot and few-shot capabilities.

Reinforcement Learning

An agent learns by trial and error — taking actions, observing rewards, and updating its strategy to maximise long-term cumulative reward.

Q-Learning Update
Q(s,a) ← Q(s,a) + α[ r + γ·max_a' Q(s',a') − Q(s,a) ]
Q(s,a) = expected future reward from taking action a in state s. The bracket is the "TD error" — the difference between what we expected and what we observed plus the best future estimate.
Policy Gradient (REINFORCE)
∇J(theta) = E[ ∇log(pi_theta(a|s)) · G_t ]
Increase the probability of actions that led to high return G_t, decrease probability of actions that led to low return. Directly optimises the policy instead of a value function.

Intuition

An agent doesn't have a dataset of "correct answers" — it has to DISCOVER good behaviour by trying actions and observing rewards. Q-learning keeps a table (or function) estimating "how good is it to take action A in state S, considering all future rewards too?" Policy gradient methods skip the value-estimation step entirely and directly adjust the probability of taking good actions.

The Maze-Learning Analogy

Imagine learning a maze blindfolded by trial and error. Q-learning: you keep a notebook scoring "how good is each possible move from each position I've been in," updating scores as you learn whether choices led somewhere good. Policy gradient: no notebook — you just remember "last time I turned left here and it worked out well, I'll be more likely to turn left here again."

The Math

1
Bellman equation: Q*(s,a) = E[ r + gamma*max_a' Q*(s',a') ]
The optimal Q-value of taking action a in state s equals the immediate reward plus the discounted value of the BEST possible action from whatever state you land in next. This recursive structure is what makes Q-learning solvable through repeated updates.
2
Q-learning update: Q(s,a) ← Q(s,a) + alpha*[r + gamma*max_a' Q(s',a') − Q(s,a)]
The bracketed term is the "TD error" — the gap between your current estimate Q(s,a) and a better estimate built from the observed reward plus your best guess about the future. Nudge your old estimate toward the new, better-informed one by a small learning rate alpha.
3
Epsilon-greedy exploration: with probability epsilon take a random action, otherwise take argmax_a Q(s,a)
Pure greedy action selection gets stuck exploiting the first decent strategy found and never discovers better ones. Epsilon-greedy forces ongoing random exploration, typically decaying epsilon over time as the agent's estimates become more trustworthy.
4
Policy Gradient: grad J(theta) = E[ grad log(pi_theta(a|s)) * G_t ]
G_t = the actual observed return (sum of future discounted rewards) following action a. If G_t was large (good outcome), increase the log-probability of having taken that action; if G_t was small or negative, decrease it. This directly optimises the POLICY, with no value table required.
Actor-Critic — combining both ideas
Use a learned value function V(s) (the "critic") as a baseline to reduce variance in the policy gradient (the "actor")
Pure policy gradient (REINFORCE) has very high variance because raw returns are noisy. Subtracting a baseline V(s) — replacing G_t with the "advantage" A_t = G_t − V(s) — dramatically stabilises training while keeping the gradient unbiased. This is the foundation of modern RL algorithms like A3C and PPO.

Expert Must-Know

On-policy vs Off-policy: Q-learning is off-policy — it learns about the OPTIMAL policy (the max_a' term) regardless of what action the agent actually took during exploration, so old experience can be reused (experience replay). Vanilla policy gradient is on-policy — it can only learn from data generated by the CURRENT policy, making it more sample-inefficient.
Deep Q-Networks (DQN): Replace the Q-table with a neural network for huge/continuous state spaces (e.g. raw pixels from an Atari game). Key stabilisation tricks: experience replay buffer (break correlation between consecutive samples) and a separate, slowly-updated target network (prevents the "moving target" problem of bootstrapping off your own rapidly-changing estimates).
PPO (Proximal Policy Optimisation): The current industry-standard policy gradient method (used to train ChatGPT-style models via RLHF). Clips the policy update so it can't change too drastically in one step — directly addressing the instability that plagued earlier policy gradient methods, while remaining simple to implement.
