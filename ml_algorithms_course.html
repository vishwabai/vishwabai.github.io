CHAPTER 0

How data becomes a model

Before any algorithm, one idea: a model is a function with knobs (parameters), and learning is turning those knobs to make the function's output match reality as closely as some loss allows.

The one idea underneath everything

Pick a function shape f(x; θ) — a line, a curve, a set of if/else splits, a distance rule. It has adjustable numbers θ inside it. Define a loss L(θ) that scores how wrong f currently is on your data. Then search for the θ that makes L smallest. That's the whole game — every chapter below is just a different choice of f and L, and a different way of doing the searching.

CHAPTER 1

Cleaning & preprocessing data

Every algorithm downstream silently assumes the data was prepared a certain way. Get this chapter wrong and no amount of algorithm sophistication saves you.

"Preprocessing is just busywork before the real ML starts." In practice, preprocessing decisions — how you scale, how you fill gaps, how you encode categories — change which minimum an optimizer finds, sometimes more than the choice of algorithm does.

1.1 Missing values

Mean / median imputation

x̂i = 1n Σj=1n xj   (mean)   or   x̂i = median(x1…xn)

Mean imputation is pulled toward outliers; median is not. Neither adds real information — both shrink variance and can bias any model that reads variance as signal (e.g. regression coefficients).

Interactive — imputation strategy vs. distribution shape

A dataset with missing values (shown as gaps on the axis). Toggle the imputation strategy and watch how the reconstructed histogram — and its variance — changes.

1.2 Feature scaling

Standardization (z-score)

z = x − μσ

Centers to mean 0, scales to std 1. Assumes roughly Gaussian-shaped data; robust choice for algorithms that rely on distances or gradients (linear/logistic regression, k-NN, PCA, SVM).

Min-max normalization

x′ = x − min(x)max(x) − min(x)

Squashes into [0,1]. Sensitive to outliers (a single extreme value compresses everything else into a tiny sub-range) — check for outliers first.

1.3 Encoding categorical variables

One-hot vs. ordinal encoding

Ordinal encoding maps categories to integers (Red=0, Green=1, Blue=2) — this silently tells the model Blue > Green > Red, which is meaningless for unordered categories. One-hot encoding instead creates a binary column per category:

Red → [1,0,0]   Green → [0,1,0]   Blue → [0,0,1]

Trade-off: one-hot avoids inventing false ordinal structure, but adds one dimension per category — with high-cardinality categories (e.g. zip codes) this explodes the feature space.

1.4 Outlier detection

Z-score rule

|zi| = |xi − μ|σ > 3 ⇒ outlier

IQR rule

xi < Q1 − 1.5·IQR  or  xi > Q3 + 1.5·IQR

IQR = Q3 − Q1. Robust to outliers itself, unlike the z-score rule (μ and σ are themselves dragged by outliers).

1.5 Train/test split & leakage

"I'll scale the whole dataset, then split into train/test." This leaks test-set statistics (its mean, its min/max) into training — the model gets information it wouldn't have at real deployment time. Correct order: split first → fit the scaler (compute μ, σ) on train only → apply that same transform to test.

fit: μ, σ ← train   →   transform: ztrain, ztest both use train's μ, σ

CHAPTER 2

Linear regression

The simplest possible f: a straight line. Everything about optimization shows up here first, in a form you can see.

Model & loss

ŷ = θ₀ + θ₁x
J(θ₀,θ₁) = 12n Σi=1n (ŷi − yi)²

Mean Squared Error. Squaring punishes large errors disproportionately and keeps J smooth and differentiable everywhere — essential for gradient descent.

Gradient descent update

θⱼ ← θⱼ − α ∂J∂θⱼ
∂J∂θ₀ = 1n Σ(ŷᵢ−yᵢ)     ∂J∂θ₁ = 1n Σ(ŷᵢ−yᵢ)xᵢ

α is the learning rate. Too small → slow crawl. Too large → overshoot / diverge, exactly as in Chapter 0.

Two ways to see it

Physical: the loss surface is a bowl; θ is a ball; gradient descent is gravity plus friction (α controls the friction/step size).
Geometric: at the true minimum, the residual errors are uncorrelated with x — the line has "absorbed" all the linear signal there is to absorb, leaving only noise.

Closed form: the Normal Equation

θ = (XᵀX)−1 Xᵀy

For linear regression the minimum has an exact algebraic solution — no iteration needed. But XᵀX inversion is O(d³) in the number of features d, so gradient descent wins when d is large (many features).

CHAPTER 3

Logistic regression

Same linear core as Chapter 2, but squashed through a curve so the output is a probability, and paired with a loss that specifically punishes confident wrongness.

The sigmoid

σ(z) = 11 + e−z    z = θ₀ + θ₁x

Maps any real number to (0,1). z=0 → 0.5; large positive z → near 1; large negative z → near 0. The decision boundary is simply where z = 0.

Binary cross-entropy loss

J(θ) = −1n Σ [ yᵢ log(ŷᵢ) + (1−yᵢ) log(1−ŷᵢ) ]

If the true label is 1 and the model predicts ŷ→0, log(ŷ)→−∞ — the loss explodes. This is deliberate: it punishes confident-and-wrong predictions far more than MSE would.

"Logistic regression is a classification tree in disguise." It's not — it produces one smooth linear boundary (a straight line/plane), not the axis-aligned rectangular regions that trees produce (Chapter 5). If classes aren't linearly separable, logistic regression will underfit no matter how much data you add.

CHAPTER 4

k-Nearest Neighbors

No training phase, no parameters to fit — just a distance function and a vote. The entire "model" is the dataset itself.

Euclidean distance & the vote

d(a,b) = √( Σj=1d (aⱼ − bⱼ)² )

Find the k training points with smallest d to the query point; predict the majority class among them (classification) or their average y (regression).

Interactive — vote among the k nearest

Move your mouse over the canvas — the k nearest labeled points get highlighted and connected, and the predicted class for that location is shown.

Hover the canvas to classify a point.

Two ways to see it

Physical: ask your k closest neighbors what they'd do, then do the majority answer.
Geometric: as k→1, the decision regions become a Voronoi diagram (every point owned by its single nearest neighbor) — jagged and overfit. As k→n, the boundary flattens toward always predicting the majority class overall — underfit.

"k-NN has no hyperparameters since there's no training." k itself is a hyperparameter, and — critically — k-NN is extremely sensitive to feature scale (Chapter 1.2): an unscaled feature with a huge numeric range will dominate the distance calculation and silently drown out every other feature.

CHAPTER 5

Decision trees

Instead of one global equation, a tree asks a sequence of yes/no questions, each chosen to make the resulting groups as "pure" as possible.

Entropy & Gini impurity

H(S) = − Σc pᶜ log₂(pᶜ)     Gini(S) = 1 − Σc pᶜ²

Both measure how mixed a group's labels are. H=0 (or Gini=0) means perfectly pure (one class only). Both peak when classes are 50/50.

Information gain

IG = H(parent) − Σk |Sₖ||S| H(Sₖ)

At each node, the tree tries every possible split threshold on every feature, and picks whichever split maximizes information gain — the biggest drop in weighted impurity.

"A deeper tree is always a better tree." An unconstrained tree keeps splitting until every leaf is pure — including leaves that isolate a single noisy outlier. That's memorization, not learning: the tree overfits, which is why max depth, min samples per leaf, or pruning are essential in practice.

CHAPTER 6

k-Means clustering

The first unsupervised algorithm in this course — there are no labels, only a claim that the data has k natural groups, and an alternating optimization to find them.

Objective & the two-step loop

J = Σi=1n ‖xᵢ − μc(i)‖²

Minimize total squared distance from each point to its assigned centroid. There's no closed form — instead, alternate:

1. Assign: c(i) = argmink ‖xᵢ − μk‖²    2. Update: μk = mean of points assigned to k

"k-Means finds THE correct clusters." It converges to a local minimum of J, and which one depends on the random centroid initialization — run it a few times with different seeds and compare J; k itself also has to be chosen, often via the "elbow" in J vs k.

CHAPTER 7

Principal Component Analysis

Not a predictor at all — a change of viewpoint. PCA finds the rotation of the axes under which the data's spread is easiest to describe with the fewest numbers.

Covariance & eigenvectors

Σ = 1n XᵀcXc    (Xc = X mean-centered)

The principal components are the eigenvectors of the covariance matrix Σ; their eigenvalues are the variance captured along each. The first principal component points along the direction of maximum spread.

Interactive — rotate to find maximum spread

Two ways to see it

Physical: shine a flashlight through the cloud of points onto a wall and rotate the light — PCA is the angle where the shadow is longest.
Geometric: it's a rotation of the coordinate system so the new axes are uncorrelated and sorted by how much variance each one explains.

CHAPTER 8

Naive Bayes

A fully probabilistic classifier built from one theorem and one — deliberately naive — simplifying assumption.

Bayes' theorem

P(y|x) = P(x|y) P(y)P(x)

To classify, compare P(y=1|x) against P(y=0|x); since P(x) is the same for both, just compare the numerators.

The "naive" independence assumption

P(x₁,…,xd|y) = Πj=1d P(xⱼ|y)

Treats every feature as conditionally independent given the class — almost never exactly true, but it turns an intractable joint distribution into a product of easy 1-D ones, and works surprisingly well in practice (spam filtering is the classic example).

Gaussian Naive Bayes

P(xⱼ|y) = 1√(2πσy²) exp(−(xⱼ − μy)²2σy²)

For continuous features, model each class's feature distribution as a Gaussian fit from the training data, then plug into the product above.

CHAPTER 9

Evaluating models

A model is only as good as the number you use to judge it. Accuracy alone lies constantly — here's what to use instead.

Confusion matrix

TP · FP
FN · TN

TP = predicted positive, actually positive. FP = predicted positive, actually negative ("false alarm"). FN = predicted negative, actually positive ("missed it"). TN = correctly negative.

Precision & recall

Precision = TPTP+FP
Recall = TPTP+FN

F1 score

F1 = 2 · Precision · RecallPrecision + Recall

The harmonic mean — punishes the case where one of the two is very low, unlike a plain average.

Interactive — threshold, confusion matrix, and the ROC curve

A fixed set of scored predictions. Slide the classification threshold and watch TP/FP/FN/TN update live, along with your current point on the ROC curve.

"95% accuracy means a great model." If 95% of a dataset is the negative class, a model that always predicts "negative" scores 95% accuracy while catching zero positives — this is exactly why precision, recall, and the ROC/AUC exist: they surface performance imbalance that raw accuracy hides.

Where this leaves you

Every chapter followed the same pattern: choose a function shape, choose a loss that reflects what you actually care about, and optimize. Preprocessing decides what the model even sees; evaluation decides whether you can trust what it tells you. Everything else — random forests, gradient boosting, neural networks — builds on exactly these same pieces, just composed more elaborately.
