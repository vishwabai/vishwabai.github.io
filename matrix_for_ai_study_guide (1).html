Eigenvalues & Eigenvectors Key
1
Definition
For matrix A, a vector v is an eigenvector if Av = λv. Multiplying by A only stretches v by scalar λ (the eigenvalue) — direction unchanged.
2
Why AI cares
PCA uses eigenvectors to find directions of maximum variance. The largest eigenvalue → the most informative direction in your data.
3
Solving
Eigenvalues satisfy: det(A − λI) = 0. The characteristic polynomial. For 2×2: λ² − tr(A)λ + det(A) = 0.
4
Spectral radius
ρ(A) = max|λᵢ|. In RNNs, if ρ > 1 → gradients explode. If ρ < 1 → gradients vanish. The root of the vanishing gradient problem.
04 — Factorisation

Matrix Decomposition

Decompose matrices into simpler parts to reveal structure, reduce dimensionality, and solve systems.

Singular Value Decomposition (SVD) Foundation of PCA

Every matrix A = U Σ Vᵀ. U and V are orthogonal (rotations). Σ is diagonal (stretches). SVD is the Swiss army knife of linear algebra.

A = U Σ Vᵀ -- U: left singular vectors (m×m orthogonal) -- Σ: singular values (m×n diagonal, σ₁≥σ₂≥…≥0) -- Vᵀ: right singular vectors (n×n orthogonal) -- Rank-k approximation (low-rank compression): Aₖ = U[:, :k] · Σ[:k, :k] · Vᵀ[:k, :]
Applications in AI
  • 📐 PCA — principal component analysis
  • 🗜 Model compression — LoRA uses low-rank SVD
  • 🔍 Recommender systems — collaborative filtering
  • 🧹 Noise removal from data
LoRA Connection
-- Instead of updating W ∈ ℝ^(d×d): ΔW = A · B -- A ∈ ℝ^(d×r), B ∈ ℝ^(r×d), r≪d -- Saves ~99% of parameters
LU Decomposition Ax = b

A = LU where L is lower-triangular and U is upper-triangular. Solves linear systems efficiently. Used in batch normalisation stat computation.

Ax = b → L(Ux) = b → solve Ly=b, then Ux=y -- O(n³) factorisation, O(n²) solves
QR Decomposition Stable

A = QR where Q is orthogonal (Qᵀ=Q⁻¹) and R is upper-triangular. Numerically stable. Used in least-squares and eigenvalue algorithms.

A = QR QᵀQ = I -- orthonormal cols -- least squares: x = R⁻¹Qᵀb
Determinant, Rank & Invertibility
det(A)
Volume scaling factor. det = 0 → singular (non-invertible). For 2×2: ad−bc.
rank(A)
Number of linearly independent rows/cols. rank < min(m,n) → rank-deficient → info lost.
A⁻¹
Inverse exists iff det ≠ 0. AA⁻¹ = I. Rarely computed explicitly — solve Ax=b instead.
Pseudo-inverse A⁺
Moore-Penrose. Works even for non-square/singular. Used in least-squares regression.
05 — Calculus

Matrix Calculus & Gradients

Backpropagation is matrix calculus. The chain rule, Jacobians, and the gradient are how models learn.

Backpropagation: The Chain Rule How Models Learn

↑ Click to animate the backward pass

-- Forward: L = loss(Ŷ, Y), Ŷ = σ(XW + b) -- Backward (chain rule): ∂L/∂W = Xᵀ · ∂L/∂Z -- shape: (d×h) ∂L/∂b = sum(∂L/∂Z, axis=0) -- shape: (h,) ∂L/∂X = ∂L/∂Z · Wᵀ -- shape: (N×d) -- Gradient descent update: W ← W − α · ∂L/∂W
Jacobian ∂f/∂x

For f: ℝⁿ → ℝᵐ, the Jacobian J is the (m×n) matrix of all partial derivatives. It's the multi-dimensional derivative.

J[i,j] = ∂fᵢ/∂xⱼ -- In backprop: ∂L/∂x = Jᵀ ∂L/∂f -- Softmax Jacobian: δᵢⱼpᵢ - pᵢpⱼ
Hessian 2nd Order

Matrix of second-order partials. Tells you the curvature of the loss landscape. Powers second-order optimisers (Newton, K-FAC).

H[i,j] = ∂²L/∂wᵢ∂wⱼ -- Positive definite H → bowl shape -- Too expensive for large nets
Vector & Matrix Norms

Norms measure "size". Used in regularisation (L1, L2), gradient clipping, and convergence analysis.

L1 norm ‖x‖₁
Σ|xᵢ|
Sum of absolute values. Encourages sparsity (LASSO).
L2 norm ‖x‖₂
√Σxᵢ²
Euclidean length. Weight decay / Ridge regression.
Frobenius ‖A‖_F
√Σᵢⱼ Aᵢⱼ²
Matrix version of L2. Used in LoRA loss.
Spectral norm ‖A‖₂
σ_max(A)
Largest singular value. Spectral normalisation in GANs.

Softmax — The Final Layer Classification

Converts logit vector z into a probability distribution. Its Jacobian is the key to cross-entropy backprop.

softmax(z)ᵢ = exp(zᵢ) / Σⱼ exp(zⱼ) -- numerically stable version (subtract max): softmax(z)ᵢ = exp(zᵢ − max z) / Σⱼ exp(zⱼ − max z) -- Jacobian: ∂softmaxᵢ/∂zⱼ = softmaxᵢ(δᵢⱼ − softmaxⱼ)
07 — Statistics

Probability & Matrices

Statistical quantities live naturally in matrix form. Covariance, Gaussian distributions, and Markov chains are all matrix objects.

Covariance Matrix — Live Visualiser Statistics

The covariance matrix Σ = (1/n)XᵀX encodes how features vary together. It's symmetric and positive semi-definite. Click to regenerate data.

-- Zero-mean data X ∈ ℝ^(n×d): Σ = (1/n) Xᵀ X ∈ ℝd×d -- Properties: Σ = Σᵀ -- symmetric xᵀΣx ≥ 0 ∀x -- positive semi-definite Σ[i,i] = Var(xᵢ) -- diagonal = variances Σ[i,j] = Cov(xᵢ,xⱼ) -- off-diag = covariances
Multivariate Gaussian Distribution 𝒩(μ, Σ)

The backbone of Gaussian processes, VAEs, and normalising flows. The covariance matrix shapes the distribution ellipse.

p(x) = (2π)^(-d/2) |Σ|^(-1/2) exp(-½(x-μ)ᵀΣ⁻¹(x-μ)) -- (x-μ)ᵀΣ⁻¹(x-μ) = Mahalanobis distance² -- Σ diagonal → independent features -- Σ = I → standard normal (isotropic) -- In VAEs: encoder outputs μ and log(σ²)
Markov Chains & Transition Matrices Language Models

A Markov chain's state transitions are a stochastic matrix P where each row sums to 1. The stationary distribution π satisfies πP = π — an eigenvector problem.

↑ Click to step the chain forward

-- After k steps: P(state at k) = π₀ · Pᵏ -- Stationary dist: πP = π (left eigenvector, λ=1) -- PageRank is a Markov chain on the web graph -- N-gram LMs are Markov chains over vocabulary
Precision Matrix Σ⁻¹

The inverse covariance. Encodes conditional independence: Σ⁻¹[i,j]=0 iff xᵢ⊥xⱼ | rest. Foundation of Gaussian graphical models.

Λ = Σ⁻¹ Λ[i,j] = 0 ↔ xᵢ ⊥ xⱼ | others -- Sparse Λ = sparse graph structure
Information Matrix Fisher

𝓕 = E[∇logp · ∇logpᵀ]. Measures how much data informs parameters. Used in natural gradient descent and Cramér-Rao bound.

𝓕[i,j] = -E[∂²logp/∂θᵢ∂θⱼ] -- Natural gradient: θ ← θ - α𝓕⁻¹∇L -- Better conditioned than vanilla GD
08 — Training

Optimisation & Matrix Geometry

Every optimiser — SGD, Adam, AdaGrad — manipulates matrices of gradients. Understanding their geometry explains why they work.

Loss Landscape — Gradient Descent Paths Interactive

Click anywhere on the loss surface to start gradient descent. Compare how SGD, Momentum, and Adam navigate the same landscape.

SGD: θ ← θ - α·∇L(θ) -- Simple. Sensitive to learning rate. Zigzags in ravines.
Optimiser Internals Matrix Form
SGD + Momentum
v ← βv + (1-β)∇L θ ← θ - αv
Accumulates velocity. Rolls through small minima. β≈0.9.
AdaGrad
G ← G + ∇L ⊙ ∇L θ ← θ - α/√(G+ε) ⊙ ∇L
G is a diagonal preconditioner. Adapts lr per param. Can stop early.
Adam
m ← β₁m+(1-β₁)∇L 1st moment v ← β₂v+(1-β₂)∇L² 2nd moment θ ← θ - αm̂/√(v̂+ε)
Combines momentum + adaptive lr. The default choice. β₁=0.9, β₂=0.999.
L-BFGS (2nd order)
θ ← θ - αH⁻¹∇L Hₖ ≈ via rank-2 updates
Approximates inverse Hessian without O(n²) cost. Used in full-batch settings.
Condition Number — Why Training Stalls Numerical Stability

κ(A) = σ_max / σ_min. A high condition number means gradient descent takes tiny steps in one direction and huge ones in another — the loss landscape is a narrow canyon.

κ(A) = ‖A‖‖A⁻¹‖ = σ_max / σ_min -- κ ≈ 1 → well-conditioned (sphere: easy) -- κ ≫ 1 → ill-conditioned (canyon: slow GD) -- Solutions: normalisation, preconditioning, Adam -- BatchNorm makes κ(Hessian) ≈ 1 for each layer
09 — Computation

Numerical Methods & Stability

Theory meets hardware. Floating-point arithmetic, iterative solvers, and numerical tricks are what separates textbook algebra from production ML.

Floating-Point Precision in AI FP16 / BF16 / FP32

Modern AI uses mixed precision. Matrix multiplications in FP16, accumulation in FP32. Understanding precision explains numerical instability, loss scaling, and why BF16 beats FP16 for training.

-- IEEE 754 floating-point formats: FP32: 1 sign | 8 exponent | 23 mantissa → range ±3.4×10³⁸ FP16: 1 sign | 5 exponent | 10 mantissa → range ±6.5×10⁴ (overflow risk!) BF16: 1 sign | 8 exponent | 7 mantissa → same range as FP32, less precision -- Mixed precision training (Micikevicius 2018): matmul(FP16, FP16) → accumulate in FP32 → store master weights FP32 -- Loss scaling: multiply loss by S, unscale gradients before update
Power Iteration — Finding the Largest Eigenvector Iterative

Power iteration repeatedly multiplies a vector by A and renormalises. It converges to the dominant eigenvector. Foundation of PageRank and spectral methods. Click to step.

↑ Click to iterate

-- Algorithm: 1. Start with random v₀ 2. vₖ₊₁ = A·vₖ / ‖A·vₖ‖ -- multiply then normalise 3. λ ≈ vₖᵀAvₖ -- Rayleigh quotient 4. Repeat until convergence -- Rate: |λ₂/λ₁|ᵏ → 0 as k → ∞
Log-Sum-Exp Trick Stability

Computing softmax naively overflows/underflows. Subtract the maximum first — mathematically equivalent but numerically safe.

-- Naive: exp(1000) → ∞ LSE(x) = log Σ exp(xᵢ) = c + log Σ exp(xᵢ-c) -- c = max(x) → always safe -- Used in cross-entropy loss
Gram-Schmidt & Numerical QR Orthogonalisation

Classical Gram-Schmidt loses orthogonality in floating point. Modified GS or Householder reflections are used in practice for stable QR factorisation.

-- Modified Gram-Schmidt: for j = 1..n: uⱼ = vⱼ - Σᵢ<ⱼ (uᵢᵀvⱼ/‖uᵢ‖²)uᵢ eⱼ = uⱼ/‖uⱼ‖ -- Householder: numerically superior
Sparse Matrices & Storage Formats Efficiency

Most real-world matrices (attention masks, adjacency matrices, embeddings) are sparse. Storing and multiplying them efficiently is critical for scalability.

COO Format
(row[], col[], val[])
Simplest. Store triples of non-zero entries. Easy to build, slow to multiply.
CSR Format
(row_ptr, col_idx, val)
Compressed Sparse Row. Fast row access and matmul. Default in scipy, PyTorch sparse.
Block Sparse
BSR / BCSR
Groups non-zeros into dense blocks. Better GPU utilisation in sparse transformers.
Structured Sparsity
N:M pruning
NVIDIA A100: 2:4 sparsity — 2 zeros per 4 values. 2× speedup with hw support.

-- Computer Vision (CNN): Image batch: (B, C, H, W) -- 32 × 3 × 224 × 224 Conv weight: (C_out, C_in, kH, kW) -- 64 × 3 × 3 × 3 Feature map: (B, C_out, H', W') -- Language (Transformer): Token ids: (B, seq_len) Embeddings: (B, seq_len, d_model) -- 4 × 512 × 768 Q, K, V: (B, heads, seq, d_k) -- multi-head split Attn weights: (B, heads, seq, seq) -- 4 × 12 × 512 × 512! -- Speech (RNN/Conformer): Audio frames: (B, T, mel_bins) -- 8 × 800 × 80 Hidden state: (layers, B, hidden) -- 4 × 8 × 512
CP Decomposition Rank-R

Generalises matrix rank to tensors. Decomposes a 3D tensor into a sum of R rank-1 tensors (outer products of vectors). Used in model compression.

𝒯 ≈ Σᵣ aᵣ ⊗ bᵣ ⊗ cᵣ -- ⊗ = outer product -- R = number of components -- Compresses conv weight tensors
Tucker Decomposition Core + Factors

Generalises matrix SVD to tensors. A core tensor multiplied by factor matrices along each mode. Used in recommender systems and NLP.

𝒯 ≈ 𝒢 ×₁ A ×₂ B ×₃ C -- 𝒢: small core tensor -- A,B,C: factor matrices -- More expressive than CP
Kronecker Product ⊗ A ⊗ B

The Kronecker product of A (m×n) and B (p×q) is the (mp × nq) block matrix where each element of A scales a full copy of B. Used in K-FAC, multi-task learning, and quantum computing.

A ⊗ B = [[a₁₁B, a₁₂B, …], [a₂₁B, a₂₂B, …], …] -- Property: (A⊗B)(C⊗D) = (AC)⊗(BD) -- K-FAC: approximates Fisher as F ≈ Aˡ⊗Gˡ per layer -- Reduces O(p²) Fisher storage to O(a²+g²)
11 — Graph Theory

Graph Matrices & GNNs

Graphs are everywhere — molecules, social networks, knowledge graphs. Graph Neural Networks are matrix operations on adjacency structures.

Graph Matrices — Adjacency, Degree & Laplacian GNNs

Click nodes to toggle edges. Watch A, D, and L = D − A update in real time.

-- Adjacency matrix A: A[i,j]=1 if edge (i,j) -- Degree matrix D: D[i,i] = Σⱼ A[i,j] -- Graph Laplacian: L = D - A -- Normalised: L̃ = D^(-1/2) L D^(-1/2) -- GCN layer (Kipf & Welling 2017): Hˡ⁺¹ = σ(Ã Hˡ Wˡ) where Ã = D̃⁻¹/²(A+I)D̃⁻¹/² -- Each layer aggregates 1-hop neighbourhood
Spectral Graph Theory Eigenvalues of L

The eigenvalues of the Laplacian are graph frequencies. Small eigenvalues = slow-varying signals (community structure). Large = rapidly varying (noise).

Lv = λv λ₀ = 0 always -- DC component # connected comps = # zero eigenvalues -- Spectral clustering: eigenvecs of L -- Graph convolution in frequency domain
Message Passing GNN Core

Every GNN layer is a sparse matrix multiply. Aggregating neighbour features is Ã·H — one sparse matmul. K layers = K-hop receptive field.

-- 1 GCN layer = 1 sparse matmul: H' = ÃH (n×n)·(n×d) → (n×d) -- Then linear: H' = H'W (n×d)·(d×d') -- GAT: attention weights on edges -- GraphSAGE: sample + aggregate
PageRank — Dominant Eigenvector of Web Graph Classic

PageRank is the stationary distribution of a random walk on the web graph — the dominant left eigenvector of the transition matrix. Google's founding algorithm; still relevant in GNNs.

PR(i) = (1-d)/N + d · Σⱼ∈in(i) PR(j)/|out(j)| -- Matrix form: r = dMr + (1-d)(1/N)𝟏 -- M: column-stochastic transition matrix -- Solve by power iteration: r ← Mr until convergence -- d = 0.85 (damping: prob of following a link)
12 — Frontier

Advanced Topics

The cutting edge of linear algebra in AI: matrix functions, random projections, kernel methods, and the mathematics of diffusion models.

Random Projections & Johnson-Lindenstrauss Dimensionality Reduction

The JL Lemma: any n points in high-D space can be embedded into O(log n / ε²) dimensions with at most ε relative distortion — using a random matrix. No learning required.

↑ Click to project 3D → 2D with a random matrix

-- JL Lemma: for ε ∈ (0,1), k = O(log n / ε²) R ∈ ℝ^(k×d): R[i,j] ~ 𝒩(0, 1/k) x' = Rx preserves: (1-ε)‖x-y‖² ≤ ‖x'-y'‖² ≤ (1+ε)‖x-y‖² -- Applications: -- Locality-sensitive hashing (approximate NN search) -- Randomised SVD (faster than exact for large matrices) -- FlashAttention uses block tiling, not random proj
Kernel Trick — Implicit High-D Feature Maps SVMs / GPs

The kernel k(x,y) = φ(x)·φ(y) computes inner products in a (possibly infinite-dimensional) feature space without ever computing φ explicitly. The Gram matrix K[i,j] = k(xᵢ,xⱼ) is the key object.

-- Common kernels: Linear: k(x,y) = xᵀy Polynomial: k(x,y) = (xᵀy + c)ᵈ RBF/Gauss: k(x,y) = exp(-‖x-y‖²/2σ²) Neural Tang: k(x,y) = E_{W}[φ(Wx)·φ(Wy)] -- NTK -- Gram matrix K ∈ ℝ^(n×n) must be PSD -- Mercer's theorem: valid kernel ↔ PSD Gram -- Kernel attention: replaces softmax with kernel(Q,K)
Matrix Exponential eᴬ

The matrix exponential generalises scalar eˣ. Used in continuous-time state spaces (Mamba, S4), neural ODEs, and Lie group geometry.

eᴬ = Σₖ Aᵏ/k! = I + A + A²/2! + … -- If A=QΛQ⁻¹: eᴬ = Q·diag(eᵅⁱ)·Q⁻¹ -- Neural ODE: dh/dt = f(h,t;θ) -- Mamba uses selective SSMs: A discretised via eᴬΔ
Score & Diffusion Matrices Diffusion Models

DDPM adds Gaussian noise via matrix-weighted sums. The forward process is a Markov chain; the reverse is learned by predicting the noise ε ≈ εθ(xₜ, t).

-- Forward (noise schedule αₜ ∈ [0,1]): xₜ = √ᾱₜ·x₀ + √(1-ᾱₜ)·ε ε~𝒩(0,I) -- Reverse (learned denoiser): p(xₜ₋₁|xₜ) = 𝒩(μθ(xₜ,t), σₜ²I) -- Score function: ∇ₓ log p(x) ≈ -ε/σ
Rotary Position Embeddings (RoPE) LLaMA / GPT-NeoX

Instead of adding positional info, RoPE rotates query and key vectors by a position-dependent rotation matrix. The dot product QKᵀ then automatically encodes relative positions.

-- For 2D block: rotate by angle mθ at position m R(m,θ) = [[cos(mθ), -sin(mθ)], [sin(mθ), cos(mθ)]] -- Applied to each 2D sub-block of Q and K: q'[2i:2i+2] = R(m, θᵢ) · q[2i:2i+2] k'[2i:2i+2] = R(n, θᵢ) · k[2i:2i+2] -- q'ᵀk' depends only on (m-n): relative position! -- θᵢ = 10000^(-2i/d): low freq for high dims
FlashAttention — IO-Aware Matrix Computation Systems

Standard attention materialises the full (seq × seq) matrix in HBM. FlashAttention tiles the computation to keep everything in fast SRAM — same math, 3× faster, O(n) memory instead of O(n²).

-- Standard attention (materialises QKᵀ in HBM): S = QKᵀ/√dₖ -- (seq × seq) → HBM write: O(n²) P = softmax(S) -- HBM read+write O = PV -- HBM read -- FlashAttention (tiles, no full S in memory): for block (Qᵢ, Kⱼ, Vⱼ): Sᵢⱼ = QᵢKⱼᵀ/√dₖ -- in SRAM online softmax update -- running max/sum Oᵢ += softmax(Sᵢⱼ)·Vⱼ -- accumulate output -- HBM access: O(n) instead of O(n²)
