01 — Optimisation

Linear Programming

LP is the workhorse of combinatorial optimisation, the foundation of interior-point methods, and the relaxation tool for NP-hard problems in ML.

Simplex Method — 2D VisualiserInteractive

The simplex method traverses vertices of the feasible polytope, improving the objective at each step. Geometrically it walks along edges from vertex to vertex. Click to step.

Click to take a simplex step
-- Standard form LP: min cᵀx s.t. Ax = b, x ≥ 0 -- Every LP has an optimal solution at a vertex (BFS) -- # vertices ≤ C(n,m) where n=vars, m=constraints -- Simplex: O(2ⁿ) worst case, polynomial average -- Interior-point (Karmarkar 1984): O(n³·⁵L) guaranteed -- Ellipsoid method (Khachiyan 1979): first poly time
LP Duality Strong Duality
-- Primal: min cᵀx s.t. Ax≥b, x≥0 -- Dual: max bᵀy s.t. Aᵀy≤c, y≥0 -- Weak duality: cᵀx ≥ bᵀy always -- Strong duality: if primal feasible → cᵀx* = bᵀy* -- Complementary slackness: xᵢ>0 ↔ (Aᵀy)ᵢ = cᵢ (tight dual constraint) yⱼ>0 ↔ (Ax)ⱼ = bⱼ (tight primal constraint) -- LP dual = KKT conditions for LP!
LP Relaxations in ML Combinatorial

Many ML problems (MAP inference, submodular optimisation, combinatorial search) are solved via LP relaxations that are tractable.

-- Integer LP: x ∈ {0,1}ⁿ → NP-hard -- LP relaxation: 0 ≤ x ≤ 1 → poly time -- Integrality gap: LP_OPT/ILP_OPT -- MAP in MRF as LP (Wainwright 2003): max Σᵢ θᵢ(xᵢ) + Σᵢⱼ θᵢⱼ(xᵢ,xⱼ) -- Relaxed to marginal polytope LP -- Belief propagation ≈ LP solver (tree-reweighted)
Interior-Point Methods — Barrier Functions Central Path
-- Log-barrier for LP: min cᵀx - μ Σᵢ log xᵢ -- Barrier pulls iterates away from boundary -- As μ→0: solution converges to LP optimum -- Central path: {x*(μ) : μ>0} — smooth curve to x* -- Newton step on barrier problem: Δx = -(∇²f_μ)⁻¹ ∇f_μ -- Hessian: ∇²f_μ = μ·diag(1/xᵢ²) → easy to invert -- Primal-dual IPM (most practical): -- Simultaneously solves primal + dual + complement. slackness -- (x,y,s): s=slacks, xᵢsᵢ=μ → KKT perturbed -- Convergence: O(√n · log(1/ε)) Newton steps
02 — Sparse Recovery

Compressed Sensing

Under-determined linear systems can be solved exactly when the unknown signal is sparse — via L1 minimisation. The RIP condition characterises when this works.

Sparse Recovery — LASSO vs Exact RecoveryInteractive

We have y = Ax + noise, with x sparse. LASSO (L1 + L2) recovers the sparse signal when the measurement matrix A satisfies RIP. Drag the sparsity slider to see when recovery breaks down.

Restricted Isometry Property RIP

The RIP(k,δ) condition ensures that the measurement matrix A approximately preserves the geometry of k-sparse vectors — the key condition for compressed sensing to work.

(1-δ)‖x‖² ≤ ‖Ax‖² ≤ (1+δ)‖x‖² -- holds for all k-sparse x -- δ_2k < √2-1 ≈ 0.414: L1 recovery exact -- Random Gaussian A ∈ ℝ^(m×n): -- satisfies RIP(k,δ) with high prob when m ≥ Ck log(n/k)/δ² -- m = O(k log n) measurements suffice! -- (n/k factor: compression ratio)
Basis Pursuit & LASSO L1 Minimisation
-- Basis Pursuit (noiseless): min ‖x‖₁ s.t. Ax = y -- Equivalent to LP! (x = x⁺ - x⁻) -- Exact recovery iff A satisfies RIP -- LASSO (noisy): min ½‖Ax - y‖² + λ‖x‖₁ -- ADMM / coordinate descent for large scale -- Proximal operator: soft-threshold x̂ᵢ = sign(xᵢ)·max(|xᵢ|-λ, 0) -- OMP (greedy alternative): -- Iteratively add atom most correlated with residual -- O(km) per iteration, k iterations
Connections to ML Sparse Representations
-- Dictionary learning: min_{D,Z} ‖X - DZ‖² + λ‖Z‖₁ -- D = dictionary (atoms), Z = sparse codes -- K-SVD algorithm: alternates dict update + LASSO -- Sparse autoencoders (SAE) — LLM interpretability: -- Train f: ℝᵈ → ℝᵏ (k ≫ d), sparse activations -- Loss: ‖x - Wf(x)‖² + λ‖f(x)‖₁ -- Features = monosemantic (superposition hypothesis) -- Neural network pruning: -- L0: min #nonzero weights, subject to accuracy -- L1 proximal: soft-threshold weights each step -- Magnitude pruning: remove weights with |w| < threshold

Mercer's Theorem & Feature Maps Foundation
-- Valid kernel ↔ Gram matrix PSD for all data -- Mercer: k(x,y) = Σᵢ λᵢ φᵢ(x) φᵢ(y) -- Feature map: φ(x) = (√λᵢ φᵢ(x))ᵢ -- k(x,y) = ⟨φ(x), φ(y)⟩ inner product in ℋ -- Common kernels: RBF: exp(-‖x-y‖²/2σ²) -- ∞-dim feature space Poly: (xᵀy+c)ᵈ -- all monomials deg≤d Matérn: ν controls smoothness Periodic: cos(2π‖x-y‖/p) -- GP for time series
Neural Tangent Kernel (NTK) Infinite Width

As network width → ∞, the network's behaviour at initialisation is described by the NTK. Training dynamics become linear — exact solutions are possible.

Θ(x,x') = Σₗ ∂f(x;θ)/∂θₗ · ∂f(x';θ)/∂θₗ -- NTK is constant during training (infinite width) -- Output evolves as: ḟ = -Θ(X,X)·(f-y) -- Solution: f(t) = (I-e^(-ΘKt))y + e^(-ΘKt)f(0) -- Converges to kernel regression solution -- NTK regime: finite nets if LR and width right -- Feature learning (μP regime): NTK breaks down
Gaussian Processes as Kernel Methods Probabilistic
-- GP prior: f ~ GP(m(x), k(x,x')) -- Posterior (given noisy obs y=f(X)+ε, ε~𝒩(0,σ²I)): μ(x*) = k(x*,X)[K+σ²I]⁻¹(y-m(X)) σ²(x*) = k(x*,x*) - k(x*,X)[K+σ²I]⁻¹k(X,x*) -- Marginal likelihood (for hyperparameter tuning): log p(y|X,θ) = -½yᵀ(K+σ²I)⁻¹y - ½log|K+σ²I| - n/2 log 2π -- Bottleneck: O(n³) inversion → sparse/inducing pts -- Deep kernel: k(x,x') = k(f_θ(x), f_θ(x'))
Random Fourier Features — Scalable Kernel Approximation Efficient
-- Bochner's theorem: any shift-invariant PSD kernel k(x-y) = E_{ω~p(ω)}[e^(iωᵀ(x-y))] -- Sample ω₁,…,ωD from spectral density p(ω) z(x) = √(2/D)[cos(ω₁ᵀx+b₁),…,cos(ωDᵀx+bD)] k(x,y) ≈ z(x)ᵀz(y) (D → ∞: exact) -- RBF spectral density: p(ω) = 𝒩(0, σ⁻²I) -- Approximation error: O(1/√D) with D samples -- Kernelised SVM: O(n²) → Random FF + linear: O(nD) -- Performer (linear attention): RFF for softmax kernel
04 — Information Geometry

Information Geometry

Statistical manifolds, the Fisher metric, α-connections, and the Riemannian structure of probability distributions — the geometry that unifies exponential families, natural gradients, and variational inference.

Statistical Manifold — Gaussian Family CurvatureVisualiser

Each point on the statistical manifold 𝒮 = {p(x;θ)} is a probability distribution. The Fisher information metric makes 𝒮 a Riemannian manifold. Geodesics are "straightest paths" between distributions.

Click two points to draw the geodesic between those distributions.
Fisher Information Metric Riemannian
-- Fisher metric tensor: gᵢⱼ(θ) = E_{p(x;θ)}[∂ᵢ log p · ∂ⱼ log p] = -E[∂ᵢ∂ⱼ log p] (Fisher information) -- Infinitesimal KL divergence: D_KL(p_θ ‖ p_{θ+dθ}) ≈ ½ dθᵀ g(θ) dθ -- Fisher distance = Riemannian geodesic length -- For Gaussian 𝒩(μ,σ²): g = diag(1/σ², 2/σ²) -- Poincaré half-plane! -- Geodesics = semicircles perpendicular to μ-axis
α-Connections & Dually Flat Spaces Amari

The statistical manifold carries a family of affine connections parameterised by α ∈ ℝ. The e-connection (α=1) and m-connection (α=-1) are dual, giving a dually flat structure on exponential families.

-- α-connection: Γ^(α) = (1-α)/2 · Γ^(0) + (1+α)/2 · Γ̃^(0) -- α=0: Levi-Civita (Riemannian, torsion-free) -- α=1: e-connection (exponential family natural) -- α=-1: m-connection (mixture family natural) -- Duality: ⟨∂/∂θⁱ, ∂/∂ηⱼ⟩ = δᵢⱼ -- θ: natural params, η: expectation params -- Pythagorean theorem in dually flat space: D_KL(p‖r) = D_KL(p‖q) + D_KL(q‖r) -- iff q = m-projection of r onto submanifold
Exponential Families — Unified Framework Statistics
-- Exponential family: p(x;θ) = h(x)·exp(θᵀT(x) - A(θ)) -- θ: natural parameters, T(x): sufficient statistics -- A(θ) = log Z(θ): log-partition function (cumulant gen. fn) -- Moment duality: ∇A(θ) = E[T(x)] (mean parameters η) ∇²A(θ) = Cov[T(x)] = Fisher information g(θ) -- Examples: Gaussian: θ=(μ/σ²,-1/2σ²), T(x)=(x,x²), A=μ²/2σ²+log σ Bernoulli: θ=log(p/(1-p)), T(x)=x, A=log(1+eᶿ) Poisson: θ=log λ, T(x)=x, A=eᶿ -- Bregman divergence from A: D_A(η,η') = A*(η) - A*(η') - ⟨η-η', ∇A*(η')⟩ -- where A* = Legendre conjugate of A -- Special case: D_KL = Bregman div from neg-entropy

Directed Models — Bayesian Networks DAG
-- Joint factorisation (chain rule on DAG): p(x₁,…,xₙ) = ∏ᵢ p(xᵢ | pa(xᵢ)) -- d-separation rules (information flow): Chain: X→Z→Y: X⊥Y|Z (Z blocks) Fork: X←Z→Y: X⊥Y|Z (Z blocks) Collider: X→Z←Y: X⊥Y (Z opens when conditioned!) -- Bayes Ball algorithm: find all d-sep sets -- Explaining away: collider creates dependence -- P(rain|wet,sprinkler): conditioning on effect -- creates dependence between causes
Undirected Models — MRFs Gibbs
-- Markov Random Field (Gibbs distribution): p(x) = (1/Z) exp(-E(x)) E(x) = Σ_{C ∈ cliques} ψ_C(x_C) -- Z = Σ_x exp(-E(x)) (partition fn: #P-hard) -- Ising model (binary MRF on grid): E(x) = -J Σ_{(i,j)} xᵢxⱼ - h Σᵢ xᵢ -- Phase transition at critical temperature! -- Hammersley-Clifford: Markov ↔ Gibbs (positive) -- Restricted Boltzmann Machine: bipartite MRF
Exact Inference — Junction Tree Algorithm O(exp(treewidth))
-- Triangulate graph → find clique tree (junction tree) -- Clique tree has running intersection property -- Message from clique Cᵢ to Cⱼ (via separator Sᵢⱼ): μᵢ→ⱼ(Sᵢⱼ) = Σ_{Cᵢ\Sᵢⱼ} ψᵢ(Cᵢ) ∏_{k∈nb(i)\j} μₖ→ᵢ(Sₖᵢ) -- After two passes (inward + outward): p(Cᵢ) ∝ ψᵢ(Cᵢ) ∏_{j∈nb(i)} μⱼ→ᵢ(Sⱼᵢ) -- Complexity: O(n · exp(treewidth w)) -- Low treewidth graphs: efficient exact inference -- General graphs: treewidth can be n → MCMC needed -- Variable elimination = specific message order -- Min-fill heuristic: greedy triangulation

Optimal Control

Pontryagin's Minimum Principle Necessary Conditions
-- Continuous-time optimal control: min ∫₀ᵀ L(x,u,t)dt + V_f(x(T)) s.t. ẋ = f(x,u), x(0) = x₀ -- Hamiltonian: H(x,u,λ) = L(x,u) + λᵀf(x,u) -- Optimality conditions (PMP): ẋ = ∂H/∂λ -- state equation λ̇ = -∂H/∂x -- costate equation u* = argmin_u H -- min Hamiltonian -- λ(T) = ∇V_f(x(T)) (transversality) -- Neural ODE adjoint = costate λ!
HJB Equation Dynamic Programming

The Hamilton-Jacobi-Bellman PDE characterises the value function of an optimal control problem — the continuous-time analogue of the Bellman equation.

-- HJB equation (infinite horizon): min_u {L(x,u) + ∇V(x)ᵀf(x,u)} = 0 -- Or: ρV(x) = min_u{L(x,u)+∇V(x)ᵀf(x,u)} (discounted) -- LQR solution: V(x) = xᵀPx -- P satisfies Algebraic Riccati Equation (ARE): AᵀP + PA - PBR⁻¹BᵀP + Q = 0 -- Solved by Schur decomposition or iteration -- u*(x) = -R⁻¹BᵀPx (linear feedback)
Model Predictive Control & RL Connection Planning
-- MPC: solve finite-horizon OCP at each step, apply first action min_{u₀,…,uₙ₋₁} Σₜ L(xₜ,uₜ) + V_f(xₙ) s.t. xₜ₊₁ = f(xₜ,uₜ), xₜ ∈ 𝒳, uₜ ∈ 𝒰 -- Receding horizon: re-solve every step → feedback -- MPC stability: if V_f is a control Lyapunov function -- RL ↔ Optimal Control connections: Q*(s,a) ↔ -H(x,u,λ) -- Q-fn = Hamiltonian V*(s) ↔ V(x) -- value fn Policy gradient ↔ PMP -- adjoint state = gradient Model-based RL ↔ MPC -- learn dynamics, plan -- iLQR (iterative LQR): locally-linear approximation -- Model Predictive Path Integral (MPPI): sampling-based

Triplet Loss & Margin Learning Contrastive
-- Triplet: (anchor a, positive p, negative n) L_triplet = max(0, d(a,p) - d(a,n) + margin) -- Pull positives close, push negatives far -- margin α > 0: prevents collapse to zero -- Sampling strategy is crucial: -- Easy negatives: d(a,n) ≫ d(a,p) → zero loss -- Hard negatives: d(a,n) < d(a,p) → strongest signal -- Semi-hard: d(a,p) < d(a,n) < d(a,p)+margin -- NT-Xent (SimCLR) = multi-class contrastive: L = -log(exp(d(z,z⁺)/τ) / Σⱼ exp(d(z,zⱼ)/τ)) -- Equivalent to cross-entropy on 2N-way classification
Hyperbolic Geometry for Hierarchies Poincaré

Euclidean space grows polynomially; hyperbolic space grows exponentially — matching the structure of trees and hierarchies. Word embeddings in hyperbolic space better capture taxonomy.

-- Poincaré ball model: {x : ‖x‖ < 1} ds² = 4‖dx‖² / (1-‖x‖²)² -- Distance: d(x,y) = arccosh(1 + 2‖x-y‖²/((1-‖x‖²)(1-‖y‖²))) -- Tree embeds isometrically into ℍ² (Sarkar 2011) -- Riemannian SGD for hyperbolic embeddings: x ← exp_x(-η · grad_R L) -- exp_x: exponential map (Riemannian step) -- grad_R = (1-‖x‖²)²/4 · ∇E (scaling factor)
Optimal Transport as a Metric Geometry of Distributions
-- Wasserstein distance W_p: W_p(μ,ν) = (min_{γ∈Γ(μ,ν)} ∫ ‖x-y‖ᵖ dγ)^(1/p) -- Satisfies metric axioms (triangle inequality!) -- W₂ geodesics = displacement interpolation -- Sliced Wasserstein (fast): SW(μ,ν) = ∫_{S^(d-1)} W(Pθ#μ, Pθ#ν) dθ -- Average 1D Wasserstein over random projections -- O(n log n) per projection vs O(n³) for full OT -- Sinkhorn algorithm (entropy-regularised OT): W_ε(μ,ν) = min_{γ} ∫ c·γ - ε H(γ) -- Solved by O(n²/ε²) iterations of row/col norm -- Differentiable → usable as loss function in DL

Curse of Dimensionality High-D Hell

In high dimensions, all statistical estimation becomes harder exponentially. Neural networks partially overcome this by exploiting structure — but don't eliminate it.

-- Volume of d-ball: Vd = πᵈ/² / Γ(d/2+1) · rᵈ -- Most volume is near the surface (d→∞) -- Nearest-neighbor distance: min‖xᵢ-q‖ ≈ O(n^(-1/d)) -- Need n = O(ε^(-d)) points for ε-cover -- Blessing of dimensionality (concentration): -- For x~𝒩(0,I): ‖x‖/√d → 1 as d→∞ -- Gaussian in high-D concentrates on thin shell -- Manifold hypothesis: real data lives on -- low-dim manifold in high-dim space -- Effective dim << ambient dim → neural nets work
Kolmogorov Complexity & MDL Minimum Description Length
-- Kolmogorov complexity K(x): length of shortest -- program that outputs x on a universal TM -- K(x) is uncomputable (halting problem) -- But: K(x) ≤ |x| + O(1) always -- K(x) ≥ |x| - O(log|x|) for most strings (incompressible) -- MDL principle (Rissanen): -- Best model = shortest description of (model + data|model) L(θ) + L(data|θ) -- two-part code -- Equivalent to MAP with prior p(θ) ∝ 2^(-L(θ)) -- Stochastic Complexity (ideal MDL): -log p(x^n | M) = nL_M(x) -- normalised maximum likelihood -- COMP(M) = log NML normalisation ≈ d/2 log n (BIC)
