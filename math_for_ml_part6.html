02 — Uncertainty Quantification

Conformal Prediction

Distribution-free prediction intervals with finite-sample validity. No assumptions on the model or data distribution — only exchangeability.

Conformal Prediction Interval — LiveInteractive

Given calibration scores {s₁,…,sₙ}, the conformal quantile q̂ = ⌈(n+1)(1-α)⌉-th order statistic. The prediction set C(x) = {y: s(x,y) ≤ q̂} has coverage ≥ 1-α regardless of the data distribution.

Coverage 1-α: 90% Cal. size n: 50
—
Split Conformal Prediction Algorithm
1
Split data
Reserve calibration set D_cal = {(x₁,y₁),…,(xₙ,yₙ)} (≥ 1000 samples recommended). Train model on D_train.
2
Compute nonconformity scores
sᵢ = |yᵢ - ŷᵢ| for regression. Or sᵢ = 1 - p̂(yᵢ|xᵢ) for classification. Any score that is large when "surprising".
3
Find quantile threshold
q̂ = ⌈(n+1)(1-α)⌉/n-th empirical quantile of {s₁,…,sₙ}. Equivalently: the ⌈(n+1)(1-α)⌉-th order statistic.
4
Prediction interval
C(x_new) = [ŷ(x_new) − q̂, ŷ(x_new) + q̂]. Guarantee: P(y_new ∈ C(x_new)) ≥ 1−α. No distributional assumptions — only exchangeability of (xᵢ,yᵢ).
Theoretical Guarantee Finite-Sample
-- Coverage guarantee (exact): P(Y_{n+1} ∈ C(X_{n+1})) ≥ 1-α -- Holds for any exchangeable sequence -- And any model (black box!): -- Upper bound (anti-conservatism): P(Y_{n+1} ∈ C(X_{n+1})) ≤ 1-α + 1/(n+1) -- Conditional coverage (harder): -- E[1{Y∈C(X)} | X=x] ≥ 1-α ∀x -- Impossible without assumptions on P(Y|X) -- Mondrian CP: group-conditional coverage -- Weighted CP: covariate shift robustness -- Online CP: martingale-based for non-exchangeable
Conformal Risk Control & LLM Selective Generation Applications
-- Conformal Risk Control (Angelopoulos 2022): -- Find λ s.t. E[L(ŷ_λ(x), y)] ≤ α for any loss L -- Guarantee holds for any monotone prediction set -- Applications: -- LLM: abstain when confidence < q̂ → FDR controlled -- Medical: set-valued predictions with guaranteed recall -- RAG: retrieve enough docs to cover answer with prob ≥ 1-α -- RAPS (Regularised Adaptive Prediction Sets): s(x,y) = Σ_{k≤π(y)} p̂(yₖ|x) + u·p̂(y|x) - λ·π(y) -- π(y) = rank of true class, u~Uniform[0,1] -- Smaller prediction sets than naive conformal
03 — Mean Field

Mean Field Theory for NNs

The infinite-width limit in a different regime from the NTK. Mean field theory analyzes signal propagation, chaos, and the edge of chaos where deep networks are trainable.

Signal Propagation — Ordered vs Chaotic RegimeAnimated

The mean field equations track how the variance q* and correlation c* of pre-activations evolve across layers. The edge of chaos (χ=1) separates ordered (χ<1) from chaotic (χ>1) phases.

σ_w²: 1.50 σ_b²: 0.05
—
Mean Field Equations Recursion
-- Pre-activation variance propagation: q^l = σ_w² · E_{z~𝒩(0,q^{l-1})}[φ(z)²] + σ_b² -- Fixed point: q* satisfies q* = F(q*) -- Correlation propagation (two inputs x, x'): c^l = (1/q^l)·σ_w² · E[φ(z)φ(z')] + σ_b²/q^l -- (z,z')~𝒩(0,q*[[1,c^{l-1}],[c^{l-1},1]]) -- Lyapunov exponent χ (Jacobian norm per layer): χ = σ_w² · E_{z~𝒩(0,q*)}[φ'(z)²] -- χ < 1: ordered phase (signal contracts) -- χ = 1: edge of chaos (trainable deep nets!) -- χ > 1: chaotic phase (signal explodes)
Depth Scales & μP Maximal Update

Mean field theory predicts the maximum trainable depth. The μP (maximal update parametrisation) puts all layers at the edge of chaos, enabling feature learning at any width.

-- Depth scale ξ: correlation relaxes as c^l ≈ c*+(c^0-c*)e^{-l/ξ} ξ⁻¹ = -log χ -- near edge of chaos: ξ → ∞ -- μP (Yang & Hu 2022): -- Standard: Δθ = O(1/√n) per update → NTK regime -- μP: Δθ = O(1/n) for hidden → O(1) feature change -- Learning rates scale: η_l = η_0/fan_in -- Enables hyperparameter transfer: tune at width 64, -- apply to width 65536 unchanged
04 — Decision Theory

Statistical Decision Theory

The axiomatic framework unifying estimation, hypothesis testing, and prediction. Risk, admissibility, Bayes rules, and the complete class theorem.

Risk, Admissibility & Stein's Paradox Classic
-- Risk: R(θ, δ) = E_{X|θ}[L(θ, δ(X))] -- Estimator δ is inadmissible if ∃δ' with R(θ,δ') ≤ R(θ,δ) ∀θ and < for some θ -- Stein's paradox (1956): -- X~𝒩(θ,I), d≥3: MLE θ̂=X is inadmissible! -- James-Stein estimator dominates: θ̂_JS = (1 - (d-2)/‖X‖²)X R(θ,θ̂_JS) < R(θ,X) for all θ, d≥3 -- Implication: shrinkage (L2 regularisation) always -- improves on MLE in d≥3 dimensions!
Bayes Risk & Complete Class Theorem Optimality
-- Bayes risk: r(π,δ) = E_θ[R(θ,δ)] = ∫R(θ,δ)dπ(θ) -- Bayes rule: δ_π = argmin_d E[L(θ,d)|X] -- minimises posterior expected loss -- Complete class theorem (Wald 1950): -- Every admissible estimator is a Bayes rule -- (or limit of Bayes rules) -- Converse: every Bayes rule is admissible -- (under regularity) -- In ML: regularisation = Bayesian prior -- Weight decay → Gaussian prior (admissible!) -- Dropout → posterior approximation
Hypothesis Testing — Neyman-Pearson & Multiple Testing Testing
-- NP Lemma: most powerful level-α test for H₀ vs H₁: φ*(x) = 1 if p₁(x)/p₀(x) > k, 0 if < k -- k chosen so E_{H₀}[φ*] = α -- Likelihood ratio is sufficient statistic -- Multiple testing (m hypotheses): -- FWER control (Bonferroni): reject if p < α/m -- FDR control (Benjamini-Hochberg 1995): -- Sort p₍₁₎≤…≤p₍ₘ₎; reject all H₍ᵢ₎ with i ≤ k* k* = max{i : p₍ᵢ₎ ≤ αi/m} -- FDR ≤ α under independence (and positive dependence) -- In ML: feature selection, A/B testing, model comparison -- Selective inference: valid p-values after LASSO selection
05 — Free Probability

Free Probability

The noncommutative analogue of classical probability. Free independence replaces statistical independence for matrices — unlocking exact predictions for random matrix spectra in deep networks.

Free Independence & R-Transform Core Concept
-- Classical: X,Y indep → MGF: M_{X+Y} = M_X·M_Y -- Free: A,B freely indep → R-transform: R_{A+B} = R_A + R_B -- R-transform (free cumulant gen fn): R_A(z) = G_A^{-1}(z) - 1/z -- G_A(z) = E[(zI-A)⁻¹]: Stieltjes transform G_A(z) = ∫ ρ_A(λ)/(z-λ) dλ -- Free convolution ⊞: -- Spectral density of A+B when A,B are free: μ_{A+B} = μ_A ⊞ μ_B -- Free CLT: free sum → semicircle law -- Marchenko-Pastur = free Poisson
Applications to Deep Network Spectra Neural Networks

Free probability predicts the spectrum of products and sums of random weight matrices — exactly the kind of computation that happens in a deep network's forward pass.

-- Product of free matrices (S-transform): S_{AB}(z) = S_A(z) · S_B(z) -- Sigma_transform for products -- Deep network: spectrum of Wₗ…W₁ -- Free product of L weight matrices -- Predicts: singular value distribution of Jacobian -- Application (Yang 2020): -- NTK spectrum = free product of layer spectra -- Explains width-depth tradeoff analytically -- Voiculescu's free entropy: χ(X) = ∫∫ log|x-y| dμ(x)dμ(y) -- Maximised by semicircle (free Gaussian!)
Operator-Valued Free Probability & Structured Networks Advanced
-- Operator-valued free prob: replace scalars with matrices -- E_B[·]: conditional expectation onto subalgebra B -- B-valued R-transform: analytic function on B-bimodule -- Applications: -- Predicts spectrum of Attention weight matrices -- Structured matrices (block diagonal, sparse) -- Transfer matrix methods for RNNs -- Free CLT (operator-valued): -- Σᵢ Aᵢ/√n → semicircular over B as n→∞ -- When Aᵢ are free over B (conditional freeness)
06 — Tropical Mathematics

Tropical Geometry in ML

Replace (×,+) with (+,min). The tropical semiring turns polynomial algebra into piecewise linear functions — which are exactly ReLU networks.

Tropical Polynomials = ReLU FunctionsVisualiser

A tropical polynomial is a piecewise-linear function (max of linear functions). This is exactly what a 1-layer ReLU network computes. Tropical algebra formally characterises the geometry of ReLU networks.

-- Tropical semiring 𝕋 = (ℝ∪{-∞}, ⊕, ⊗) a ⊕ b = max(a, b) -- tropical addition a ⊗ b = a + b -- tropical multiplication -- Tropical monomial: a ⊗ x^d = a + dx (linear!) -- Tropical polynomial: ⊕ of monomials = max of linears -- = exactly a piecewise-linear convex function -- = output of ReLU network after integration! -- ReLU networks are tropical rational maps: -- depth-d ReLU = depth-d tropical polynomial -- Newton polytope of tropical poly = activation regions
Linear Regions of ReLU Networks Geometry
-- A depth-L width-n ReLU net partitions ℝᵈ into -- linear regions (polyhedra) where output is linear -- Zaslavsky's theorem: at most N_regions ≤ Σᵢ₌₀^d C(nL, i) -- exponential in L, d -- Tropical perspective: -- Each linear region = vertex of tropical hypersurface -- Tropical dual = Newton polytope -- Deeper nets → finer polyhedral subdivision -- Montufar bound: Ω(⌊n/d⌋^d · 2^{n(L-1)}) regions -- Exponential in depth → depth advantage
Tropical Optimization Dynamic Programming

Tropical matrix multiplication (max-plus algebra) solves shortest path problems. The Viterbi algorithm is tropical matrix exponentiation.

-- Tropical matrix mult (A⊗B)[i,j] = max_k(A[i,k]+B[k,j]) -- = shortest path in weighted DAG -- Tropical matrix power Aᵏ: k-step shortest paths -- Kleene star A* = ⊕_k Aᵏ: all-pairs shortest paths -- Viterbi (HMM decoding): δₜ(j) = max_i δₜ₋₁(i) ⊗ aᵢⱼ ⊗ bⱼ(oₜ) -- = tropical matrix-vector product -- Tropical SVD: sparse factorisation of cost matrices
07 — Quantum Computing

Quantum ML Mathematics

Hilbert spaces, density matrices, quantum channels, and variational quantum circuits — the linear algebra of quantum computing that may accelerate certain ML subroutines.

Quantum State & Measurement Foundations
-- Pure state: |ψ⟩ ∈ ℂ^(2ⁿ), ‖|ψ⟩‖=1 -- n-qubit: superposition of 2ⁿ basis states |ψ⟩ = Σᵢ αᵢ|i⟩, Σ|αᵢ|²=1 -- Mixed state: density matrix ρ = Σᵢ pᵢ|ψᵢ⟩⟨ψᵢ| -- ρ PSD, tr(ρ)=1; pure iff ρ²=ρ -- Measurement in basis {|m⟩}: P(outcome m) = |⟨m|ψ⟩|² -- Born rule; expectation of observable O: ⟨O⟩=⟨ψ|O|ψ⟩ -- Quantum channel (CPTP map): ε(ρ) = Σₖ KₖρKₖ† -- Kraus operators: Σ Kₖ†Kₖ = I
Quantum Speedups for ML Algorithms
-- Grover search: O(√N) vs O(N) classical -- Applies to: unstructured search, min-finding -- HHL (linear systems): Ax=b in O(log N · κ²) -- vs classical O(N·κ) — exponential speedup! -- But: exponential input/output cost (dequantization) -- Quantum PCA (Lloyd 2014): O(log d) per eigenvector -- Dequantized (Tang 2018): classical O(poly log d) -- Many quantum ML speedups dequantizable! -- Quantum kernel: K(x,y) = |⟨φ(x)|φ(y)⟩|² -- Feature map φ via quantum circuit -- Potentially exponential feature spaces
Variational Quantum Circuits (VQC) Parametric
-- Ansatz: |ψ(θ)⟩ = U(θ)|0⟩, U(θ) = ∏ₗ Uₗ(θₗ) -- Each Uₗ(θₗ) = exp(-iθₗ Hₗ/2) (Pauli rotation) -- Loss: L(θ) = ⟨ψ(θ)|C|ψ(θ)⟩ (expectation of cost operator) -- Gradient (parameter shift rule): ∂L/∂θₗ = (L(θₗ+π/2) - L(θₗ-π/2))/2 -- Requires only 2 circuit evaluations per parameter! -- Barren plateau problem: -- Var[∂L/∂θ] ≤ 2/2ⁿ exponentially small in n! -- Gradients vanish → hard to train deep circuits -- Solutions: local cost functions, layerwise training -- Quantum advantage: when C is many-body Hamiltonian -- Classical simulation intractable: O(4ⁿ) full state vector
08 — Algebraic Graph Theory

Algebraic Graph Theory

Cayley graphs, graph homomorphisms, zeta functions, and algebraic characterisations of graph properties — the deep structure behind GNN expressiveness and graph classification.

Ihara Zeta Function — Graph Spectral InvariantVisualiser

The Ihara zeta function ζ_G(u) = ∏_C (1-u^{|C|})^{-1} over prime cycles encodes the full spectral information of a graph. Its poles are related to the adjacency matrix eigenvalues.

-- Ihara determinant formula: ζ_G(u)^{-1} = (1-u²)^{m-n} det(I - Au + (D-I)u²) -- A: adjacency, D: degree, n: nodes, m: edges -- Ramanujan graphs: λ₂ ≤ 2√(d-1) -- Poles of ζ_G on |u| = 1/√(d-1) — Riemann hypothesis for graphs -- Optimal expanders (used in coding theory, CS) -- Graph homomorphism counts: hom(H,G) = number of graph homomorphisms H→G -- hom(K₂,G) = 2|E|, hom(C₃,G) = 6·#{triangles} -- 2-WL ≡ counting subgraph homomorphisms
Cayley Graphs & Group Symmetry Algebra meets Graphs
-- Cayley graph Cay(G,S): vertex set G, -- edge (g, gs) for each s ∈ S (generating set) -- G acts on itself by left multiplication → G-equivariant! -- Properties: -- Vertex-transitive: all vertices "look the same" -- Expander iff Cayley graph of group has spectral gap -- Hypercube: Cay(ℤ₂ⁿ, standard basis) -- Application to GNNs: -- Message passing on Cayley graph = group convolution -- Equivariant to group G by construction
Graph Homomorphisms & k-WL Expressiveness
-- k-WL test: colours k-tuples of nodes -- k-WL ≡ k-dimensional Weisfeiler-Leman -- 2-WL: counts homomorphisms from trees -- 3-WL: counts homomorphisms from graphs of tw≤2 -- Lovász theorem: -- G ≅ H iff hom(F,G) = hom(F,H) ∀F -- Homomorphism counts determine isomorphism! -- Subgraph counting GNNs: -- Inject subgraph counts as features -- Strictly more expressive than 1-WL -- I²-GNN, NGNN: count walks, cycles, cliques
09 — Integration

Worked Examples

End-to-end derivations connecting multiple mathematical areas — the kind of reasoning expected in ML research papers and graduate coursework.

Example 1: Deriving the ELBO from First Principles VI + Info Theory
1
Start with log marginal likelihood
log p(x) = log ∫ p(x|z) p(z) dz. This is intractable for deep decoders — the integral has no closed form.
2
Multiply and divide by q(z|x)
= log E_{q(z|x)}[p(x|z)p(z)/q(z|x)]. This identity holds for any q with the right support.
3
Apply Jensen's inequality (log is concave)
≥ E_{q(z|x)}[log(p(x|z)p(z)/q(z|x))] = E_q[log p(x|z)] + E_q[log p(z)/q(z|x)] = E_q[log p(x|z)] − KL(q‖p).
4
ELBO and gap
log p(x) = ELBO + KL(q(z|x)‖p(z|x)) ≥ ELBO. Maximising ELBO tightens the bound. The gap is the posterior approximation error.
-- Summary: log p(x) ≥ ELBO = E_{q(z|x)}[log p(x|z)] - D_KL(q(z|x)‖p(z)) = H_cross(q, p(x,z)) - H(q(z|x)) -- KL(q‖p) ≥ 0 → log p(x) ≥ ELBO always -- Equality when q(z|x) = p(z|x) (true posterior)
Example 2: Policy Gradient via Likelihood Ratio Trick RL + Calculus
-- Objective: J(θ) = E_{τ~π_θ}[R(τ)] -- = ∫ p(τ;θ)·R(τ) dτ -- ∇_θ J(θ) = ∫ ∇_θ p(τ;θ)·R(τ) dτ -- Log-derivative trick: ∇p = p·∇log p = ∫ p(τ;θ)·∇_θ log p(τ;θ)·R(τ) dτ = E_{τ~π_θ}[∇_θ log p(τ;θ)·R(τ)] -- Expand log p(τ;θ) = log p(s₀) + Σₜ[log π_θ(aₜ|sₜ) + log P(sₜ₊₁|sₜ,aₜ)] -- Only π_θ terms depend on θ: ∇_θ log p(τ;θ) = Σₜ ∇_θ log π_θ(aₜ|sₜ) -- Final: ∇J(θ) = E[Σₜ ∇_θ log π_θ(aₜ|sₜ) · R(τ)] -- Replace R(τ) with future returns Gₜ: causal structure -- Subtract baseline: subtract b(sₜ) for variance reduction
Example 3: Transformer Complexity from Matrix Multiply Counts LLM + Lin. Alg.
-- Transformer layer: n = sequence length, d = model dim, h = heads, dff = FFT dim -- Self-attention FLOPs: QKV projection: 3 × (n·d·d) = 3nd² QKᵀ: n × n × d = n²d ← quadratic bottleneck softmax(·)V: n × n × d = n²d Out projection: n × d × d = nd² -- Attention total: 4nd² + 2n²d -- FFN FLOPs: 2 × (n·d·4d) = 8nd² -- Total per layer: 12nd² + 2n²d -- For n=2048, d=4096: 12×2048×4096²+2×2048²×4096 -- ≈ 823B + 34B ≈ 857B FLOPs per layer -- Total for LLaMA-70B (80 layers): ~68.6T FLOPs/token -- At 300T tokens (Chinchilla): ~2×10²⁸ FLOPs training
Example 4: Why Adam ≈ Diagonal Natural Gradient Optimisation + Info Geo
-- Natural gradient: θ ← θ - α·F(θ)⁻¹·∇L -- F(θ)[i,j] = E[∂ᵢ log p · ∂ⱼ log p]: Fisher information -- Diagonal approximation: F ≈ diag(E[gᵢ²]) -- E[gᵢ²] ≈ EMA of g²: second moment estimate in Adam! -- Adam update: Δθᵢ = α·m̂ᵢ/√v̂ᵢ -- Natural gradient: Δθᵢ = α·gᵢ/F[i,i] -- With F[i,i] ≈ v̂ᵢ: Adam ≈ diag. natural gradient -- Why it helps: Fisher metric accounts for curvature -- Parameters with high curvature (large Fᵢᵢ) → small steps -- Parameters with low curvature → large steps -- Reparameterisation invariant (up to diagonal approx)
