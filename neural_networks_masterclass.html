The Single Neuron — One Node, Three Operations

A biological neuron either fires or doesn't based on how much input it receives. The mathematical neuron does the same thing — but continuously, with real numbers, so we can apply calculus to it.

The Three-Step Forward Pass

// Step 1: weighted sum
z = w₁·x₁ + w₂·x₂ + b

// Step 2: activation (non-linearity)
ŷ = σ(z) = 1 / (1 + e−z)

This is literally everything a single neuron does. Every deep learning model — GPT, ResNet, Stable Diffusion — is just this computation repeated millions of times in different configurations.

What Each Part Does

w
Weight wᵢ — controls how much input xᵢ influences the output. Positive weight: more xᵢ → higher output. Negative weight: more xᵢ → lower output (inhibition). Zero weight: ignore that input entirely.
b
Bias b — shifts the activation threshold. Without bias, the neuron can only fire based on inputs. With bias, it can fire even when all inputs are zero. Think of it as the neuron's "default tendency." Without it, the decision boundary is forced through the origin — a huge restriction.
σ
Activation σ(z) — squashes z from (−∞, +∞) to (0, 1). Without this, the neuron is just a linear function — no matter how many neurons you stack, the whole network collapses to one linear equation. This is why activations are non-negotiable.
Let's compute by hand with x₁=1, x₂=0.5, w₁=0.8, w₂=0.3, b=0.1:
z =0.8×1 + 0.3×0.5 + 0.1 = 1.05
ŷ = σ(1.05) =1/(1+e⁻¹·⁰⁵) = 0.741
So this neuron outputs 0.741 — closer to 1 than 0. Now drag the sliders above and watch how these numbers change live.
The volume knob analogy: Imagine each weight is a volume dial on a mixing board. x₁ is a guitar track, x₂ is a bass track. w₁ and w₂ control how loud each track is in the final mix (z). The bias is like a constant background hum. The activation function is the speaker — it converts the electrical signal (z) to actual sound, but clips it so it never goes beyond a safe range.

Vector / Matrix Form

z = W·x + b   // for a whole layer
ŷ = σ(z)

where x ∈ ℝn, W ∈ ℝm×n, b ∈ ℝm

When you have m neurons each receiving n inputs, the matrix multiply W·x computes all m neurons simultaneously. This is why GPUs (which are matrix multiply machines) are so well-suited for neural networks.

A single neuron with sigmoid activation can learn any linear decision boundary — it can classify whether a point is above or below a line. But it cannot solve XOR (a curved boundary). You need at least one hidden layer with multiple neurons for that. We'll prove this in Chapter 8.
Chapter 02

Activation Functions — The Source of All Non-Linearity

If you remove activation functions from a 100-layer network, it becomes mathematically identical to a single-layer network. Activations are what make depth meaningful.

Activation Curves + Derivatives
The dashed line is the derivative σ'(z). This is what backpropagation multiplies by at every layer. Where it's flat (near 0), gradients die — the neuron stops learning. This is the vanishing gradient problem in its most visual form.

Sigmoid σ(z)

σ(z) = 1/(1+e−z)     output: (0, 1)
σ'(z) = σ(z)·(1−σ(z))  max value: 0.25 at z=0

The derivative maxes out at 0.25. In a 10-layer network, the gradient shrinks by at least 0.25¹⁰ = 0.000001 per pass. By the time the gradient reaches layer 1, it's essentially zero — the early layers stop learning. This is why sigmoid fell out of favor for hidden layers.

Still used for binary output layers where you need a probability between 0 and 1.

ReLU max(0, z)

ReLU(z) = max(0, z)
ReLU'(z) = 1 if z > 0 else 0

Gradient is either 1 (positive z, passes gradient unchanged) or 0 (negative z, blocks gradient entirely). The clean gradient=1 for positive inputs solved the vanishing gradient problem and made deep networks trainable.

Dying ReLU: If a neuron's z gets stuck negative (perhaps after a large gradient update), it will always output 0 and its gradient is always 0. The weight never updates again — the neuron is "dead." Fix: Leaky ReLU, He initialization, lower learning rates.

Tanh

tanh(z) = (ez−e−z)/(ez+e−z)  range: (−1, 1)
tanh'(z) = 1 − tanh²(z)          max: 1.0 at z=0

Zero-centered output is a key advantage over sigmoid. When outputs are symmetric around 0, gradients push weights in both positive and negative directions naturally. Sigmoid's (0,1) range causes gradients to be always positive, which causes inefficient zig-zagging updates (the "zigzag problem").

GELU (Modern Default)

GELU(z) ≈ 0.5z(1+tanh(√(2/π)(z+0.044z³)))

Used in GPT, BERT, and most modern transformers. Unlike ReLU, GELU is smooth at z=0 and has a slight negative region for small negative inputs — it "weights" inputs by how likely they are to be positive under a Gaussian distribution. Differentiable everywhere, empirically works better than ReLU for large language models.

Comparison Table

The Universal Approximation Theorem says: a neural network with just one hidden layer and a non-linear activation can approximate any continuous function to arbitrary precision — given enough neurons. This doesn't tell you how to train it, but it proves the expressive power is there. Activations are literally what makes this theorem possible.

Loss Functions — Measuring How Wrong We Are

The loss function is the compass of training. It takes the gap between prediction and truth and turns it into a single number that we can minimize. The choice of loss function shapes what "learning" means for your model.

Loss Landscape

MSE loss-
BCE loss-
Drag ŷ close to the truth y and watch both losses approach 0. Now set y=1 and drag ŷ near 0 — notice how BCE (gold) shoots toward infinity. This is BCE punishing confident wrong predictions exponentially harder than MSE does.

Mean Squared Error — Regression

LMSE = (1/n) ∑i (yi − ŷi)²

∂L/∂ŷ = −2(y − ŷ)/n = 2(ŷ − y)/n

The gradient has clean intuition: if ŷ > y, gradient is positive → the update rule subtracts from ŷ (pushes it down). If ŷ < y, gradient is negative → ŷ gets pushed up. MSE always nudges the prediction toward the target.

The squared term means large errors are punished much harder than small ones — an error of 2 costs 4× more than an error of 1. This is good when outliers are meaningful, bad when outliers are noise.

Binary Cross-Entropy — Classification

LBCE = −[y·log(ŷ) + (1−y)·log(1−ŷ)]

∂L/∂ŷ = −y/ŷ + (1−y)/(1−ŷ)
         = (ŷ − y) / [ŷ(1−ŷ)]

When y=1 and ŷ→0: −log(0) → ∞. The model is confidently wrong and gets catastrophically penalized. When y=1 and ŷ→1: −log(1) = 0. Perfect prediction, zero cost. The log ensures the penalty grows exponentially as confidence in the wrong answer increases.

Notice the gradient simplifies to (ŷ − y) / [ŷ(1−ŷ)]. When we use sigmoid output with BCE loss, the denominator ŷ(1−ŷ) = σ'(z) — it cancels exactly with the sigmoid derivative in backprop! This is why sigmoid + BCE is the canonical classification setup: the gradients simplify to just (ŷ − y), clean and numerically stable.

Categorical Cross-Entropy (Multi-class)

L = −∑c yc·log(ŷc)

softmax(zc) = ezc / ∑j ezj

For classifying into K categories. Softmax converts raw scores (logits) into probabilities that sum to 1. Cross-entropy then scores how much probability mass was placed on the correct class. Used in every image classifier, language model, and more.

Loss Surface Intuition

1
Think of loss as the altitude of a mountain landscape. The x-y axes are the weights. We want to reach the lowest valley.
2
For 2 weights it's a literal landscape. For 1 million weights, it's a 1-million-dimensional surface — impossible to visualize, but the math works the same way.
3
Local minima were once feared to be a big problem. Research shows that in high dimensions, most local minima have similar loss values to the global minimum — saddle points are more problematic than local minima in practice.
Why not just use accuracy as the loss? Accuracy (0 or 1 per sample) has zero gradient almost everywhere — it can't guide gradient descent because a tiny weight change almost never changes which class is predicted. MSE and BCE are differentiable everywhere, so the gradient always points somewhere useful.

Gradient Descent — The Learning Algorithm

Gradient descent is the engine of all neural network training. It asks one question at every step: which direction is downhill? Then it takes a step in that direction. Repeat until you reach the bottom.

Try setting α=0.3 and watch it overshoot and bounce. Then try α=0.01 and watch it crawl. The red tangent line shows the current gradient — steeper means bigger step.

The Update Rule — The Heart of Learning

wnew = wold − α · ∂L/∂w
bnew = bold − α · ∂L/∂b

Read this as: "Move each parameter a small step in the direction that reduces loss." The minus sign is critical — the gradient points uphill, so we go in the opposite direction.

If w=2.0, L=3.5, ∂L/∂w=1.2, α=0.1:
wnew =2.0 − 0.1 × 1.2 = 1.88
We moved w downhill by 0.12. The gradient says "increasing w increases loss," so we decreased w.

Learning Rate α — The Most Important Hyperparameter

αStep sizeWhat happens
0.0001TinyVery slow, may get stuck in local minima
0.001SmallSafe default for Adam optimizer
0.01MediumGood for SGD with momentum
0.1LargeMay oscillate around the minimum
1.0+HugeLoss explodes, training diverges

In practice: learning rate schedules start high (fast exploration) and decay over time (precise convergence). Warmup (start low, rise, then decay) prevents instability at the start of training.

Three Flavors of Gradient Descent

B
Batch GD: Compute gradient over ALL training samples, then update once. Exact gradient, but very slow per update. Uses full dataset memory.
S
Stochastic GD (SGD): Use ONE sample per update. Very noisy gradient, but fast updates. Noise can actually help escape local minima (acts like regularization).
M
Mini-batch GD: Use k=32–512 samples per update. Balances accuracy and speed. Allows GPU parallelism. This is the standard approach in all modern deep learning.

Gradient Descent vs. Calculus Intuition

The gradient ∂L/∂w is just the slope of the loss curve at the current weight. If you plot L vs. w (as in the animation), the gradient is the steepness of the curve at your current position. Descending the curve = reducing loss. The animation above is a perfect visual: the red tangent line is the gradient at every step.

"Every optimization algorithm in deep learning is fundamentally a variant of gradient descent. Adam, RMSProp, AdaGrad — they all just compute smarter step sizes, but always follow the gradient."
Chapter 05

Backpropagation — The Algorithm That Made Deep Learning Possible

Backprop efficiently computes the gradient of the loss with respect to every weight in the network simultaneously. Before it was discovered (1986), training deep networks was computationally infeasible.

Forward + Backward Pass
phaseIDLE
output delta δ-

Forward Pass — Store Everything

z1 = W1·x + b1
a1 = σ(z1) // STORE THIS
z2 = W2·a1 + b2
ŷ = σ(z2) // STORE THIS

During the forward pass, we cache every intermediate value (a1, z1, etc.). These are needed to compute gradients during the backward pass. This is why training uses far more GPU memory than inference — you're storing the entire forward computation graph.

Backward Pass — The Delta Rule

// Output layer error signal
δ2 = (ŷ − y) · σ'(z2)

// Output layer weight gradients
∂L/∂W2 = δ2 · (a1)T
∂L/∂b2 = δ2

// Propagate error signal backward
δ1 = (W2)T · δ2 ⊙ σ'(z1)

// Hidden layer weight gradients
∂L/∂W1 = δ1 · xT

What is Delta δ?

δl (delta for layer l) is "the error signal reaching this layer". It has two components multiplied together:

Error from above
(Wl+1)T·δl+1
How much does the loss change if this layer's output changes?
Local sensitivity
σ'(zl)
How much does this layer's output change if its pre-activation changes?

The ⊙ symbol means element-wise (Hadamard) product — multiply corresponding elements. If any σ'(z) is near 0 (saturated neuron), that kills the gradient at that position — the vanishing gradient problem in concrete form.

One-layer example with numbers:
Let ŷ=0.8, y=1, z2=1.39 (so σ'(z2)=0.16), a1=0.7:
ŷ−y =0.8−1 = −0.2
δ2 =−0.2 × 0.16 = −0.032
∂L/∂W2 =−0.032 × 0.7 = −0.0224
Weight update (α=0.1): W2 ← W2 − 0.1×(−0.0224) = W2 + 0.00224. The negative gradient pushes the weight up, which increases ŷ, which is correct since we need ŷ to move toward 1.
Why not just use finite differences? You could estimate ∂L/∂w ≈ [L(w+ε)−L(w)]/ε for each weight. With 1 million weights, that's 1 million forward passes per gradient. Backprop computes ALL gradients in just 2 passes (1 forward + 1 backward). That's the entire secret of why deep learning is tractable.
Chapter 06

The Chain Rule — Why ∂L/∂w = ∂L/∂ŷ · ∂ŷ/∂z · ∂z/∂w

The chain rule from calculus is the only mathematical concept you need to understand all of backpropagation. Everything else is just applying it systematically to a computation graph.

Chain Rule Flow
Watch the particles flow from w → z → ŷ → L. The gradient flows in the reverse direction, multiplied at each node. The final formula at the bottom is derived by tracing back from L to w.

Full Derivation — Step by Step

// Setup: z=wx+b, ŷ=σ(z), L=½(y−ŷ)²

// How does L change when ŷ changes?
∂L/∂ŷ = −(y − ŷ) = (ŷ − y)

// How does ŷ change when z changes?
∂ŷ/∂z = σ'(z) = σ(z)·(1−σ(z))

// How does z change when w changes?
∂z/∂w = x                  // because z=wx+b

// Chain them together:
∂L/∂w = ∂L/∂ŷ · ∂ŷ/∂z · ∂z/∂w
         = (ŷ−y) · σ'(z) · x

Intuition for Each Factor

1
∂L/∂ŷ = (ŷ−y) — The prediction error. If we predicted too high (ŷ > y), this is positive, meaning L increases when ŷ increases. Makes sense — being more wrong means more loss.
2
∂ŷ/∂z = σ'(z) — The slope of the activation curve. This is what gets multiplied at every layer in a deep network. If the neuron is saturated (|z| large), σ'(z) ≈ 0, and the gradient vanishes here — this layer learned nothing this step.
3
∂z/∂w = x — This is just the input! How much does the pre-activation change if we wiggle w? By exactly x. So: gradient proportional to input.
✕
Multiply all three to get ∂L/∂w. This is the chain rule: the total effect of w on L is the product of all the partial sensitivities along the path w → z → ŷ → L.

The Critical Insight: ∂L/∂w = δ · x

δ = (ŷ−y) · σ'(z)    // error signal
∂L/∂w = δ · x            // gradient = error × input
∂L/∂b = δ · 1 = δ        // bias gradient = just error

This formula contains the entire secret of how neural networks learn:

x = 0? Then ∂L/∂w = 0 — the weight never updates, no matter how wrong the prediction. Always activate all inputs or normalize to avoid dead inputs.
Large |x|? Large gradient. The weight for a big input signal updates faster. This is why feature scaling matters so much.

Why the Bias Gradient = δ

z = w·x + b
∂z/∂b = 1

The bias acts like an input with a fixed value of 1. So ∂L/∂b = δ · 1 = δ. The bias always gets the full error signal, regardless of inputs. This is why biases often converge faster than weights during training.

The Chain Rule — Universal Form
∂L/∂wl = δl · al-1
Error signal at layer l, times the activation feeding into that layer. Every weight update in every neural network follows this formula.
Chapter 07

Multi-Layer Networks — Depth Creates Hierarchy

Stack layers and something remarkable happens: each layer learns to represent a higher-level abstraction of the data. Early layers detect edges, middle layers detect shapes, deep layers detect concepts.

Animated Deep Network

Layer-by-Layer Forward Pass

a0 = x                    // input layer
al = σ(Wl·al−1 + bl)    // hidden layers
ŷ = softmax(WL·aL−1+bL)   // output

Each layer takes the previous layer's output as input. Critically, you never skip layers in a standard feedforward network — information flows one layer at a time (skip connections in ResNets are a special case that explicitly add the input back).

Dimension Accounting (MNIST example)

Input: x ∈ ℝ784     // 28×28 image flattened
W1 ∈ ℝ128×784 → a1 ∈ ℝ128
W2 ∈ ℝ64×128  → a2 ∈ ℝ64
W3 ∈ ℝ10×64   → ŷ ∈ ℝ10   // 10 digit classes

Total parameters: 128×784 + 128 + 64×128 + 64 + 10×64 + 10 = 109,386 parameters. Modern LLMs have billions. The math is identical — just more matrix multiplies.

What Do Hidden Layers Learn?

L1
First hidden layer: Raw feature detectors — edges, simple textures, frequency components. Neurons activate for specific patterns in the raw input.
L2
Middle layers: Combinations of earlier features — corners, curves, parts of objects. Representations become increasingly task-specific.
Ln
Deep layers: High-level concepts — "face," "digit 3," "positive sentiment." These abstract representations are what get classified in the final layer.

Vanishing and Exploding Gradients

δl = (Wl+1)T·δl+1 ⊙ σ'(zl)

Each backward step multiplies by the weight matrix and the activation derivative. Over L layers:

If ||W|| · σ'(z) < 1 each layer: gradient shrinks by this factor L times → vanishes to ~0

If ||W|| · σ'(z) > 1 each layer: gradient grows exponentially → explodes to infinity

With sigmoid activations and 10 layers: gradient shrinks by at least 0.25¹⁰ = 10⁻&sup6;. Early layers receive essentially zero learning signal. This is why it took decades from the idea of deep nets (1940s) to their success (2010s) — this problem needed to be solved first.

Solutions to Gradient Problems

ProblemSolutionKey idea
VanishingReLUGradient = 1 for positive activations
VanishingBatchNormNormalizes z to prevent saturation
VanishingResNet skipGradient highway bypasses layers
ExplodingGradient clippingCap ||gradient|| at a max value

Weight Initialization — Why It Matters

Xavier: w ~ U(−√(6/(nin+nout)), +√(...))
He:     w ~ N(0, √(2/nin))      // for ReLU

Goal: keep the variance of activations and gradients roughly 1.0 throughout all layers. If variance grows: exploding. If it shrinks: vanishing. He init is derived by solving for the initial weight scale that preserves variance when passing through ReLU.

If we initialize all weights to 0: every neuron computes the same thing → same gradient → same update → they never differentiate. Symmetry breaking through random init is essential. If we initialize too large (e.g. w ~ N(0, 1)): sigmoid input z is huge → σ'(z) ≈ 0 → no gradients from step 1.

The Complete Training Loop

for epoch in range(N_EPOCHS):
  for (x, y) in dataset:
    // 1. Forward pass
    ŷ = forward(x)
    // 2. Compute loss
    L = loss_fn(y, ŷ)
    // 3. Backpropagation
    grads = backward(L)
    // 4. Update all weights
    W -= α * grads.W
    b -= α * grads.b

This 4-step loop, applied billions of times, is literally all of training in any neural network. PyTorch/TensorFlow just automate steps 3 and 4 with automatic differentiation.

Why XOR Needs a Hidden Layer

XOR is not linearly separable — there is no single straight line that separates 0s from 1s in the (x₁,x₂) plane. A single neuron implements exactly one linear boundary.

With one hidden layer of 2 neurons, the network learns two linear boundaries (one per hidden neuron), then the output neuron combines them to carve out the non-linear XOR region. This is the Universal Approximation Theorem in action.

What the hidden neurons learn (approximately):
h₀ activateswhen x₁ OR x₂ is 1 (OR gate)
h₁ activateswhen x₁ AND x₂ are 1 (AND gate)
outputh₀ AND NOT h₁ = XOR!
The network discovers this decomposition on its own through gradient descent.

Modern Optimizers

// SGD with Momentum
v = β·v + (1−β)·∇L   // accumulate direction
w -= α·v

// Adam (Adaptive Moment Estimation)
m = β₁·m + (1−β₁)·∇L              // 1st moment
v = β₂·v + (1−β₂)·(∇L)²            // 2nd moment
m̂ = m/(1−β₁t), v̂ = v/(1−β₂t)   // bias correct
w -= α · m̂/(√(v̂)+ε)

Momentum builds up speed in consistent directions, dampens oscillation. Think of a ball rolling downhill that builds up velocity.

Adam tracks per-parameter learning rates. Parameters with consistent gradients → larger effective lr. Rare parameters → larger effective lr. This is why Adam works well on sparse problems (NLP) and is the default in most modern work.

Regularization — Preventing Overfitting

MethodMechanismEffect

L2 regularization modifies the gradient: ∇Ltotal = ∇Ldata + 2λW. So the weight update becomes: w ← w − α(∇L + 2λw) = (1−2αλ)w − α∇L. The (1−2αλ) factor slightly shrinks weights every step — this is why L2 is also called weight decay.
The Complete Learning Equation
w ← w − α · (1/n) ∑ ∂L/∂w
Average gradient over mini-batch · learning rate · subtract = new weight. Every neural network that has ever been trained uses exactly this.
