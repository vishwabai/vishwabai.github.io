Chapter 01

Signal Processing for ML

From audio transformers to CNNs on time series, signal processing mathematics is essential — sampling theory, filter design, spectral analysis, and wavelets all appear directly in modern architectures.

Sampling Theory

Nyquist-Shannon Theorem:
  A signal bandlimited to f_max can be perfectly reconstructed
  from samples taken at f_s ≥ 2·f_max (Nyquist rate).
  Aliasing: frequencies above f_s/2 "fold back" → distortion.

Discrete-Time Fourier Transform (DTFT):
  X(e^{jω}) = Σₙ x[n] e^{-jωn}     ← continuous in ω, periodic with 2π

DFT (finite-length N):
  X[k] = Σₙ x[n] W_N^{kn}  where W_N = e^{-j2π/N}
  x[n] = (1/N) Σₖ X[k] W_N^{-kn}   ← inverse DFT

Convolution & Correlation

Linear convolution:   (f*g)[n] = Σₖ f[k]·g[n−k]
Cross-correlation:    (f⋆g)[n] = Σₖ f̄[k]·g[n+k]   ← matched filtering
Convolution theorem:  F{f*g} = F{f}·F{g}           ← multiply in freq domain
Circular convolution: x ⊛ h  =  IFFT(FFT(x)·FFT(h)) ← O(N log N)

CNN conv layer: (I*K)[i,j] = ΣΣ I[i+m,j+n]·K[m,n]
← cross-correlation in practice (no flip); same cost, learned kernel
Dilated conv:   (I*_r K)[i,j] = ΣΣ I[i+r·m,j+r·n]·K[m,n]
← receptive field grows exponentially with depth; WaveNet, DeepLab

Short-Time Fourier Transform (STFT)

STFT:  X[n,k] = Σₘ x[m]·w[m−n]·e^{-j2πkm/N}
w[m]: window function (Hann, Blackman-Harris, …)
Spectrogram = |X[n,k]|²
Mel Spectrogram: apply triangular filterbank on log-frequency axis
Resolution trade-off (Heisenberg):
  Δt·Δω ≥ ½     ← cannot localise in both time and frequency simultaneously
Wider window → better frequency res, worse time res

Wavelets

Continuous Wavelet Transform:
  W_f(a,b) = (1/√|a|) ∫ f(t)·ψ̄((t−b)/a) dt
  a = scale (inverse of frequency), b = translation

Multiresolution Analysis (MRA):
  f = Σⱼ Σₖ ⟨f,ψⱼₖ⟩ψⱼₖ  where ψⱼₖ(t) = 2^{j/2}ψ(2^j t−k)
  Dyadic subsampling: detail at each scale stored compactly

Scattering Transform (Mallat):
  S[p]x = |W_{λₚ}|…||W_{λ₁}|x|…|  ← iterated wavelet modulus
  Translation-invariant + deformation-stable; used in audio/materials
  Theoretical foundation for CNN invariance properties

Filter Design for Neural Networks

FIR filter: y[n] = Σₖ bₖ x[n−k]           ← finite impulse response; always stable
IIR filter: y[n] = Σₖ bₖ x[n−k] − Σₖ aₖ y[n−k]  ← recursive; poles must be inside unit circle

S4/Mamba state space models:
  ẋ(t) = Ax(t) + Bu(t)
  y(t) = Cx(t) + Du(t)   ← LTI system; discretise with ZOH/Bilinear
  Convolutional kernel K = C·exp(A·Δ)·B — computed via FFT in O(L log L)
  HiPPO matrix A: projects history onto orthogonal polynomial basis

Information Geometry

Information geometry treats probability distributions as points on a curved Riemannian manifold, where the metric is the Fisher information. This reveals deep connections between statistics, geometry, and learning dynamics.

Statistical Manifold

Family of distributions: M = {p(x;θ) : θ ∈ Θ ⊂ ℝⁿ}
Fisher-Rao metric:  gᵢⱼ(θ) = E_{p(x;θ)}[∂ᵢ log p · ∂ⱼ log p]  = F(θ)ᵢⱼ
This is the unique monotone metric on statistical manifolds (Čencov 1982)
Geodesic = path of minimum "information cost" between distributions
Amari's α-connections:  ∇^{(α)} parameterises a family of connections
  α=+1:  e-geodesic (exponential family)
  α=−1:  m-geodesic (mixture family)
  α=0:   Levi-Civita (Riemannian)

Exponential Families

Exponential family:  p(x;η) = h(x) exp(ηᵀT(x) − A(η))
  η: natural parameters    T(x): sufficient statistics
  A(η): log-partition function (cumulant generating function)

∂A/∂ηᵢ = E[Tᵢ(x)]                  ← first moment = mean parameter
∂²A/∂ηᵢ∂ηⱼ = Cov[Tᵢ(x),Tⱼ(x)]     ← Hessian of A = Fisher info = Riemannian metric
Gaussian, Bernoulli, Poisson, Gamma all belong to exponential family
→ Softmax outputs are natural parameters of a Categorical exp. family

Dual Geometry & Bregman

Legendre transform: μ = ∇A(η),  η = ∇A*(μ)
  μ: expectation parameters (means);  η: natural parameters
Bregman divergence from A:
  D_A(μ‖μ') = A*(μ) − A*(μ') − ⟨∇A*(μ'), μ−μ'⟩
KL divergence = Bregman divergence of log-partition function A
Pythagorean theorem on statistical manifold:
  D_KL(p‖r) = D_KL(p‖q) + D_KL(q‖r)  if q = e-proj of p onto m-flat submanifold

Natural Gradient & Amari

Natural gradient:  θ̃ = F(θ)⁻¹ ∇_θ L
Steepest ascent in KL-divergence geometry, not Euclidean
Invariant to reparametrisation — Euclidean gradient is NOT

Efficient approximations:
  K-FAC:    F ≈ Σₗ A_{l-1} ⊗ G_l    ← Kronecker factored per layer
  Shampoo:  updates the factor matrices of K-FAC iteratively
  SOAP:     precondition in Shampoo basis; recent SOTA
  Muon:     orthogonalise gradients via Newton-Schulz — approx nat. grad.

Algebraic Topology for ML

Algebraic topology studies shape and connectivity with algebraic invariants. In ML it reveals the intrinsic structure of data, loss landscapes, and latent spaces.

Simplicial Complexes

A simplicial complex K is a collection of simplices (points, edges, triangles, …)
closed under face inclusion.
Vietoris-Rips complex VR(X,ε): add k-simplex when all pairwise distances ≤ ε
Čech complex Č(X,ε): add k-simplex when k+1 balls of radius ε have common point
Čech ⊂ VR ⊂ Č(2ε) — computationally, VR is preferred

Chain complex:  … → C_n → C_{n-1} → … → C_0 → 0
  ∂_n: C_n → C_{n-1}  (boundary operator),  ∂²=0
Homology:  H_n = ker(∂_n)/im(∂_{n+1})  ← n-cycles modulo n-boundaries
  H_0: connected components  H_1: loops  H_2: voids

Persistent Homology — Algorithm

1. Build filtration: K_0 ⊂ K_1 ⊂ … ⊂ K_m  (add simplices by ε)
2. Track homology classes: when does feature birth / death?
3. Persistence diagram: {(bᵢ,dᵢ)} for each homological feature
4. Bottleneck distance: d_∞(D,D') = min_{matching γ} max_i ‖pᵢ−γ(pᵢ)‖_∞
Stability theorem: ‖f−g‖_∞ ≥ d_∞(Dgm(f), Dgm(g))  ← robust to noise

Persistence images: vectorise diagram by convolving with Gaussians
PersLay / TopLayer: differentiable persistence for end-to-end learning

Discrete Morse Theory

Morse function f on simplicial complex K assigns values to simplices.
Critical simplex: has no lower/upper pairing → contributes to homology
Discrete gradient: matching of k-simplices with (k+1)-simplices
Topology of sublevel sets changes only at critical simplices
Used to analyse loss landscape topology: saddle points ↔ H_1 generators
Mode connectivity (Draxler 2018): minima connected by low-loss paths

Sheaf Theory & Neural Networks

A sheaf F on a topological space X assigns data F(U) to open sets U,
with consistent restriction maps F(U)→F(V) when V⊂U.
Cellular sheaf on graph G:  F(v)=ℝ^{d_v},  F(e)=ℝ^{d_e},  linear maps F_v⊴e
Sheaf Laplacian:  L_F = BᵀB  (B = coboundary operator weighted by F)
Generalises graph Laplacian — heterogeneous node/edge feature spaces
Sheaf Neural Networks (Hansen & Ghrist 2020):
  H_{k+1} = σ(L_F H_k W_k)   ← GCN with sheaf-valued diffusion

Stochastic Processes

From dropout (Bernoulli noise) to diffusion models (Brownian motion) to RL exploration (Markov chains), stochastic processes are the mathematical language of randomness over time in ML.

Brownian Motion & Wiener Process

Standard Brownian motion W(t): continuous-time stochastic process
  W(0) = 0
  W(t)−W(s) ~ N(0, t−s)  for t>s          ← independent increments
  Paths are continuous but nowhere differentiable (quadratic variation = t)
Geometric Brownian Motion:  dS = μS dt + σS dW
  S(t) = S(0) exp((μ−σ²/2)t + σW(t))      ← log-normal; stock prices
Ornstein-Uhlenbeck process:  dx = −θx dt + σ dW
  ← mean-reverting; forward process in DDPM/Score SDEs
  Stationary distribution: N(0, σ²/2θ)

Gaussian Processes

GP: f ~ GP(m, k)  ← infinite-dimensional distribution over functions
  m(x) = E[f(x)]              ← mean function
  k(x,x') = Cov[f(x),f(x')]  ← kernel / covariance function
GP Regression (posterior):
  f* | X,y,X* ~ N(μ*, Σ*)
  μ* = m(X*) + K_{*X}(K_{XX}+σ²I)⁻¹(y−m(X))
  Σ* = K_{**} − K_{*X}(K_{XX}+σ²I)⁻¹K_{X*}
Cost: O(n³) — approximate via inducing points (SVGP), random features
Deep kernels (Wilson 2016): k(x,x') = k_base(f_θ(x),f_θ(x'))
Infinitely-wide Bayesian NNs converge to GPs (Neal 1996, Lee 2018)

Point Processes

Poisson process:  N(t)~Poisson(λt);  inter-arrival ~ Exp(λ)
Hawkes process:   λ(t) = μ + Σ_{tᵢ← self-exciting
  φ(t) = α·e^{-βt}: each event temporarily increases intensity
Applications: user click sequences, neural spike trains, LLM token timing
Neural Temporal Point Processes:
  λ*(t) = softplus(w·h_t + b)  ← RNN or Transformer encodes history h_t
  Log-likelihood: ℓ = Σᵢ log λ*(tᵢ) − ∫₀^T λ*(t) dt

Martingales & Optional Stopping

Martingale:  E[Xₜ|ℱₛ] = Xₛ  for s≤t  ← "fair game"
Doob's maximal inequality:  P(max_{s≤t} Xₛ ≥ λ) ≤ E[Xₜ]/λ
Optional stopping theorem:  E[X_τ] = E[X₀] for bounded stopping time τ
Applications in ML:
  - Gradient estimates are martingale differences (unbiased SGD)
  - ERM generalisation analysis via martingale concentration
  - Early stopping criterion: stopping time τ on validation loss

Numerical Optimization Algorithms

Beyond gradient descent: the algorithmic machinery of second-order methods, constrained optimization, and the numerical tricks that make trillion-parameter training stable.

Quasi-Newton Methods

Newton's method:  θ ← θ − H⁻¹∇L   ← exact Hessian; O(n³) per step
L-BFGS (Limited-memory BFGS):
  Approximate H⁻¹ using last m gradient differences:
    sₖ = θₖ₊₁−θₖ,  yₖ = ∇Lₖ₊₁−∇Lₖ
    Hₖ₊₁ = (I−ρₖsₖyₖᵀ)Hₖ(I−ρₖyₖsₖᵀ) + ρₖsₖsₖᵀ
  m=10 pairs stored → O(mn) memory, superlinear convergence
Used for fine-tuning small models; default in scipy.optimize
BFGS SR1 update:  rank-1 correction; can violate PD but useful near saddles

Conjugate Gradient Method

Conjugate gradient (CG):  solve Ax=b for PD matrix A without forming A
  Residual: rₖ = b−Axₖ
  Direction: pₖ = rₖ + βₖ pₖ₋₁   where βₖ = ‖rₖ‖²/‖rₖ₋₁‖²
  Step:      αₖ = ‖rₖ‖²/(pₖᵀApₖ)
  Converges in ≤n steps exactly; in practice ≪n for clustered spectrum
Hessian-vector product:  Hv = d/dt[∇L(θ+tv)]|_{t=0}   ← O(n) via AD, no H storage
Used in: truncated Newton, conjugate-gradient descent, spectral norm power iter

Coordinate Descent & ADMM

Coordinate descent:  xᵢ ← argmin_{xᵢ} f(x)  (cycling through i)
Effective when subproblems are cheap: LASSO (soft threshold), SVM (SMO)

ADMM (Alternating Direction Method of Multipliers):
  min f(x)+g(z)  s.t. Ax+Bz=c
  x-update: x ← argmin_x {f(x) + (ρ/2)‖Ax+Bz−c+u‖²}
  z-update: z ← argmin_z {g(z) + (ρ/2)‖Ax+Bz−c+u‖²}
  u-update: u ← u + Ax+Bz−c
Separable updates → distributed/federated optimisation
Used in: consensus optimisation, model averaging, LASSO path
Steps: 0

Preconditioned Gradient Methods

Preconditioned update:  θ ← θ − η·P⁻¹∇L
  P = I:           vanilla GD
  P = diag(v̂):    Adam / RMSProp
  P = F(θ):        Natural gradient
  P = Kronecker F: K-FAC
  P = Shampoo:     full layer-wise Gram matrices

Spectral interpretation:
  Condition number κ(P⁻¹H) ≤ κ(H)  ← preconditioning stretches poorly-scaled axes
  Convergence rate: (1 − 1/κ)^t → need t ≈ κ steps without preconditioning

Stochastic Variance-Reduced Methods

SVRG:  ∇̃ₜ = ∇fᵢₜ(θₜ) − ∇fᵢₜ(θ̃) + ∇f(θ̃)    ← variance-reduced gradient
  Full gradient ∇f(θ̃) computed periodically; cost ≈ 2× SGD per epoch
  Convergence: linear rate O((n+κ)log(1/ε)) vs O(1/ε²) for SGD
SARAH / SpiderBoost:  recursive variance reduction; tighter bounds
STORM:  momentum-based variance reduction; no need for full gradient pass

Category Theory for ML

Category theory is the mathematics of mathematical structure. It provides a unified language for functors (neural network layers), monads (probabilistic programming), and string diagrams (differentiable programming).

Categories, Functors, Natural Transformations

Category C = (Ob(C), Hom(C), ∘, id)
  Objects: Ob(C);  Morphisms: f: A→B;  Composition: g∘f;  Identity: id_A
Functor F: C→D  maps objects to objects and morphisms to morphisms:
  F(g∘f) = F(g)∘F(f),  F(id_A) = id_{F(A)}
Natural transformation η: F⇒G  maps components ηₐ: F(A)→G(A)
  such that for all f:A→B,  G(f)∘ηₐ = η_B∘F(f)

Neural network view:
  Object = tensor type;  Morphism = differentiable function
  Composition = layer stacking;  Backprop = functor (cotangent functor)

Monads & Probabilistic Programming

Monad (T, η, μ) on category C:
  T: C→C  (endofunctor)
  η_A: A→T(A)  (unit / return)
  μ_A: T(T(A))→T(A)  (multiplication / join / bind)
  Satisfying: μ∘Tμ=μ∘μT,  μ∘Tη=μ∘ηT=id

Probability monad:  T(X) = probability distributions over X
  η(x) = δ_x (Dirac delta)    ← deterministic return
  μ = marginalisation (flatten mixture of mixtures)
Probabilistic programs = programs with stochastic bind (>>=)
Effect handlers in Pyro/NumPyro implement the probability monad

String Diagrams & Differentiable Programming

String diagrams: 2D graphical calculus for monoidal categories
  Wires = objects (tensor types)
  Boxes = morphisms (operations)
  Composition = vertical stacking
  Tensor product = horizontal juxtaposition

Computational graph = string diagram in the category of smooth maps
Automatic differentiation = applying the reverse derivative functor R:
  R[f: A→B] = (f, f̄): A×B*→A*   ← forward + backward pass together
Optic / lens formulation: (get,put) pairs model forward/backward AD
Categorical foundations of JAX's (jvp, vjp) primitives

Limits, Colimits & Architectures

Product A×B: universal object with projections π_A, π_B
  ← multi-head attention: separate Q,K,V projections then combine
Coproduct A⊔B: universal object with injections i_A, i_B
  ← skip connections / residual streams: branch + merge
Pullback:  shared computation before branching
  ← shared encoder in multi-task learning
Kan Extension:  best approximation of functor along another
  ← optimal feature transfer; theoretical basis of domain adaptation

Causal Inference & Causal ML

Correlation is not causation. Causal inference provides the mathematical framework to reason about interventions — essential for fair ML, off-policy RL, and scientific discovery.

Structural Causal Models (SCMs)

SCM M = (U, V, F, P_U):
  U = exogenous (noise) variables
  V = endogenous variables
  F = {fᵢ}: each vᵢ = fᵢ(Pa(vᵢ), uᵢ)   ← structural equations
  P_U = distribution over noise variables

Directed Acyclic Graph (DAG) G:  encodes causal structure
  Nodes = variables;  Edges = direct causal relationships
Markov condition:  each variable ⊥ non-descendants | parents
Faithfulness:  all conditional independences come from d-separation in G

Do-Calculus (Pearl)

Intervention do(X=x):  remove all edges INTO X; set X=x
  P(Y|do(X=x)) ≠ P(Y|X=x)  in general
Adjustment formula (backdoor criterion):
  P(Y|do(X)) = Σ_Z P(Y|X,Z)·P(Z)
  Z blocks all backdoor paths from X to Y

Three rules of do-calculus:
  1. Insertion/deletion of observations
  2. Action/observation exchange
  3. Insertion/deletion of actions
Any identifiable causal effect can be derived from these three rules

Front-door criterion:
  P(Y|do(X)) = Σ_M Σ_X' P(M|X')P(X')P(Y|X',M)
  ← when no Z blocks backdoor but mediator M is available

Potential Outcomes Framework (Rubin)

Y_i(t): potential outcome for unit i under treatment t ∈ {0,1}
Fundamental problem of causal inference:  only one of Y_i(0), Y_i(1) observed
ATE:  τ = E[Y(1)−Y(0)]  ← average treatment effect
ATT:  τ_T = E[Y(1)−Y(0)|T=1]  ← ATE on treated
CATE:  τ(x) = E[Y(1)−Y(0)|X=x]  ← heterogeneous; learned by T-learner, X-learner

Ignorability (unconfoundedness):  Y(0),Y(1) ⊥ T | X
  ← no unmeasured confounders given covariates X
IPW estimator:  τ̂ = (1/n)Σᵢ [TᵢYᵢ/e(Xᵢ) − (1−Tᵢ)Yᵢ/(1−e(Xᵢ))]
  e(x) = P(T=1|X=x)  ← propensity score

Causal Discovery & ML

PC algorithm:  start with complete graph; remove edges by CI tests
FCI:  allows latent confounders; outputs PAG (partial ancestral graph)
NOTEARS:  min ‖X−XWᵀ‖² s.t. h(W)=0  ← h(W)=tr(e^W)−d encodes acyclicity
Turns DAG learning into continuous optimisation — trainable!

Causal representation learning:
  Learn z = encoder(x) such that z respects causal structure of the DGP
  iVAE: identifiable VAE with auxiliary variables (labels, domains)
  CITRIS: temporal causal structure from time-series videos
Invariant Risk Minimisation (IRM):
  min Σ_e R^e(Φ)  s.t.  W* ∈ argmin_W R^e(W∘Φ)  for all e
  ← learn representation Φ where same classifier W* is optimal across envs

Off-Policy Evaluation (OPE) in RL

OPE:  estimate V^{π_e} using data from π_b (behaviour policy)
IS estimator:  V̂_IS = (1/n)Σ_τ ρ(τ)·R(τ)
  ρ(τ) = Π_t π_e(aₜ|sₜ)/π_b(aₜ|sₜ)  ← importance weights; high variance
Doubly robust (DR):
  V̂_DR = V̂_DM + (1/n)Σ ρₜ(rₜ+γV̂(sₜ₊₁)−Q̂(sₜ,aₜ))
  ← consistent if EITHER Q̂ OR ρ is correct → doubly robust
Connection: OPE = causal inference with time-varying treatments
