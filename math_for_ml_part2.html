Limits & Continuity Foundations

f is continuous at a iff lim_{x→a} f(x) = f(a). Critical for activation functions: ReLU is continuous but not differentiable at 0 — its subgradient is used instead.

-- Lipschitz continuity (used in GAN training): |f(x) - f(y)| ≤ L·‖x - y‖ ∀ x,y -- L = Lipschitz constant -- Ensures gradients can't explode unboundedly -- Enforced by spectral norm, gradient penalty
Mean Value & Intermediate Value Theorems

MVT: ∃ c ∈ (a,b) with f'(c) = (f(b)−f(a))/(b−a). Powers convergence proofs for gradient descent: if f is L-smooth, GD with α≤1/L converges.

-- L-smoothness (key for GD analysis): ‖∇f(x) - ∇f(y)‖ ≤ L‖x - y‖ f(y) ≤ f(x) + ∇f(x)ᵀ(y-x) + L/2‖y-x‖² -- GD with α=1/L: f(xₜ₊₁) ≤ f(xₜ) - 1/2L‖∇f‖²

-- Directional derivative in direction u (‖u‖=1): D_u f(x) = ∇f(x)ᵀu = lim_{h→0} [f(x+hu) - f(x)] / h -- Gradient ∇f: vector of partials — points uphill -- Jacobian J ∈ ℝ^(m×n): all first partials of f: ℝⁿ→ℝᵐ -- Hessian H ∈ ℝ^(n×n): all second partials (symmetric if C²) -- Second-order Taylor (loss landscape): f(x+δ) ≈ f(x) + ∇f(x)ᵀδ + ½δᵀHδ + O(‖δ‖³) -- δᵀHδ > 0 everywhere → local min (bowl) -- δᵀHδ < 0 somewhere → saddle point

Information-Theoretic Quantities
-- Shannon entropy (bits of surprise): H(X) = -Σₓ p(x) log₂ p(x) = -E[log p(X)] -- H=0: deterministic. H=log₂K: uniform over K outcomes -- Cross-entropy (what we minimise in classification): H(P,Q) = -Σₓ p(x) log q(x) = H(P) + D_KL(P‖Q) -- KL divergence (info gained switching P→Q): D_KL(P‖Q) = Σₓ p(x) log[p(x)/q(x)] ≥ 0 (Gibbs) -- Not symmetric! D_KL(P‖Q) ≠ D_KL(Q‖P) -- =0 iff P=Q. Used in VAE: D_KL(q(z|x)‖p(z)) -- Mutual information: I(X;Y) = H(X) - H(X|Y) = D_KL(p(x,y)‖p(x)p(y)) -- =0 iff X⊥Y. Measures dependency without assuming linearity -- Used in IB (information bottleneck), contrastive SSL -- Jensen-Shannon divergence (symmetric, bounded): JSD(P‖Q) = ½D_KL(P‖M) + ½D_KL(Q‖M), M=(P+Q)/2 -- JSD ∈ [0,1]. √JSD is a metric. Used in original GAN
ELBO — The Variational Lower Bound VAEs
1
The problem
We want log p(x) = log ∫ p(x|z)p(z)dz. The integral is intractable — we can't compute it directly for deep networks.
2
Introduce variational posterior q(z|x)
Approximate the true posterior p(z|x) with a tractable q(z|x) (e.g. diagonal Gaussian). The encoder in a VAE outputs the parameters of q.
3
Derive the ELBO by Jensen's inequality
log p(x) ≥ E_{q(z|x)}[log p(x|z)] − D_KL(q(z|x)‖p(z)) = ELBO. The reconstruction term + KL regularisation. Maximise ELBO ↔ minimise VAE loss.
4
Reparameterisation trick
z = μ + σ·ε, ε~𝒩(0,I). Moves the stochasticity out of the graph so gradients flow through μ and σ. Critical for backprop through sampling.
-- VAE objective (maximise): ELBO = E_{q(z|x)}[log p(x|z)] - D_KL(q(z|x)‖p(z)) = Reconstruction - KL regularisation -- β-VAE: weight KL by β>1 for disentanglement -- log p(x) = ELBO + D_KL(q(z|x)‖p(z|x)) [gap = posterior gap]
Contrastive Learning & MI Maximisation SimCLR / CLIP

Self-supervised contrastive methods (SimCLR, MoCo, CLIP) are implicitly maximising mutual information between different views of the same sample.

-- InfoNCE loss (van den Oord 2018): L = -E[ log( exp(f(x)ᵀf(x⁺)/τ) / Σⱼ exp(f(x)ᵀf(xⱼ)/τ) ) ] -- τ = temperature, x⁺ = positive pair -- Minimising InfoNCE ≈ maximising I(z; z⁺) -- Numerator: push representations of same image close -- Denominator: push away from N-1 negatives (in-batch)
04 — Optimisation Theory

Convexity & Optimisation Geometry

Convexity, saddle points, Lagrange multipliers, duality — the mathematical scaffolding that tells us when and why optimisation algorithms work.

Convexity Visualiser — f(x) and its Tangent LinesGeometry

A function is convex if every chord lies above the function. Equivalently: f(λx + (1−λ)y) ≤ λf(x) + (1−λ)f(y). Convex functions have no local-but-not-global minima — gradient descent always finds the optimum.

Function:
Lagrangian & KKT Conditions Constrained Opt

Constrained optimisation: minimise f(x) subject to g(x)≤0, h(x)=0. The Lagrangian encodes constraints as penalty terms. KKT conditions are the first-order optimality conditions.

-- Lagrangian: L(x, λ, μ) = f(x) + λᵀg(x) + μᵀh(x) -- KKT conditions (necessary for optimality): 1. ∇_x L = 0 -- stationarity 2. g(x) ≤ 0 -- primal feasibility 3. λ ≥ 0 -- dual feasibility 4. λᵢgᵢ(x) = 0 ∀i -- complementary slackness 5. h(x) = 0 -- equality feasibility -- SVM: maximise margin ↔ minimise ½‖w‖² s.t. yᵢ(wᵀxᵢ+b)≥1 -- KKT gives: w = Σᵢ λᵢ yᵢ xᵢ (support vectors: λᵢ>0)
Duality Primal / Dual

The dual problem provides a lower bound on the primal (weak duality). For convex problems with Slater's condition, strong duality holds: primal = dual. SVMs are solved in the dual.

g(λ,μ) = inf_x L(x,λ,μ) -- dual function g(λ,μ) ≤ p* -- weak duality -- Strong duality: g(λ*,μ*) = p* = d*
Saddle Points Non-convex

Deep networks have exponentially many saddle points (∇f=0 but not a min). Their presence slows training; second-order methods and noise help escape them.

x* is saddle: ∇f(x*) = 0 H has mixed signs -- some λ>0, some λ<0 -- Gradient noise helps escape (SGD > GD) -- Most critical points in deep nets are saddles
Convergence Rate ComparisonAnalysis

Different problem structures yield different convergence guarantees. Convexity and smoothness are the key conditions.

-- Convergence rates for GD (after T steps): Convex + L-smooth: f(xₜ) - f* ≤ O(1/T) Strongly convex (μ>0): f(xₜ) - f* ≤ O((1-μ/L)ᵀ) -- linear Non-convex + smooth: ‖∇f(xₜ)‖² ≤ O(1/T) -- stationary pt -- κ = L/μ (condition number) governs rate for strongly convex -- Momentum (Nesterov): O(1/T²) for convex — optimal!
05 — Functional Analysis

Hilbert Spaces & Functional Analysis

Functions as vectors in infinite-dimensional spaces. The inner-product structure of Hilbert spaces powers kernel methods, Gaussian processes, and operator theory.

Inner Product Spaces ⟨f,g⟩

A Hilbert space ℋ generalises ℝⁿ to (possibly infinite) sequences or functions. The inner product defines geometry: angles, orthogonality, projections.

-- Inner product axioms: ⟨f,g⟩ = ⟨g,f⟩* -- conjugate symmetry ⟨αf+g,h⟩ = α⟨f,h⟩+⟨g,h⟩ -- linearity ⟨f,f⟩ ≥ 0, =0 iff f=0 -- positive definite -- L²([0,1]) example: ⟨f,g⟩ = ∫₀¹ f(x)g(x) dx ‖f‖ = √⟨f,f⟩
Cauchy-Schwarz & Parseval Inequalities

The most important inequality in Hilbert spaces. Also the origin of attention's dot-product similarity measure.

|⟨f,g⟩| ≤ ‖f‖·‖g‖ -- Cauchy-Schwarz -- Parseval's identity (energy conservation): Σₙ |⟨f,eₙ⟩|² = ‖f‖² -- Total energy = sum of squared Fourier coefficients -- Basis of FFT efficiency in signal processing
Reproducing Kernel Hilbert Spaces (RKHS) Kernel Methods

An RKHS is a Hilbert space where evaluation is a continuous linear functional. The reproducing kernel k(x,y) is the "inner product in feature space" — without ever computing the (infinite-dimensional) feature map.

-- Reproducing property: f(x) = ⟨f, k(·,x)⟩_ℋ -- evaluation as inner product! k(x,y) = ⟨φ(x), φ(y)⟩ -- kernel = feature-space inner product -- Representer theorem (key result): -- Any solution to min_{f∈ℋ} Σᵢ L(yᵢ,f(xᵢ)) + λ‖f‖² -- has the form: f*(x) = Σᵢ αᵢ k(xᵢ, x) -- Infinite-dim optimisation reduces to n-dim! -- Mercer's theorem: k PSD ↔ valid kernel ↔ RKHS exists -- Neural tangent kernel: k_NTK(x,x') as width → ∞
Linear Operators & Spectral Theory Infinite-dim Matrices

Linear maps between function spaces generalise matrices. The integral operator (Tf)(x) = ∫k(x,y)f(y)dy has eigenvalues/eigenfunctions just like a matrix — and this is the foundation of kernel PCA, Gaussian processes, and spectral methods.

-- Integral operator with kernel k: (Tf)(x) = ∫ k(x,y) f(y) dy -- If k PSD, T is compact, positive, self-adjoint -- Spectral decomp: Tφᵢ = λᵢφᵢ (Mercer's expansion) k(x,y) = Σᵢ λᵢ φᵢ(x) φᵢ(y) -- Gaussian process: f ~ GP(m, k) means f(x₁,...,xₙ ~ 𝒩(m(x), K) K[i,j] = k(xᵢ,xⱼ) -- the covariance matrix IS the kernel

Riemannian Metric Curvature

A Riemannian manifold (ℳ, g) equips each tangent space with an inner product g. The metric tensor g determines distances, angles, and curvature.

-- Infinitesimal distance: ds² = gᵢⱼ dxⁱ dxʲ -- metric tensor -- Euclidean: gᵢⱼ = δᵢⱼ (flat, identity) -- Fisher: gᵢⱼ = 𝓕ᵢⱼ (statistical manifold) -- Geodesic = shortest path on manifold -- Exponential map: exp_x(v) = curve from x in dir v -- Log map: log_x(y) = tangent vector pointing to y
Natural Gradient Fisher Metric

Standard gradient descent ignores the geometry of the parameter space. Natural gradient uses the Fisher information matrix as the metric, taking the steepest descent in distribution space.

-- Natural gradient update: θ ← θ - α 𝓕(θ)⁻¹ ∇L(θ) -- 𝓕(θ) = E[∇log p · ∇log pᵀ] -- Invariant to reparameterisation! -- K-FAC ≈ natural gradient, tractable -- Adam ≈ diagonal natural gradient (heuristic)
Normalising Flows — Change of Variables Generative Models

A normalising flow transforms a simple base distribution p₀(z) into a complex target p(x) via an invertible differentiable map f. The key formula is the change of variables — involving the Jacobian determinant.

-- If x = f(z), f invertible, z ~ p₀: log p(x) = log p₀(f⁻¹(x)) + log|det J_{f⁻¹}(x)| = log p₀(z) - log|det J_f(z)| -- Jacobian determinant: volume change factor -- Triangular Jacobians (RealNVP, Glow): O(n) det computation -- Continuous NF (FFJORD): det via Hutchinson trace estimator -- Training objective (max log-likelihood): max E_x[ log p₀(f⁻¹(x)) + log|det J_{f⁻¹}(x)| ]
Lie Groups & Symmetry in Deep Learning Equivariance

Lie groups (smooth manifolds with group structure) formalise symmetries. CNNs are equivariant to translation; equivariant networks (SE(3)-Transformer, E(n)-GNN) build in rotation/reflection symmetry.

-- Group equivariance: f(T_g · x) = T_g' · f(x) ∀ g ∈ G -- If G = translation: CNNs are equivariant -- If G = SO(3): SE(3) networks for molecular geometry -- Lie algebra: tangent space at identity -- Exp map: so(3) → SO(3) (rotation matrices from angles) -- Rodrigues formula: R = I + sin(θ)K + (1-cos θ)K² -- Group convolution: (f★k)(g) = Σ_{h∈G} f(h) · k(g⁻¹h)

PAC Learning & Generalisation Bounds Theory
-- PAC (Probably Approximately Correct) learning: -- A learner PAC-learns ℋ if ∀ε,δ>0, ∃ sample complexity m(ε,δ) s.t. -- with n≥m(ε,δ) samples: P(R(h) ≤ R*(h) + ε) ≥ 1-δ -- Generalisation bound (finite hypothesis class): R(h) ≤ R̂(h) + √( log(|ℋ|/δ) / 2n ) -- R(h): true risk. R̂(h): empirical risk. -- VC dimension bound: R(h) ≤ R̂(h) + O( √( (VC(ℋ)·log(n/VC(ℋ)) + log(1/δ)) / n ) ) -- Rademacher complexity (tighter, distribution-dependent): R(h) ≤ R̂(h) + 2ℛₙ(ℋ) + 3√(log(2/δ)/2n) ℛₙ(ℋ) = E_σ[sup_{h∈ℋ} (1/n) Σᵢ σᵢ h(xᵢ)] -- σᵢ ∈ {±1} Rademacher vars. Measures class richness.

Double Descent & Modern ML Overparameterisation

Classical statistics: more parameters → overfitting. Modern ML breaks this. Beyond the interpolation threshold, test error decreases again — the "double descent" phenomenon.

-- Classical regime: n > p (underparameterised) -- Bias-variance tradeoff applies, optimal complexity exists -- Interpolation threshold: n ≈ p -- Model perfectly fits training data; test error peaks -- Overparameterised regime: p >> n -- Many solutions fit training data; SGD finds the minimum norm -- Implicit regularisation: ‖θ‖ minimised by GD on linear models -- Benign overfitting: interpolating the noise can still generalise -- Epoch-wise double descent also observed during training!
08 — Signal Processing

Fourier Analysis & Signals

The Fourier transform decomposes signals into frequencies. Convolution in time = multiplication in frequency. This underpins CNNs, spectral graph methods, and audio ML.

Fourier Decomposition — Build a Signal from SinusoidsInteractive

Any periodic signal can be built from sine waves at different frequencies (harmonics). Adjust amplitudes to construct signals — this is what the DFT computes.

Convolution Theorem CNNs
-- Time domain convolution = frequency domain multiplication: (f * g)(t) = ∫ f(τ)g(t-τ)dτ ←→ F(ω)·G(ω) -- Cross-correlation (CNN "convolution"): (f ⋆ g)(t) = ∫ f(τ)g(τ+t)dτ ←→ F*(ω)·G(ω) -- DFT: X[k] = Σₙ x[n] e^(-i2πkn/N) (O(N²)) -- FFT: same result in O(N log N) via Cooley-Tukey -- CNN as spectral filter: -- Each filter bank learns to detect a frequency pattern -- Strided convolution ≈ downsampling in frequency -- Spectral conv on graphs: multiply eigenvectors of L
Nyquist-Shannon Sampling Theorem Aliasing

A bandlimited signal with maximum frequency f_max can be perfectly reconstructed from samples at rate ≥ 2f_max (Nyquist rate). Aliasing occurs when this is violated.

f_s ≥ 2 · f_max -- Nyquist criterion -- In CNNs: strided conv / pooling can alias -- Anti-aliasing CNNs blur before downsampling -- Attention: no downsampling, no aliasing problem
Wavelets & Multi-resolution Localised

Wavelets are localised in both time and frequency — unlike Fourier (localised in freq only). Used in image compression, U-Net skip connections, and scattering transforms.

ψ_{a,b}(t) = 1/√a · ψ((t-b)/a) -- a = scale, b = translation Wf(a,b) = ⟨f, ψ_{a,b}⟩ = ∫ f(t) ψ*_{a,b}(t) dt -- Scattering transform: cascade of wavelets + |·|
Sinusoidal Positional Encodings — Fourier Basis in Transformers Transformers

The original Transformer (Vaswani 2017) encodes position using sinusoids at different frequencies. The model can represent any relative offset as a linear combination, leveraging the Fourier structure.

PE(pos, 2i) = sin(pos / 10000^(2i/d)) PE(pos, 2i+1) = cos(pos / 10000^(2i/d)) -- i = dimension index, d = model dimension -- Low i → high freq (fine position), high i → low freq (coarse) -- Key property: PE(pos+k) = M_k · PE(pos) -- M_k is a fixed rotation matrix -- So the model CAN represent relative offset k as a linear op -- This motivated RoPE: make the rotation position-dependent

Higher-Order Derivatives MAML

Differentiating through the optimisation process itself. MAML computes ∂²L/∂θ² to learn an initialisation that adapts in few steps.

-- MAML inner loop: θ' = θ - α∇_θ L_task(θ) -- Outer loop (through inner!): ∇_θ L_meta(θ') = ∂²L/∂θ² · ∇L -- Requires Hessian-vector products -- Approx: first-order MAML drops this
Hessian-Vector Products Efficient

Computing the full n×n Hessian is O(n²). But Hv (product with a vector) can be computed in O(n) — same cost as one gradient — using reverse-over-forward AD.

-- Exact Hessian: O(n²) time and space -- Hessian-vector product Hv: Hv = ∇(∇f · v) -- reverse of forward Cost: O(cost(f)) -- same as gradient! -- Enables conjugate gradient, Lanczos, KFAC
10 — Foundations

Measure Theory & Integration

The rigorous foundation beneath probability and calculus. Lebesgue integration, σ-algebras, and the Radon-Nikodym theorem unify discrete and continuous probability — and explain why KL divergence sometimes diverges.

σ-algebras, Measurable Functions & Probability Spaces
-- Probability space: (Ω, ℱ, P) Ω = sample space -- all outcomes ℱ = σ-algebra -- events we can assign probability to P: ℱ → [0,1] -- probability measure, P(Ω)=1 -- σ-algebra ℱ must be closed under: 1. Ω ∈ ℱ 2. A ∈ ℱ → Aᶜ ∈ ℱ -- complement 3. A₁,A₂,… ∈ ℱ → ∪Aᵢ ∈ ℱ -- countable union -- Random variable: X: Ω → ℝ measurable -- Measurable: X⁻¹(B) ∈ ℱ for all Borel sets B
Lebesgue vs Riemann Integration Why It Matters

Lebesgue integration partitions the range rather than the domain. It handles discontinuous functions, defines expectations rigorously, and works on abstract spaces (not just ℝ).

-- Riemann: partition domain [a,b] ∫ f ≈ Σᵢ f(xᵢ*) Δxᵢ -- Lebesgue: partition range ∫ f dμ = ∫₀^∞ μ({x: f(x) > t}) dt -- Works for any measure μ, any space -- E[X] = ∫ X dP is Lebesgue integral
Radon-Nikodym Theorem KL / Likelihood

If P is absolutely continuous w.r.t. Q (P≪Q), there exists a density dP/dQ. This is the theoretical basis for change-of-measure in importance sampling and why KL(P‖Q) = +∞ when Q(A)=0 but P(A)>0.

P ≪ Q: Q(A)=0 ⟹ P(A)=0 -- abs. continuity -- Radon-Nikodym density: dP/dQ = p(x)/q(x) -- likelihood ratio P(A) = ∫_A (dP/dQ) dQ -- KL divergence in measure-theoretic form: D_KL(P‖Q) = ∫ log(dP/dQ) dP -- = +∞ if P ≢ Q (support mismatch!)
Wasserstein Distance & Optimal Transport GANs / Geometry

KL divergence breaks when distributions have non-overlapping support (mode collapse in GANs). The Wasserstein distance — earth mover's distance — is geometrically meaningful even then. It's the cost of transporting one distribution to another.

-- Wasserstein-1 (Earth Mover's Distance): W₁(P,Q) = inf_{γ ∈ Γ(P,Q)} ∫ ‖x-y‖ dγ(x,y) -- Γ(P,Q): all joint distributions with marginals P,Q -- γ = transport plan (how to move mass) -- Kantorovich-Rubinstein duality (tractable form): W₁(P,Q) = sup_{‖f‖_L ≤ 1} E_P[f(x)] - E_Q[f(x)] -- f Lipschitz-1: WGAN discriminator! -- Enforced by weight clipping or gradient penalty (WGAN-GP) -- W₂ (Wasserstein-2): used in OT-based generative models, flow matching

An SDE describes a process driven by both deterministic drift and Brownian noise. The Itô integral gives a rigorous meaning to integrals against W(t).

-- General SDE (Itô form): dX = f(X,t)dt + g(X,t)dW ↑ drift term ↑ diffusion term -- Itô's Lemma (chain rule for SDEs): dV(X,t) = (∂V/∂t + f·∂V/∂x + ½g²·∂²V/∂x²)dt + g·∂V/∂x·dW -- Ornstein-Uhlenbeck process (mean-reverting): dX = -θXdt + σdW → stationary dist 𝒩(0, σ²/2θ) -- Used in DDPM forward process: Xₜ = √(ᾱₜ)X₀ + √(1-ᾱₜ)ε -- Score-based diffusion (Song et al. 2020): dx = [f(x,t) - g(t)²∇_x log pₜ(x)]dt + g(t)dW̄ (reverse SDE) -- ∇_x log pₜ(x) = score function — what the denoiser learns

Martingales Fair Game

A martingale is a process where the expected future value equals the current value: E[Xₜ₊₁|X₁,…,Xₜ] = Xₜ. Central to financial math, MCMC convergence proofs, and reinforcement learning.

E[Xₜ₊₁ | ℱₜ] = Xₜ -- martingale property -- Optional stopping theorem: E[X_τ] = E[X₀] for stopping time τ -- Doob's martingale inequality: P(max_{0≤t≤T} Xₜ ≥ λ) ≤ E[Xₜ]/λ
Markov Chain Monte Carlo Sampling

MCMC constructs a Markov chain whose stationary distribution is the target p(x). Detailed balance ensures convergence. Metropolis-Hastings, HMC, and NUTS are the workhorses.

-- Detailed balance (ensures πP = π): π(x)P(x→y) = π(y)P(y→x) -- Metropolis-Hastings acceptance: α = min(1, p(x')q(x|x')/p(x)q(x'|x)) -- HMC: leapfrog integrator, No-U-Turn (NUTS)
Poisson Processes & Point Processes Events in Time

A Poisson process counts random events arriving at rate λ. The number of events in [0,t] is Poisson(λt). Point processes generalise this to arbitrary event spaces — used in neural event models and spatial statistics.

Diffusion Models — Full Mathematical Picture DDPM / Score Matching
1
Forward process: gradually destroy information
q(xₜ|xₜ₋₁) = 𝒩(√(1-βₜ)xₜ₋₁, βₜI). After T steps: xₜ ≈ 𝒩(0,I). By reparameterisation: xₜ = √ᾱₜ x₀ + √(1-ᾱₜ) ε, ε~𝒩(0,I). Can sample any xₜ in one shot.
2
Score matching objective
Train denoiser ε_θ(xₜ, t) to predict the noise ε. This is equivalent to learning the score: s_θ(xₜ,t) ≈ ∇_{xₜ} log p(xₜ) = -ε/√(1-ᾱₜ). Loss: E[‖ε - ε_θ(xₜ, t)‖²].
3
Reverse process: learned denoising
p_θ(xₜ₋₁|xₜ) = 𝒩(μ_θ(xₜ,t), σₜ²I). The mean μ_θ is derived from the noise prediction: μ_θ = (1/√αₜ)(xₜ - βₜ/√(1-ᾱₜ) ε_θ(xₜ,t)). Iteratively denoise from xₜ to x₀.
4
DDIM — deterministic sampling
DDIM replaces the Markov chain with a deterministic ODE solver. This allows 10–50 NFE (function evaluations) instead of 1000, while maintaining sample quality. The ODE is: dx = [f(x,t) - ½g(t)² s_θ(x,t)]dt.
-- Noise schedule: βₜ ∈ [β₁, βₜ], ᾱₜ = ∏ᵢ(1-βᵢ) -- Training loss (simplified): L = E_{t,x₀,ε}[‖ε - ε_θ(√ᾱₜ x₀ + √(1-ᾱₜ)ε, t)‖²] -- Classifier-free guidance (CFG): ε̃ = ε_θ(xₜ,∅) + w·(ε_θ(xₜ,c) - ε_θ(xₜ,∅)) -- w>1 trades diversity for fidelity
Flow Matching & Rectified Flows Generative ODEs

Flow matching trains a vector field v_θ(x,t) whose induced ODE dx/dt = v_θ(x,t) transports samples from a simple p₀ to the data distribution p₁ in a single straight path — faster sampling than diffusion.

-- Conditional flow matching (Lipman et al. 2022): L_CFM = E_{t,x₀,x₁}[‖v_θ(xₜ,t) - (x₁-x₀)‖²] xₜ = (1-t)x₀ + t·x₁ -- straight-line interpolation -- Rectified flow (Liu et al. 2022): -- Straighten trajectories by iterative reflow: (x₀, x₁) ← (x₀, ODE(x₀)) -- resample from flow -- After k iterations: nearly straight paths → 1-NFE sampling -- Connection to SDE: -- Flow matching = probability flow ODE of score SDE -- Both parameterise the same generative process
Normalising Flow Architectures — Volume PreservationExact Likelihood

Different flow architectures compute log|det J| differently. The key design constraint: make the Jacobian triangular or structured so its determinant is O(n) rather than O(n³).

-- Coupling layer (RealNVP): y₁ = x₁ -- identity y₂ = x₂ · exp(s(x₁)) + t(x₁) -- affine J = [[I, 0], [*, diag(exp(s(x₁)))]] -- triangular! log|det J| = Σ s(x₁)[i] -- O(n) -- Autoregressive flow (MAF / IAF): yᵢ = f(xᵢ; x₁,...,xᵢ₋₁) -- sequential dependency -- J is triangular → O(n) det; but slow sampling (sequential) -- Residual flow: y = x + g(x), ‖Jg‖ < 1 log|det J| ≈ Σₖ (-1)^(k+1)/k · tr((Jg)ᵏ) (power series)
15 — Numerical Linear Algebra

Numerical Linear Algebra

The algorithms that actually compute matrix operations at scale. Iterative solvers, preconditioning, and modern GPU-aware algorithms are what separate theory from production systems.

Conjugate Gradient — Krylov Subspace MethodsIterative Solver

Conjugate Gradient solves Ax=b for symmetric positive-definite A without forming A⁻¹. It takes at most n steps but often converges in √κ steps — much faster than Gauss-Seidel. Used in second-order optimisers.

↑ Click to step the conjugate gradient algorithm

-- CG algorithm (minimises ½xᵀAx - bᵀx): 1. r₀ = b - Ax₀, p₀ = r₀ 2. αₖ = rₖᵀrₖ / pₖᵀApₖ -- optimal step size 3. xₖ₊₁ = xₖ + αₖpₖ 4. rₖ₊₁ = rₖ - αₖApₖ 5. βₖ = rₖ₊₁ᵀrₖ₊₁ / rₖᵀrₖ 6. pₖ₊₁ = rₖ₊₁ + βₖpₖ -- A-conjugate direction -- Convergence: ‖xₖ-x*‖_A ≤ 2·((√κ-1)/(√κ+1))ᵏ·‖x₀-x*‖_A
Preconditioning Reduce κ

Replace Ax=b with M⁻¹Ax=M⁻¹b where M≈A is easy to invert. A good preconditioner reduces κ(M⁻¹A) ≪ κ(A), dramatically speeding up iterative solvers.

-- Diagonal preconditioner: M = diag(A) -- cheap but effective -- Incomplete LU (ILU): M ≈ LU (sparse, drop small entries) -- Adam as diagonal preconditioner: M = diag(√v̂ + ε) ← 2nd moment EMA -- Effective κ(M⁻¹∇²L) ≈ 1
BLAS Levels & GPU Efficiency Hardware

Matrix operations map onto three levels of BLAS. BLAS 3 (matmul) maximises arithmetic intensity — the key to GPU efficiency. Deep learning is BLAS-3 dominated by design.

-- BLAS 1: O(n) ops, O(n) mem → low intensity -- BLAS 2: O(n²) ops, O(n²) mem → matrix-vector -- BLAS 3: O(n³) ops, O(n²) mem → high intensity -- Arithmetic intensity = FLOPs/bytes -- matmul (n=4096): 128 FLOPs/byte → GPU roofline ✓ -- Fused kernels (FlashAttn): keep data in SRAM
Randomised Numerical Linear Algebra Sketching

Randomised algorithms approximate matrix operations orders of magnitude faster than deterministic counterparts. Sketching reduces an m×n matrix to a k×n sketch, preserving geometry with high probability.

-- Randomised SVD (Halko et al. 2011): 1. Draw Ω ∈ ℝ^(n×k), k = r + oversampling 2. Y = AΩ (sketch: m×k matrix) 3. [Q,_] = QR(Y) (orthonormal basis for range) 4. B = QᵀA (k×n) 5. [Û,Σ,Vᵀ] = SVD(B) (exact, small) 6. U = QÛ Cost: O(mnk) vs O(mn²) — huge saving for r ≪ n -- Hutchinson trace estimator: tr(A) ≈ (1/s) Σᵢ εᵢᵀ A εᵢ, εᵢ ~ Rademacher -- Used in FlashAttention, FFJORD log-det estimation -- Count Sketch / JL projection: S ∈ ℝ^(k×n), k = O(1/ε²) preserves ‖Ax‖² ± ε‖A‖²‖x‖²
Matrix Multiplication Algorithms Strassen & Beyond

The naive matmul is O(n³). Strassen achieves O(n^2.807). Recent work (DeepMind AlphaTensor, 2022) found faster algorithms by framing matmul as a tensor decomposition problem.

-- Naive: n³ multiplications for n×n matmul -- Strassen: 7 mults for 2×2 block (vs 8) -- recurrence: T(n) = 7T(n/2) → O(n^log₂7) ≈ O(n^2.807) -- AlphaTensor (2022): discovered new algorithms -- 4×4 matmul in 47 mults (vs 49 previously) -- Framed as: find rank decomposition of matmul tensor 〈n,m,p〉 -- 〈n,m,p〉 = Σᵣ u_r ⊗ v_r ⊗ w_r (CP decomp) -- Current best: ω < 2.371 (Le Gall 2024) -- Practical: cuBLAS uses Tensor Cores (4×4 tiles in FP16)
16 — Category Theory

Category Theory for ML

Categories abstract the essence of mathematical structure. Functors, natural transformations, and monads formalise composition, equivariance, and sequential computation — appearing in functional programming and differentiable programming.

Categories, Functors & Natural Transformations Abstraction

A category has objects and morphisms (arrows) with associative composition. Functors map between categories preserving structure. Natural transformations are morphisms between functors.

-- Category C: objects Obj(C), morphisms Hom(A,B) -- composition: g∘f, identity: id_A -- Functor F: C→D maps objects and morphisms -- F(g∘f) = F(g)∘F(f), F(id_A) = id_{F(A)} -- Natural transformation η: F→G -- η_A: F(A)→G(A) (component for each object) -- commutes: G(f)∘η_A = η_B∘F(f) -- Yoneda lemma: an object is determined by -- all morphisms into it (representable functors)
Monads & Kleisli Composition Sequential Effects

A monad is a functor T with unit η: Id→T and multiplication μ: T²→T satisfying coherence laws. Monads model computational effects: probability, state, I/O, nondeterminism.

-- Monad: (T, η, μ) -- return: A → T(A) η_A -- bind: T(A) → (A→T(B)) → T(B) -- Probability monad: T(A) = Dist(A) -- State monad: T(A) = S → (A × S) -- Maybe monad: T(A) = A ∪ {⊥} -- Kleisli category: morphisms A→T(B) -- compose with >>=: sequential programs
Differentiable Programming & Categorical Semantics JAX / PyTorch

AD frameworks like JAX are built on categorical foundations. The forward derivative is a functor from the category of smooth maps to the category of tangent bundles. Reverse AD is the adjoint of this functor.

-- Cartesian closed category (CCC): models simply-typed λ-calculus -- Smooth maps form a category SmoothMan -- Forward AD functor: T_fwd: SmoothMan → SmoothMan -- T_fwd(f) = (f, Jf) (value and Jacobian) -- Reverse AD: adjoint functor T_rev -- T_rev(f) = (f, Jfᵀ) (value and Jacobian transpose) -- JAX's vmap: natural transformation between functors -- vmap(f): applies f over a batch axis automatically -- jit(f): functorial transformation (same semantics, faster) -- grad(f) = reverse-mode AD functor applied to f -- Optic/Lens framework: bidirectional data accessor -- (get, put) pair = forward pass + backward pass
String Diagrams — Visualising Tensor Contractions Diagrammatic

String diagrams are a 2D graphical calculus for monoidal categories. They make tensor contractions, compositions, and network architectures visually precise — the same formalism used in quantum computing circuit diagrams.

-- Wires = types (tensors), boxes = morphisms (operations) -- Composition = vertical stacking (sequential) -- Tensor product = horizontal juxtaposition (parallel) -- Trace = wire loops back (contraction / recurrence) -- RNN unrolled in time = string diagram with trace -- Attention = string diagram: Q⊗K⊗V → Output
