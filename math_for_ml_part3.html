Counting Principles Rules
-- Product rule: |A × B| = |A|·|B| -- Sum rule: |A ∪ B| = |A|+|B| (disjoint) -- Inclusion-exclusion: |A∪B| = |A|+|B|-|A∩B| |A∪B∪C| = |A|+|B|+|C|-|A∩B|-|A∩C|-|B∩C|+|A∩B∩C| -- Permutations: P(n,k) = n!/(n-k)! -- Combinations: C(n,k) = n!/(k!(n-k)!) -- Multinomial: n!/(k₁!k₂!…kₘ!) for k₁+…+kₘ=n
Generating Functions Power Series

A generating function encodes a sequence aₙ as coefficients of a power series. They turn combinatorial recurrences into algebra.

-- Ordinary GF: A(x) = Σₙ aₙ xⁿ -- Exponential GF: A(x) = Σₙ aₙ xⁿ/n! -- Fibonacci: F(x) = x/(1-x-x²) -- Catalan: C(x) = (1-√(1-4x))/(2x) -- Coefficient extraction: aₙ = [xⁿ]A(x) -- Used in: vocab size analysis, tree counting
Probabilistic Method & Randomised Algorithms Non-constructive

If E[X] > 0 for some random construction, then X > 0 for at least one instance. This non-constructive proof technique underpins hashing, random projections, and randomised algorithms.

-- Lovász Local Lemma (LLL): -- Bad events A₁,…,Aₙ each with P(Aᵢ) ≤ p -- Each Aᵢ depends on ≤ d others -- If ep(d+1) ≤ 1 → P(∩Āᵢ) > 0 -- Birthday paradox: n people, P(collision) ≥ 1-e^(-n²/2m) -- Hash collision in table of size m with n keys -- ≥50% collision: n ≈ √(2m·ln2) ≈ 1.177√m -- Union bound: P(∪Aᵢ) ≤ ΣP(Aᵢ) -- Fundamental tool: "at least one bad thing happens"
Stirling's Approximation & Entropy Log Factorial

Stirling approximates n! for large n. It connects combinatorics to information theory: the log of a multinomial coefficient becomes cross-entropy in disguise.

-- Stirling: n! ≈ √(2πn)·(n/e)ⁿ log n! ≈ n·log n - n + ½log(2πn) -- Log multinomial (n tokens, kᵢ each of type i): log C = log n! - Σᵢ log kᵢ! ≈ -n Σᵢ (kᵢ/n)·log(kᵢ/n) (using Stirling) = n · H(p) where pᵢ = kᵢ/n -- Entropy = log count per sample! -- Language model perplexity = 2^H bits
Pascal's Triangle & Attention ComplexityAnalysis

C(n,k) satisfies Pascal's recurrence C(n,k) = C(n-1,k-1) + C(n-1,k). The same triangular structure appears in sparse attention patterns and combinatorial token interactions.

Minimax Theorem Zero-Sum

Von Neumann's minimax theorem: in a zero-sum game max_x min_y = min_y max_x. This underpins GAN training, adversarial robustness, and robust optimisation.

max_x min_y xᵀAy = min_y max_x xᵀAy -- x,y are mixed strategies (probability vectors) -- A is the payoff matrix -- GAN as minimax: min_G max_D V(D,G) = min_G max_D E[logD(x)] + E[log(1-D(G(z)))] -- At saddle: p_g = p_data
Mechanism Design & RLHF Incentives

Mechanism design asks: how to design rules so that self-interested agents produce a desired outcome? RLHF's reward model must be robust to "reward hacking" — agents exploiting the mechanism.

-- Vickrey-Clarke-Groves (VCG) mechanism: -- Truthful reporting is dominant strategy -- Payment: pᵢ = Σⱼ≠ᵢ vⱼ(x*) - h(b₋ᵢ) -- Arrow's impossibility: no voting rule satisfies -- Pareto efficiency + IIA + non-dictatorship -- RLHF reward hacking: -- max_π E[r_θ(x,π(x))] can diverge from true reward -- KL penalty: max E[r] - β·KL(π‖π_ref)
Regret Minimisation & Online Learning Algorithms

An online learner makes sequential decisions without knowing future data. Regret measures how much worse the learner does compared to the best fixed strategy in hindsight.

-- Regret after T rounds: R_T = Σₜ lₜ(aₜ) - min_a Σₜ lₜ(a) -- Sub-linear regret: R_T/T → 0 → "no-regret learner" -- Multiplicative Weights Update (MWU): wᵢ(t+1) = wᵢ(t)·(1-ε)^{lᵢ(t)} pᵢ(t) = wᵢ(t)/Σⱼwⱼ(t) -- normalise -- Regret ≤ √(T·log n / 2) (n = actions) -- Connections: -- MWU = online gradient descent on log-weights -- Adagrad, Adam: no-regret optimisers -- Nash equilibrium via MWU: avg strategy → NE

do-Calculus Intervention

P(Y|X=x) = correlation. P(Y|do(X=x)) = causal effect. The do-operator mutilates the graph: remove all incoming edges to X before computing P.

-- Observational: P(Y|X) -- Interventional: P(Y|do(X=x)) -- These differ when there is confounding! -- Adjustment formula (no unobserved confounders): P(Y|do(X)) = Σ_Z P(Y|X,Z)·P(Z) -- Z = set of confounders (backdoor criterion) -- Front-door criterion (unobserved confounders): P(Y|do(X)) = Σ_M P(M|X) Σ_{X'} P(Y|X',M)P(X')
Potential Outcomes (Rubin) Counterfactual

Each unit has two potential outcomes: Y(1) under treatment, Y(0) under control. We only observe one. The fundamental problem of causal inference.

-- Individual treatment effect (ITE): τᵢ = Yᵢ(1) - Yᵢ(0) (never observed) -- Average treatment effect (ATE): τ = E[Y(1) - Y(0)] -- SUTVA: no interference between units -- Ignorability: (Y(0),Y(1)) ⊥ T | X -- Propensity score: e(x) = P(T=1|X=x) -- IPW estimator: τ = E[TY/e(X) - (1-T)Y/(1-e(X))]
Structural Causal Models (SCMs) Pearl
-- SCM: (U, V, F, P(U)) -- U = exogenous variables (noise), V = endogenous -- F = structural equations: Vᵢ = fᵢ(pa(Vᵢ), Uᵢ) -- Three rungs of Pearl's ladder: 1. Association: P(Y|X) -- seeing 2. Intervention: P(Y|do(X)) -- doing 3. Counterfactual: P(Yₓ|X=x',Y=y') -- imagining -- Causal discovery algorithms: -- PC algorithm: constraint-based (CI tests) -- GES: score-based (BIC penalised likelihood) -- NOTEARS: continuous optimisation of DAG -- min ‖X-XᵀW‖² + λ‖W‖₁ s.t. tr(eᴬ)=d

Representation Theory Symmetry → Matrices

A group representation is a homomorphism ρ: G → GL(V). It turns abstract group elements into matrices, making symmetry computationally tractable.

-- Representation: ρ(gh) = ρ(g)ρ(h) -- Character: χ(g) = tr(ρ(g)) -- Irreducible representations (irreps): -- Cannot be block-decomposed further -- Peter-Weyl theorem: any L² function on G -- decomposes into irreps (generalised Fourier) -- Equivariant layer via Schur's Lemma: -- Linear map commuting with all ρ(g): -- must be scalar on each irrep
Homomorphisms & Isomorphisms Structure-Preserving Maps

A homomorphism preserves group structure. Isomorphisms are bijective homomorphisms — the groups are "the same" up to relabelling. Neural network weight-sharing implements quotient maps.

-- Homomorphism: φ(g·h) = φ(g)·φ(h) -- Kernel: ker(φ) = {g : φ(g) = e} — normal subgroup -- First isomorphism theorem: G/ker(φ) ≅ Im(φ) -- Quotient group G/N: cosets as elements -- gN · hN = (gh)N (well-defined iff N ◁ G) -- Weight sharing as quotient: -- CNN: weight tied across positions (translation quotient) -- Equivariant net: weights in representation of G -- Lagrange: |G| = |H|·[G:H] (subgroup index)

Hamiltonian Systems Energy Conservation

Hamiltonian mechanics conserves energy. Symplectic integrators (leapfrog) preserve this structure — used in HMC and for physics-informed ML.

dq/dt = ∂H/∂p dp/dt = -∂H/∂q -- H(q,p) = T(p) + V(q) (kinetic + potential) -- Symplectic integrator: leapfrog -- p_{t+½} = p_t - (Δt/2)∂V/∂q_t -- q_{t+1} = q_t + Δt·∂T/∂p_{t+½} -- p_{t+1} = p_{t+½} - (Δt/2)∂V/∂q_{t+1} -- HMC: q=θ (params), p=momentum, H=loss+½‖p‖²
Gradient Flow Infinite-lr Limit

Gradient descent with infinitesimally small step size becomes gradient flow — a continuous ODE. This limit reveals implicit biases and convergence geometry.

dθ/dt = -∇L(θ) -- gradient flow -- L(θ(t)) is non-increasing d/dt L(θ) = ∇Lᵀ dθ/dt = -‖∇L‖² ≤ 0 -- Implicit bias (linear networks): -- GF converges to min-norm solution -- Mirror flow: dθ/dt = -∇²Ψ(θ)⁻¹∇L(θ) -- Ψ = mirror map (Bregman divergence) -- Adam ≈ mirror flow with Ψ = sum of entropies
Reaction-Diffusion & Score-Based Models PDE

Partial differential equations describe how quantities evolve in space and time. Score-based diffusion models and message-passing networks are both discretisations of PDEs on graphs.

-- Heat / diffusion equation: ∂u/∂t = κ·∇²u = κ·Δu -- Solution: u(x,t) = (G_t * u₀)(x) -- G_t = Gaussian with σ=√(2κt) -- DDPM forward process ≈ heat diffusion on data! -- Fokker-Planck equation (probability flow): ∂p/∂t = -∇·(fp) + ½∇·(g²∇p) -- Describes evolution of density under SDE -- Stationary solution: p* ∝ exp(-2E/g²) -- Graph neural diffusion (GRAND): dX/dt = (Â-I)X where Â = graph diffusion op -- Each GNN layer ≈ one Euler step of this PDE

In-Context Learning — Bayesian Perspective Theory

ICL (few-shot prompting) works without gradient updates. Mathematically, it can be seen as implicit Bayesian inference or as gradient descent implemented in the forward pass via attention.

-- Bayesian ICL view (Xie et al. 2022): P(y|x, context) ≈ E_{θ~P(θ|context)}[P(y|x,θ)] -- Transformer marginalises over implicit hypotheses -- Gradient descent in forward pass (Akyürek 2023): -- Single attention layer implements 1 step of GD: W_new = W_old - η·X_demoᵀ(XW_old - Y_demo) -- Q=X_query, K=X_demo, V=Y_demo -- Attention head ≈ leave-one-out predictor -- Induction heads (mechanistic): -- Copy previous token that follows same prefix -- Emergent at ~1B params — phase transition!
Context Length Scaling O(n²) Problem

Standard attention is O(n²) in time and memory. Every architectural innovation in long-context LLMs is fundamentally a way to reduce this.

-- Standard: O(n²d) FLOP, O(n²) mem -- FlashAttn: O(n²d) FLOP, O(n) mem (tiling) -- Linear attention: O(nd²) via kernel approx -- φ(Q)·(φ(K)ᵀV) — associativity trick -- Mamba (SSM): O(nd) per token (recurrence) -- Sparse: O(n√n) or O(n log n) patterns -- Retrieval-augmented: O(k) per query
Universality of Transformers Theory

Transformers with sufficient depth/width are universal approximators of sequence-to-sequence functions. More precisely: Turing-complete, and can simulate any algorithm given enough context.
