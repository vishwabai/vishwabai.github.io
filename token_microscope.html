Every token, at every layer,
read out as what it currently thinks comes next.

Real transformers never "contain" text after the first layer — just 24 numbers per position that mean nothing to a human eye. This page decodes those numbers back into a character at every single layer, using the model's own output machinery early — a real technique called the logit lens. Watch a row of tokens sharpen, waver, and settle into an answer as they pass through the network.

00 — the idea in one picture

What "equivalent token" means here

At every position, after every layer, the model has a vector — its current guess at "everything relevant so far, condensed." That vector isn't a token. But you can always ask: "if the network stopped right here and tried to predict the next character using only this vector, what would it say?" Answering that question is just running the model's own final steps (LayerNorm → unembed → softmax → argmax) early, on an intermediate vector instead of the final one. That's the entire trick. Below, every cell in the grid is one of those early readings — the token each position's vector is "equivalent to" at that depth.

The bottom row is not a probe — it's the model's actual real output, using the actual final layers. Everything above it is a genuine but early, and often wrong, guess.

03 — extend it, one token at a time

Predict, sample, append — and watch what does (and doesn't) change

Generation is the grid above, run in a loop: read the real output row's last column, sample a character from it, append it as a new column, and recompute. Because of the causal mask, every earlier column's value is mathematically forced to stay identical — position 3 can never see position 7, so adding position 7 cannot change position 3's answer at any layer. Watch for the "=" marks: they confirm every old cell really didn't move. This is also exactly why real inference servers use a "KV-cache" — since old positions never change, there's no need to ever recompute them.
