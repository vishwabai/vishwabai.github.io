Chapter 0 · Foundations

What is Calculus?

Calculus is the mathematics of continuous change. It answers two fundamental questions: how fast is something changing right now? And how much has accumulated over time?

The Two Big Ideas

All of calculus flows from two operations that are inverses of each other — like multiplication and division, or squaring and taking square roots.

🔬
Differentiation
Finds the instantaneous rate of change — the derivative. "How fast is this changing right now?"
🌊
Integration
Finds the accumulation or total area. "How much has built up over this interval?"
🔗
Fundamental Theorem
The bridge connecting both: differentiation and integration are inverse operations.
♾️
Limits
The foundation beneath both: what happens as we get infinitely close to a point?

Where Calculus Lives

Every time you see a smooth curve, a changing quantity, or accumulated effects — calculus is there:

Physics: velocity, acceleration, force, electric fields, quantum mechanics
Engineering: signal processing, control systems, bridge load analysis
Biology: population growth, drug concentration in bloodstream
Economics: marginal cost, optimal pricing, GDP growth

Limits & Continuity

A limit describes what a function approaches as its input approaches some value — even if the function is never actually defined there. Limits are the bedrock everything else stands on.

Definition of a Limit

We say lim(x→a) f(x) = L if f(x) gets arbitrarily close to L as x gets close to a (from either side).

Formal Limit Notation
lim(x → a) f(x) = L
For every ε > 0, there exists δ > 0 such that |f(x) − L| < ε whenever 0 < |x − a| < δ
Key insight: The limit doesn't care about the value AT x = a, only what happens near it. A function can have a limit even if it has a hole at that point.

Limit Laws

If lim(x→a) f(x) = L and lim(x→a) g(x) = M, then:

Limit Laws
lim [f(x) + g(x)] = L + M
lim [f(x) · g(x)] = L · M
lim [f(x) / g(x)] = L / M (if M ≠ 0)
lim [c · f(x)] = c · L
lim [f(x)ⁿ] = Lⁿ

Continuity

A function f is continuous at x = a if three things hold:

1️⃣
f(a) is defined
The function has a value at the point.
2️⃣
Limit exists
lim(x→a) f(x) exists (left = right limit).
3️⃣
They match
The limit equals the function value: lim f(x) = f(a).
Discontinuities: Jump, Removable (hole), and Infinite (asymptote) are the three types of discontinuities you'll encounter.

Chapter 2 · Differential Calculus

Derivatives — Introduction

The derivative is the instantaneous rate of change of a function. It's the slope of the tangent line at a point — and it's defined using the idea of a limit.

The Definition

The derivative of f at x is defined as the limit of the average rate of change as the interval shrinks to zero:

Definition of the Derivative
f'(x) = lim(h→0) [f(x + h) − f(x)] / h

This is also written as dy/dx, df/dx, or Df(x). Each notation emphasizes something different about the relationship.

Step-by-Step: Derivative of x²

Let's derive the derivative of f(x) = x² from first principles.

1
f'(x) = lim(h→0) [f(x+h) − f(x)] / h
Start with the definition of the derivative.
2
= lim(h→0) [(x+h)² − x²] / h
Substitute f(x) = x²
3
= lim(h→0) [x² + 2xh + h² − x²] / h
Expand (x+h)² using FOIL / binomial.
4
= lim(h→0) [2xh + h²] / h = lim(h→0) [2x + h]
Cancel x² terms, factor out h and cancel.
5
f'(x) = 2x
Take the limit as h→0. The h disappears, leaving 2x.

Chapter 3 · Differential Calculus

Rules of Differentiation

Rather than always going back to the limit definition, calculus gives us powerful shortcut rules. Learn these patterns and differentiation becomes mechanical.

Core Rules Reference

All the Essential Rules
Power: d/dx[xⁿ] = nxⁿ⁻¹
Constant: d/dx[c] = 0
Sum: d/dx[f + g] = f' + g'
Product: d/dx[f·g] = f'g + fg'
Quotient: d/dx[f/g] = (f'g − fg') / g²
Chain: d/dx[f(g(x))] = f'(g(x)) · g'(x)

Common Derivatives

Trigonometric & Exponential
d/dx[sin x] = cos x
d/dx[cos x] = −sin x
d/dx[tan x] = sec²x
d/dx[eˣ] = eˣ
d/dx[ln x] = 1/x
d/dx[aˣ] = aˣ · ln(a)

The Chain Rule — Worked Example

Find d/dx[sin(x²)]. Here f(u) = sin(u) and g(x) = x², so f(g(x)) = sin(x²).

1
Identify outer and inner: f(u) = sin(u), g(x) = x²
Chain rule applies to composed functions f(g(x)).
2
f'(u) = cos(u), and g'(x) = 2x
Differentiate each part separately.
3
d/dx[sin(x²)] = cos(x²) · 2x
Apply chain rule: f'(g(x)) · g'(x).
4
= 2x·cos(x²)
Final answer — the derivative of sin(x²).

Chapter 4 · Differential Calculus

Applications of Derivatives

Derivatives tell us everything about how a function behaves: where it's increasing, where it peaks, how curved it is. These tools solve optimization problems in science, engineering, and business.

Critical Points & Extrema

A critical point occurs where f'(x) = 0 or f'(x) is undefined. At these points the function might have a local max, local min, or saddle point.

Second Derivative Test
If f'(c) = 0 and f''(c) < 0 → local MAXIMUM
If f'(c) = 0 and f''(c) > 0 → local MINIMUM
If f'(c) = 0 and f''(c) = 0 → inconclusive (use first derivative test)

Concavity & Inflection Points

The second derivative f''(x) tells us about concavity:

☁️
Concave Up
f''(x) > 0 — the curve holds water like a bowl. The function is "accelerating."
⛰️
Concave Down
f''(x) < 0 — the curve is hill-shaped. The function is "decelerating."
✖️
Inflection Point
Where f''(x) = 0 and concavity changes — the curve switches from bowl to hill.
L'Hôpital's Rule: If a limit gives 0/0 or ∞/∞, you can replace the numerator and denominator with their derivatives: lim f(x)/g(x) = lim f'(x)/g'(x)

🎯 Quick Check

For f(x) = x³ − 3x, what are the critical points?
x = 0 only
x = 1 and x = −1
x = 3 and x = −3
f'(x) = 3x² − 3. Setting f'(x) = 0: 3x² = 3, x² = 1, so x = ±1. At x = −1 there's a local max, at x = 1 a local min (check with f'').
Chapter 5 · Integral Calculus

Integration — Introduction

Integration is the reverse of differentiation. It also computes areas under curves, total accumulated change, and connects to the derivative through the Fundamental Theorem of Calculus.

The Definite Integral as Area

The definite integral ∫[a to b] f(x)dx gives the signed area between f(x) and the x-axis from x = a to x = b. We approximate it with Riemann sums — thin rectangles that get infinitely thin.

Definite Integral Definition
∫[a to b] f(x) dx = lim(n→∞) Σᵢ f(xᵢ) · Δx

The Fundamental Theorem of Calculus

⭐
Part 1
If F(x) = ∫[a to x] f(t)dt, then F'(x) = f(x). Integration and differentiation are inverses.
⭐
Part 2
∫[a to b] f(x)dx = F(b) − F(a), where F is any antiderivative of f. Area = net change in antiderivative.
Basic Antiderivative Rules
∫ xⁿ dx = xⁿ⁺¹/(n+1) + C (n ≠ −1)
∫ eˣ dx = eˣ + C
∫ 1/x dx = ln|x| + C
∫ sin x dx = −cos x + C
∫ cos x dx = sin x + C
Always add + C! The constant of integration C represents any constant, since d/dx[C] = 0 for all constants C. For definite integrals, C cancels out.

Chapter 6 · Integral Calculus

Techniques of Integration

Not every integral has an obvious antiderivative. These techniques let you transform hard integrals into ones you can evaluate.

U-Substitution

The reverse of the chain rule. Replace a messy expression with u to simplify the integral.

1
∫ 2x · cos(x²) dx
Our target integral. Notice 2x is the derivative of x².
2
Let u = x², then du = 2x dx
Choose u to be the "inside" function.
3
∫ cos(u) du
Substitute: 2x dx becomes du, x² becomes u.
4
= sin(u) + C = sin(x²) + C
Integrate, then substitute back u = x².

Integration by Parts

The reverse of the product rule. Useful when the integrand is a product of two functions.

Integration by Parts Formula
∫ u dv = uv − ∫ v du
LIATE rule: choose u as the first of: Logarithm, Inverse trig, Algebraic, Trig, Exponential
Example: ∫ x·eˣ dx — let u = x (algebraic, simpler when differentiated), dv = eˣdx. Then du = dx, v = eˣ. Result: xeˣ − eˣ + C = eˣ(x−1) + C.

Partial Fractions

Break a rational function into simpler fractions that are easier to integrate separately.

Example: Partial Fractions
∫ 1/(x²−1) dx = ∫ [1/(2(x−1)) − 1/(2(x+1))] dx
= ½·ln|x−1| − ½·ln|x+1| + C
= ½·ln|(x−1)/(x+1)| + C

Comparison of Integration Methods

🔄
U-Substitution
Use when you spot an inner function and its derivative in the integrand.
🤝
By Parts
Use for products like x·sin(x), x·eˣ, ln(x).
🧩
Partial Fractions
Use for rational functions (polynomial divided by polynomial).
📐
Trig Substitution
Use for √(a²−x²), √(a²+x²), √(x²−a²) forms.

Chapter 7 · Advanced

Advanced Topics

Welcome to the frontier. Series, multi-variable calculus, differential equations — these extend calculus into new dimensions and bridge pure math with physics and engineering.

Taylor & Maclaurin Series

Any smooth function can be approximated by an infinite polynomial. The better the approximation, the more terms you include.

Maclaurin Series (Taylor at x = 0)
f(x) = f(0) + f'(0)x + f''(0)x²/2! + f'''(0)x³/3! + ...

eˣ = 1 + x + x²/2! + x³/3! + x⁴/4! + ...
sin(x) = x − x³/3! + x⁵/5! − ...
cos(x) = 1 − x²/2! + x⁴/4! − ...

Differential Equations

An equation involving a function and its derivatives. Solving one means finding the function itself.

Key Differential Equations
Exponential growth: dy/dt = ky → y = Ce^(kt)
Harmonic oscillator: y'' + ω²y = 0 → y = A·cos(ωt) + B·sin(ωt)
Heat equation: ∂u/∂t = k·∂²u/∂x²
Applications everywhere: Population biology (logistic growth), circuits (RLC equations), quantum mechanics (Schrödinger equation), fluid dynamics (Navier-Stokes equations).
