Epsilon-Delta Definition

The formal definition of a limit made visual. Drag ε (epsilon) to set a target tolerance on the y-axis — the animation shows the corresponding δ (delta) window on the x-axis.

Interactive Proof
0.8
ε = — δ = — If |x − a| < δ, then |f(x) − L| < ε
Formal ε-δ Definition
lim(x→a) f(x) = L means:
∀ε > 0, ∃δ > 0 such that 0 < |x − a| < δ ⟹ |f(x) − L| < ε
Reading it: "For every challenge ε you throw at me, I can always find a δ-window around a where the function stays within ε of L." The smaller ε gets, the harder the challenge — but for a continuous function, δ always exists.

🎯 Quick Check

A tighter y-tolerance (small ε) means you need to restrict x even more tightly (smaller δ). The δ must shrink to match the challenge.

Notice that as the particle moves, the slope (red line) traces its own curve — that curve IS the derivative f'(x). The derivative is itself a function mapping each x to the slope of f at that x.

Module 3 · Derivatives

Chain Rule — Live Composition

The chain rule says d/dx[f(g(x))] = f'(g(x))·g'(x). This animation shows two linked particles — when one moves on g(x), it drives the other on f, and the combined slope is their product.

Composition Animation
x = — g(x) = — f(g(x)) = — Chain: g'·f'(g) = —

Why the Chain Rule Works

Think of g as converting x-speed into u-speed, and f' as how fast f responds to u-changes. The composed rate is their product:

Chain Rule
dy/dx = (dy/du) · (du/dx)
The du's "cancel" — this is a mnemonic, not rigorous, but it works!

🎯 Quick Check

Find d/dx[e^(3x²)]
e^(3x²)
6x · e^(3x²)
3x² · e^(3x²)
Chain rule: outer = eᵘ (derivative = eᵘ), inner u = 3x² (derivative = 6x). Result: e^(3x²) · 6x = 6x·e^(3x²).

Volume Formulas
Disk (rotate around x-axis): V = π∫[a,b] [f(x)]² dx
Washer: V = π∫[a,b] ([R(x)]² − [r(x)]²) dx

Module 7 · Advanced

Fourier Series

Any periodic function can be decomposed into a sum of sines and cosines. This is calculus at its most magical — the integrals that compute the coefficients are the key.

Rotating Circles Animation
3
n = 3 harmonics 4/π(sin x + sin3x/3 + sin5x/5 + ...)
Fourier Coefficients (via Integration!)
aₙ = (1/π) ∫[−π,π] f(x)·cos(nx) dx
bₙ = (1/π) ∫[−π,π] f(x)·sin(nx) dx
f(x) = a₀/2 + Σ [aₙcos(nx) + bₙsin(nx)]
Why rotating circles? Each sinusoidal term is a circle rotating at a different speed. Adding them up traces any wave — this is why the animation shows spinning wheels.

🎯 Quick Check

For a square wave, the Fourier series only contains which harmonics?
Even harmonics (n=2,4,6...)
Odd harmonics (n=1,3,5...)
All harmonics equally
A square wave is an odd function, so all cosine (even) terms vanish. Only odd-frequency sine terms survive: 4/π · Σ sin((2k−1)x)/(2k−1).

Multivariable Calculus

When functions take multiple inputs, calculus extends to partial derivatives, gradients, and multiple integrals. The gradient ∇f points in the direction of steepest ascent — like a compass for optimization.

3D Surface + Gradient Field
∂f/∂x and ∂f/∂y shown as gradient arrows on the surface
Multivariable Essentials
Partial derivative: ∂f/∂x (treat y as constant)
Gradient: ∇f = (∂f/∂x, ∂f/∂y) — direction of steepest rise
Critical point: ∇f = 0 → use Hessian to classify

🎯 Quick Check

For f(x,y) = x² + 3y², what is the gradient ∇f at point (2, 1)?
(2, 3)
(4, 6)
(4, 3)
∂f/∂x = 2x = 4 at x=2. ∂f/∂y = 6y = 6 at y=1. So ∇f(2,1) = (4, 6). This vector points in the direction of maximum increase from (2,1).
