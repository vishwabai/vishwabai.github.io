Tokenisation — the alphabet of LLMs
BPE splits text into token IDs. Common words stay whole; rare words split into subwords. Every API charges by token — about 4 chars per token for English.

Why BPEBalance between character-level (too many steps) and word-level (too many rare words).

Flash Attention — the trick that enabled 128K context
Standard attention writes an N×N score matrix to slow HBM memory. Flash Attention tiles Q·K computation into blocks that fit in fast SRAM — never materialising the full matrix. Memory: O(N) instead of O(N²).

Activation functions — from ReLU to SwiGLU
ReLU kills gradients below zero. GeLU smooths the cutoff. SwiGLU (used in LLaMA, PaLM, Gemma) multiplies two branches — better gradient flow, ~1% less loss at same compute.

Compare all activation functions live — animate a signal through them

Show:
ReLU: zero below 0 — fast but causes dying neurons. GeLU: smooth Gaussian approximation — BERT, GPT-3. SwiGLU: gated multiplication — LLaMA, PaLM, Gemma.
Context window — why longer is harder
Full attention is O(N²). For N=32 that is 1024 ops. For N=8192 it is 67M ops per layer. Sparse patterns (local, strided) reduce cost while preserving most signal.
