Vectors, Matrices & Tensors

Why linear algebra is the language of ML Every dataset is a matrix. Every neural network layer is a matrix multiply. Attention is scaled dot-product between matrices. PCA, SVD, eigendecomposition — all linear algebra. NumPy exposes the full BLAS/LAPACK stack with clean Python syntax.

② Eigenvalues & Eigenvectors

Core identity: Av = λv A matrix A acting on eigenvector v only scales it by λ (eigenvalue). Used in PCA (find directions of max variance), graph Laplacians, spectral clustering, PageRank, and understanding gradient flow in deep networks.

Eigendecomposition

eigen.py
# Symmetric matrix → real eigenvalues
X  = np.random.randn(100, 5)
S  = X.T @ X                 # covariance-like (5,5)

vals, vecs = np.linalg.eigh(S)  # eigh for symmetric
# vals: eigenvalues  (ascending)
# vecs: columns are eigenvectors

# Verify: A v = λ v
i = 0
lhs = S @ vecs[:, i]         # A * v
rhs = vals[i] * vecs[:, i]   # λ * v
np.allclose(lhs, rhs)       # True

# Reconstruct A from eigen decomp
A_rec = vecs @ np.diag(vals) @ vecs.T

# Low-rank approx (keep top-k)
k = 2
A_k = vecs[:, -k:] @ np.diag(vals[-k:]) @ vecs[:, -k:].T

③ Singular Value Decomposition (SVD)

A = U Σ Vᵀ — the most important factorisation in ML U: left singular vectors (output space), Σ: singular values (importance ranking), Vᵀ: right singular vectors (input space). Used in: dimensionality reduction, recommendation systems, image compression, LoRA fine-tuning, least-squares, and more.
∑
SVD in NumPy
A = U Σ Vᵀ, rank-k approx: Aₖ = Uₖ Σₖ Vₖᵀ
svd.py
A = np.random.randn(6, 4)

U, s, Vt = np.linalg.svd(A, full_matrices=False)
# U:  (6,4) orthonormal columns
# s:  (4,)  singular values (descending)
# Vt: (4,4) orthonormal rows

# Reconstruct exactly
A_rec = U @ np.diag(s) @ Vt

# Rank-k approximation
k = 2
A_k = U[:, :k] @ np.diag(s[:k]) @ Vt[:k, :]
err = np.linalg.norm(A - A_k, 'fro')

# Energy captured
energy = (s[:k]**2).sum() / (s**2).sum()

# LoRA: decompose weight update ΔW
# ΔW ≈ B @ A,  B=(d,r), A=(r,k), r << min(d,k)
r = 4
B = U[:, :r] * s[:r]         # absorb σ into B
A2= Vt[:r, :]

Calculus & Backpropagation

Why calculus matters in ML Gradient descent moves parameters in the direction of steepest loss descent. Backpropagation is the chain rule applied recursively through a computation graph. Every optimizer — SGD, Adam, RMSProp — uses first-order derivatives; second-order methods use the Hessian.

① Derivatives & the Chain Rule

∂
Numerical Differentiation
f'(x) ≈ [f(x+h) - f(x-h)] / 2h
derivatives.py
# Numerical gradient (finite differences)
def numerical_grad(f, x, h=1e-5):
    return (f(x+h) - f(x-h)) / (2*h)

# Example: f(x) = x³ - 2x + 1  →  f'(x) = 3x² - 2
f     = lambda x: x**3 - 2*x + 1
f_prime = lambda x: 3*x**2 - 2

x0 = 2.0
num  = numerical_grad(f, x0)   # 10.00000
anal = f_prime(x0)              # 10.0  (exact)

# Gradient of vector function
def grad_vec(f, x, h=1e-5):
    grad = np.zeros_like(x)
    for i in range(len(x)):
        x_p, x_m = x.copy(), x.copy()
        x_p[i] += h; x_m[i] -= h
        grad[i] = (f(x_p) - f(x_m)) / (2*h)
    return grad

# Gradient check: verify analytic == numerical
def grad_check(f, grad_f, x):
    num = grad_vec(f, x)
    ana = grad_f(x)
    rel = np.linalg.norm(num-ana) / (np.linalg.norm(num)+np.linalg.norm(ana))
    print(f"Relative error: {rel:.2e}")  # should be < 1e-5

② Jacobians & the Hessian

𝐉
Jacobian Matrix

jacobian.py
# Numerical Jacobian for f: Rⁿ → Rᵐ
def jacobian(f, x, h=1e-5):
    fx = f(x)
    J  = np.zeros((len(fx), len(x)))
    for j in range(len(x)):
        xp, xm = x.copy(), x.copy()
        xp[j] += h; xm[j] -= h
        J[:, j] = (f(xp) - f(xm)) / (2*h)
    return J

# Softmax Jacobian: ∂softmax(x)ᵢ/∂xⱼ
def softmax_jacobian(x):
    s  = np.exp(x) / np.exp(x).sum()
    # J = diag(s) - s @ s.T
    return np.diag(s) - np.outer(s, s)

# Cross-entropy + softmax gradient (combined)
# ∂L/∂z = p - y_true   (very elegant!)
def ce_softmax_grad(logits, y_true_onehot):
    p = np.exp(logits) / np.exp(logits).sum(axis=-1, keepdims=True)
    return (p - y_true_onehot) / len(logits)

# Numerical Hessian
def hessian(f, x, h=1e-4):
    n = len(x)
    H = np.zeros((n, n))
    for i in range(n):
      for j in range(n):
        xpp = x.copy(); xpp[i]+=h; xpp[j]+=h
        xpm = x.copy(); xpm[i]+=h; xpm[j]-=h
        xmp = x.copy(); xmp[i]-=h; xmp[j]+=h
        xmm = x.copy(); xmm[i]-=h; xmm[j]-=h
        H[i,j] = (f(xpp)-f(xpm)-f(xmp)+f(xmm)) / (4*h**2)
    return H

# Newton step: x ← x - H⁻¹ ∇f(x)
def newton_step(f, grad_f, x):
    g = grad_f(x)
    H = hessian(f, x)
    return x - np.linalg.solve(H, g)

# Condition number → tells you how hard optim is
H_diag = np.diag(H)           # diagonal Fisher approx
cond = H_diag.max() / H_diag.min()

② Bayes' Theorem & Probabilistic ML

Bayes' Theorem: P(θ|D) ∝ P(D|θ) · P(θ) Posterior = Likelihood × Prior (normalised). In ML: parameters θ, data D. MLE maximises likelihood alone. MAP adds a prior (= L2 regularisation for Gaussian prior). Full Bayes maintains a distribution over θ.
🔮
MLE & MAP Estimation
MLE: θ* = argmax P(D|θ) = argmin −log P(D|θ)

# Log-likelihood for logistic regression
def log_likelihood(w, X, y):
    p = 1 / (1 + np.exp(-(X @ w)))
    return np.sum(y * np.log(p+1e-9) + (1-y) * np.log(1-p+1e-9))

# MAP = MLE + log-prior (Gaussian prior = L2 reg)
def log_posterior(w, X, y, lam=0.01):
    ll = log_likelihood(w, X, y)
    log_prior = -lam * np.sum(w**2)  # Gaussian prior
    return ll + log_prior

# Cross-entropy = -log_likelihood / n
def cross_entropy(p, y):
    return -np.mean(y*np.log(p+1e-9) + (1-y)*np.log(1-p+1e-9))

① Gradient Descent Variants

⬇️
SGD, Momentum & Nesterov
θ ← θ - η∇L(θ) [SGD] | v ← βv - η∇L, θ ← θ + v [Momentum]
optimisers.py
# Vanilla SGD
def sgd(params, grads, lr=0.01):
    return [p - lr*g for p, g in zip(params, grads)]

# SGD + Momentum
velocity = [np.zeros_like(p) for p in params]
def sgd_momentum(params, grads, velocity, lr=0.01, beta=0.9):
    for i, (p, g, v) in enumerate(zip(params, grads, velocity)):
        velocity[i] = beta * v - lr * g
        params[i]   = p + velocity[i]
    return params, velocity

# Nesterov Accelerated Gradient (lookahead)
def nag_step(p, v, grad_f, lr=0.01, beta=0.9):
    p_look = p + beta * v          # look ahead
    g      = grad_f(p_look)        # gradient there
    v_new  = beta * v - lr * g
    return p + v_new, v_new
⚡
Adam Optimiser (from scratch)
m ← β₁m + (1-β₁)g | v ← β₂v + (1-β₂)g² | θ ← θ - η·m̂/√v̂
adam.py
class Adam:
    def __init__(self, params, lr=1e-3,
                 beta1=0.9, beta2=0.999, eps=1e-8):
        self.params = params
        self.lr, self.b1, self.b2, self.eps = lr, beta1, beta2, eps
        self.m = [np.zeros_like(p) for p in params]
        self.v = [np.zeros_like(p) for p in params]
        self.t = 0

    def step(self, grads):
        self.t += 1
        for i, (p, g) in enumerate(zip(self.params, grads)):
            self.m[i] = self.b1*self.m[i] + (1-self.b1)*g
            self.v[i] = self.b2*self.v[i] + (1-self.b2)*g**2
            m_hat = self.m[i] / (1 - self.b1**self.t)
            v_hat = self.v[i] / (1 - self.b2**self.t)
            self.params[i] -= self.lr * m_hat / (np.sqrt(v_hat)+self.eps)
        return self.params

② Learning Rate Schedules

LR Schedule Implementations
lr_schedules.py
epochs = np.arange(100)

# Step decay
step_lr = lambda e: 0.1 * (0.5 ** (e // 30))

# Exponential decay
exp_lr  = lambda e: 0.1 * np.exp(-0.05 * e)

# Cosine annealing (used in modern LLMs)
def cosine_lr(e, T_max=100, eta_min=1e-6, eta_max=0.1):
    return eta_min + 0.5*(eta_max-eta_min)*(
           1 + np.cos(np.pi * e / T_max))

# Warmup + cosine (standard in transformers)
def warmup_cosine(e, warmup=10, T_max=100):
    if e < warmup:
        return 0.1 * e / warmup   # linear warmup
    return cosine_lr(e - warmup, T_max - warmup)

# 1-cycle (super-convergence)
def one_cycle(e, T=100, max_lr=0.1):
    pct = e / T
    if pct < 0.5: return max_lr * pct * 2    # rise
    return max_lr * (2 - pct * 2)              # fall

def entropy(p, base=2):
    """Shannon entropy in bits (base=2) or nats (base=e)"""
    p = np.asarray(p, dtype=float)
    p = p[p > 0]                  # avoid log(0)
    return -np.sum(p * np.log(p) / np.log(base))

# Examples
entropy([0.5, 0.5])         # 1.0 bit (max uncertainty, 2 classes)
entropy([1.0, 0.0])         # 0.0 bits (certain)
entropy([0.25]*4)           # 2.0 bits (max, 4 classes)

# In ML: entropy of softmax output
# Low entropy → confident prediction
# High entropy → uncertain prediction
def prediction_confidence(logits):
    p = np.exp(logits) / np.exp(logits).sum()
    H = entropy(p)
    max_H = np.log2(len(logits))   # maximum possible
    return 1 - H / max_H            # 1 = certain, 0 = uniform

def cross_entropy(p, q):
    """p=true, q=predicted"""
    q = np.clip(q, 1e-9, 1)
    return -np.sum(p * np.log(q))

def kl_divergence(p, q):
    """KL(p || q): how much q differs from p"""
    p = np.clip(p, 1e-9, 1)
    q = np.clip(q, 1e-9, 1)
    return np.sum(p * np.log(p / q))

# Relationship: H(p,q) = H(p) + KL(p||q)

                   entropy(p, base=np.e) + kl_divergence(p,q))

def kl_gaussian(mu, log_var):

def mutual_info_discrete(X, Y, bins=10):
    """Discretised mutual information between X and Y"""
    pxy, _, _ = np.histogram2d(X, Y, bins=bins, density=True)
    pxy = pxy / pxy.sum()
    px  = pxy.sum(axis=1, keepdims=True)
    py  = pxy.sum(axis=0, keepdims=True)
    mask = pxy > 0
    return np.sum(pxy[mask] * np.log(pxy[mask] / (px*py)[mask]))

              for col in X_df.columns}
    ranked = sorted(scores, key=scores.get, reverse=True)
    return ranked[:top_k]

def bootstrap_ci(data, stat_fn=np.mean, n=1000, ci=0.95):
    """Bootstrap confidence interval for any statistic"""
    rng = np.random.default_rng(42)
    stats = np.array([
        stat_fn(rng.choice(data, size=len(data), replace=True))
        for _ in range(n)
    ])

    lo, hi = np.percentile(stats, [alpha*100, (1-alpha)*100])

def metrics(y_true, y_pred):
    TP = np.sum((y_pred==1) & (y_true==1))
    TN = np.sum((y_pred==0) & (y_true==0))
    FP = np.sum((y_pred==1) & (y_true==0))
    FN = np.sum((y_pred==0) & (y_true==1))
    precision = TP / (TP + FP + 1e-9)
    recall    = TP / (TP + FN + 1e-9)
    f1        = 2*precision*recall / (precision+recall+1e-9)
    accuracy  = (TP + TN) / len(y_true)
    return {'acc':accuracy,'p':precision,'r':recall,'f1':f1}

# AUC-ROC via trapezoidal rule
def auc_roc(y_true, y_scores):
    thresholds = np.linspace(0, 1, 100)
    tprs, fprs = [], []
    for t in thresholds:
        yp = (y_scores >= t).astype(int)
        m  = metrics(y_true, yp)
        tprs.append(m['r'])
        fprs.append(np.sum((yp==1)&(y_true==0)) /
                   (np.sum(y_true==0)+1e-9))
    return -np.trapz(tprs, fprs)

def regression_metrics(y_true, y_pred):
    resid   = y_true - y_pred
    mse     = np.mean(resid**2)
    rmse    = np.sqrt(mse)
    mae     = np.mean(np.abs(resid))
    ss_res  = np.sum(resid**2)
    ss_tot  = np.sum((y_true - y_true.mean())**2)
    r2      = 1 - ss_res / ss_tot
    mape    = np.mean(np.abs(resid / (y_true+1e-9)))
    return {'MSE':mse,'RMSE':rmse,'MAE':mae,'R²':r2,'MAPE':mape}

def huber_loss(y_true, y_pred, delta=1.0):
    r = np.abs(y_true - y_pred)
    return np.where(r <= delta,
                    0.5 * r**2,
                    delta * (r - 0.5*delta)).mean()

def ridge_loss(y_true, y_pred, w, lam=0.01):
    mse  = np.mean((y_pred - y_true)**2)
    reg  = lam * np.sum(w**2)     # L2 penalty
    return mse + reg

def ridge_grad(X, y, w, lam=0.01):
    err  = X @ w - y
    dw   = (2 * X.T @ err) / len(y)
    return dw + 2 * lam * w      # ← L2 gradient

# Lasso regression (L1)
def lasso_loss(y_true, y_pred, w, lam=0.01):
    mse  = np.mean((y_pred - y_true)**2)
    reg  = lam * np.sum(np.abs(w))  # L1 penalty
    return mse + reg

def lasso_grad(X, y, w, lam=0.01):

    dw  = (2 * X.T @ err) / len(y)

rng = np.random.default_rng(42)

def dropout(h, p=0.5, training=True):
    """p = keep probability"""
    if not training: return h          # no dropout at test
    mask = rng.binomial(1, p, h.shape) # Bernoulli
    return h * mask / p                  # inverted dropout

# Inverted dropout: scale by 1/p at train time
# so test-time just uses h with no scaling

# DropConnect (drop weights instead of activations)
def dropconnect(W, p=0.5, training=True):
    if not training: return W
    mask = rng.binomial(1, p, W.shape)
    return W * mask / p

# Spatial Dropout (for CNNs: drop entire channels)
def spatial_dropout(feature_map, p=0.5):
    # feature_map: (batch, channels, H, W)
    mask = rng.binomial(1, p, feature_map.shape[:2])
    mask = mask[:, :, None, None]      # broadcast over H,W
    return feature_map * mask / p

def he_init(fan_in, fan_out):
    """For ReLU networks"""
    std = np.sqrt(2.0 / fan_in)
    return rng.normal(0, std, (fan_in, fan_out))

    std = np.sqrt(2.0 / (fan_in + fan_out))

def batch_norm_forward(x, gamma, beta, eps=1e-5, training=True,
                          running_mean=None, running_var=None, momentum=0.1):
    if training:
        mu  = x.mean(axis=0)          # batch mean
        var = x.var(axis=0)           # batch variance
        if running_mean is not None:   # exponential moving average
            running_mean[:] = (1-momentum)*running_mean + momentum*mu
            running_var[:]  = (1-momentum)*running_var  + momentum*var
    else:
        mu, var = running_mean, running_var  # use population stats
    x_hat = (x - mu) / np.sqrt(var + eps)
    return gamma * x_hat + beta, x_hat, mu, var

# Layer Norm (used in Transformers, no batch dim)
def layer_norm(x, gamma, beta, eps=1e-5):
    mu  = x.mean(axis=-1, keepdims=True)
    var = x.var(axis=-1, keepdims=True)
    return gamma * (x - mu) / np.sqrt(var + eps) + beta

① Scaled Dot-Product Attention

Attention(Q, K, V) = softmax(QKᵀ/√dₖ) · V The foundational operation of Transformers. Q (query), K (key), V (value) are linear projections of the input. The softmax creates a probability distribution over positions. √dₖ scaling prevents vanishingly small gradients when dₖ is large.
🔍
Self-Attention in NumPy
Attention(Q,K,V) = softmax(QKᵀ/√dₖ)V

def scaled_dot_product_attention(Q, K, V, mask=None):
    """
    Q: (batch, heads, seq, d_k)
    K: (batch, heads, seq, d_k)
    V: (batch, heads, seq, d_v)
    """
    d_k   = Q.shape[-1]
    scores = Q @ K.swapaxes(-2, -1) / np.sqrt(d_k)

    if mask is not None:              # causal mask for decoder
        scores = np.where(mask, scores, -1e9)

    attn_weights = np.exp(scores - scores.max(axis=-1, keepdims=True))
    attn_weights /= attn_weights.sum(axis=-1, keepdims=True)

    return attn_weights @ V, attn_weights

T = 10

# Multi-Head Attention
def multi_head_attention(X, W_Q, W_K, W_V, W_O, h=8):
    B, T, d = X.shape; d_h = d // h
    Q = (X @ W_Q).reshape(B, T, h, d_h).swapaxes(1,2)
    K = (X @ W_K).reshape(B, T, h, d_h).swapaxes(1,2)
    V = (X @ W_V).reshape(B, T, h, d_h).swapaxes(1,2)
    out, attn = scaled_dot_product_attention(Q, K, V)
    out = out.swapaxes(1,2).reshape(B, T, d)
    return out @ W_O, attn

def conv2d_naive(x, kernel, stride=1, padding=0):
    """x: (H,W)  kernel: (kH,kW)"""
    if padding > 0:
        x = np.pad(x, padding)
    H, W  = x.shape
    kH, kW = kernel.shape
    oH = (H - kH) // stride + 1
    oW = (W - kW) // stride + 1
    out = np.zeros((oH, oW))
    for i in range(oH):
        for j in range(oW):
            out[i,j] = np.sum(x[i*stride:i*stride+kH,
                                   j*stride:j*stride+kW] * kernel)
    return out

    cols = np.zeros((kH*kW, oH*oW))

        for j in range(oW):

    return cols # matmul: kernel.flatten() @ cols → output

① Newton-Raphson Root Finding

xₙ₊₁ = xₙ − f(xₙ)/f′(xₙ) Quadratic convergence: error squares each step. Used in second-order optimisers (L-BFGS), inverse kinematics, and computing softmax in log-space for numerical stability.

newton_raphson.py
def newton_raphson(f, fp, x0, tol=1e-10, max_iter=50):
    x = x0
    for i in range(max_iter):
        fx  = f(x)
        fpx = fp(x)
        if np.abs(fpx) < 1e-15: break  # flat derivative
        x_new = x - fx / fpx
        if np.abs(x_new - x) < tol: break
        x = x_new
    return x, i

# UNSTABLE softmax (overflow for large logits)
def softmax_unstable(x):
    return np.exp(x) / np.exp(x).sum()

# STABLE: subtract max before exp
def softmax_stable(x):
    e = np.exp(x - x.max())
    return e / e.sum()

# Log-sum-exp trick (for log-softmax)
def logsumexp(x):
    c = x.max()
    return c + np.log(np.sum(np.exp(x - c)))

# Numerically stable log-likelihood
def stable_cross_entropy(logits, y_true):
    # log p_i = logit_i - logsumexp(logits)
    log_Z = logsumexp(logits)
    return -np.sum(y_true * (logits - log_Z))

# Kahan summation (prevents float accumulation error)
def kahan_sum(arr):
    total, comp = 0.0, 0.0
    for x in arr:
        y = x - comp; t = total + y
        comp = (t - total) - y; total = t
    return total

PCA Full Pipeline

      

        
PCA: X̃ = Xc W_k,  W_k = top-k eigenvectors of (XᵀX)/(n-1)

        
pca_full.py

        
class PCA:
    def __init__(self, n_components):
        self.k = n_components

    def fit(self, X):
        self.mean_ = X.mean(axis=0)
        Xc = X - self.mean_
        C  = (Xc.T @ Xc) / (len(X) - 1)
        vals, vecs = np.linalg.eigh(C)          # ascending
        idx = np.argsort(vals)[::-1]            # descending
        self.components_     = vecs[:, idx[:self.k]].T  # (k,d)
        self.explained_var_  = vals[idx[:self.k]]
        self.explained_ratio_= vals[idx[:self.k]] / vals.sum()
        return self

    def transform(self, X):
        return (X - self.mean_) @ self.components_.T

    def inverse_transform(self, Z):
        return Z @ self.components_ + self.mean_

# High-dim similarity (Gaussian kernel)
def p_cond(D_sq, sigma):
    D_sq = D_sq - D_sq.min()
    num = np.exp(-D_sq / (2*sigma**2))
    np.fill_diagonal(num, 0)
    return num / num.sum(axis=1, keepdims=True)

def q_joint(Y):

    num = 1 / (1 + D_sq)      # Cauchy kernel

# STFT (sliding window FFT for audio)
def stft(x, win_len=256, hop=64):
    window = np.hanning(win_len)
    frames = []
    for i in range(0, len(x)-win_len, hop):
        frames.append(np.fft.rfft(x[i:i+win_len] * window))
    return np.array(frames).T  # (freq, time)

mfcc.py

        
# Mel filterbank (perceptual frequency scale)
def hz_to_mel(hz): return 2595 * np.log10(1 + hz/700)
def mel_to_hz(mel): return 700 * (10**(mel/2595) - 1)

def mel_filterbank(n_filters=40, n_fft=512, fs=16000):
    mel_min = hz_to_mel(0)
    mel_max = hz_to_mel(fs/2)
    mel_pts = np.linspace(mel_min, mel_max, n_filters+2)
    hz_pts  = mel_to_hz(mel_pts)
    bins    = np.floor(hz_pts * n_fft / fs).astype(int)
    fbank   = np.zeros((n_filters, n_fft//2+1))
    for m in range(1, n_filters+1):
        fbank[m-1, bins[m-1]:bins[m]]   = np.linspace(0,1, bins[m]-bins[m-1])
        fbank[m-1, bins[m]:bins[m+1]] = np.linspace(1,0, bins[m+1]-bins[m])
    return fbank

# MFCC pipeline
# 1. Pre-emphasis: y[n] = x[n] - 0.97 x[n-1]
# 2. Frame → window (Hamming)
# 3. FFT → power spectrum
# 4. Mel filterbank energy
# 5. log → DCT → MFCCs
def mfcc(x, fs=16000, n_mfcc=13):
    spec = np.abs(stft(x))**2
    fbank = mel_filterbank()
    mel_e = fbank @ spec
    log_e = np.log(mel_e + 1e-9)
    dct_m = np.cos(np.pi*np.arange(n_mfcc)[:,None]*(np.arange(40)+0.5)/40)
    return dct_m @ log_e   # (n_mfcc, frames)

# Complete feature engineering pipeline
def preprocess(df_raw, fit=True, state=None):
    df = df_raw.copy()

    # 1. Drop high-null columns (>50% missing)
    null_frac = df.isnull().mean()
    df = df[null_frac[null_frac < 0.5].index]

    # 2. Impute: numeric → median, categorical → mode
    num_cols = df.select_dtypes('number').columns
    cat_cols = df.select_dtypes('object').columns
    if fit:
        state = {
            'num_fills': df[num_cols].median(),
            'cat_fills': df[cat_cols].mode().iloc[0]
        }
    df[num_cols] = df[num_cols].fillna(state['num_fills'])
    df[cat_cols] = df[cat_cols].fillna(state['cat_fills'])

    # 3. Encode categoricals
    df = pd.get_dummies(df, columns=list(cat_cols), drop_first=True)

    # 4. Scale numerics
    if fit:
        state['mu']  = df[num_cols].mean()
        state['std'] = df[num_cols].std().replace(0, 1)
    df[num_cols] = (df[num_cols] - state['mu']) / state['std']

    return df, state

Markov Chains & Stochastic Processes

  

    Markov property: P(Xₜ₊₁|X₀...Xₜ) = P(Xₜ₊₁|Xₜ)
    The future depends only on the present, not the past. Used in: MCMC sampling (Bayesian inference), language modelling (character-level), reinforcement learning (MDPs), HMMs (speech recognition), and diffusion models (noise schedule as Markov chain).

# MCMC: Metropolis-Hastings sampling
def metropolis_hastings(target_log_prob, proposal_std=0.5, n=10000):
    x = 0.0
    samples = []
    for _ in range(n):
        x_prop = x + rng.normal(0, proposal_std)
        log_alpha = target_log_prob(x_prop) - target_log_prob(x)
        if np.log(rng.uniform()) < log_alpha:
            x = x_prop
        samples.append(x)
    return np.array(samples)

# RBF (Squared Exponential) kernel
def rbf_kernel(X1, X2, length_scale=1.0, amplitude=1.0):
    # X1: (n,d), X2: (m,d) → (n,m)
    diff = X1[:, None] - X2[None]           # (n,m,d)
    r2   = np.sum(diff**2, axis=-1)          # (n,m)
    return amplitude**2 * np.exp(-r2/(2*length_scale**2))

# GP posterior (exact, noise σ²=noise_var)
def gp_posterior(Xtrain, ytrain, Xtest, kernel, noise_var=0.01):
    Kxx = kernel(Xtrain, Xtrain) + noise_var*np.eye(len(Xtrain))
    Kxs = kernel(Xtrain, Xtest)     # (n_train, n_test)
    Kss = kernel(Xtest, Xtest)
    L     = np.linalg.cholesky(Kxx)   # Cholesky decomp
    alpha = np.linalg.solve(L.T, np.linalg.solve(L, ytrain))
    mu    = Kxs.T @ alpha               # posterior mean
    v     = np.linalg.solve(L, Kxs)
    sigma2= np.diag(Kss - v.T @ v)    # posterior variance
    return mu, sigma2                   # N(mu, diag(sigma2))

# Marginal log-likelihood (for hyperparameter optimisation)
# log p(y|X) = -½ yᵀK⁻¹y - ½log|K| - n/2 log(2π)

Bias-Variance Tradeoff & Generalisation

  

    Bias-Variance Decomposition: E[(y-ŷ)²] = Bias² + Variance + Noise
    Bias = error from wrong assumptions (underfitting). Variance = sensitivity to training set (overfitting). Noise = irreducible error. Deep learning breaks the classical tradeoff via double descent — modern overparameterised models can have both low bias and low variance.
  


  

    

      
⚖️

# Empirical bias-variance estimation
def bias_variance(model_fn, X_train_sets, X_test, y_test):
    predictions = np.array([model_fn(Xtr).predict(X_test)
                               for Xtr in X_train_sets])
    # predictions: (n_datasets, n_test)
    mean_pred = predictions.mean(axis=0)  # E[f̂(x)]

    bias2    = np.mean((mean_pred - y_test)**2)
    variance = np.mean(predictions.var(axis=0))
    noise    = np.mean((y_test - y_test.mean())**2)

    print(f"Bias²={bias2:.4f}  Var={variance:.4f}  Noise={noise:.4f}")
    print(f"Total={bias2+variance+noise:.4f}")
    return bias2, variance, noise

# - L2 (ridge): shrinks weights → lower variance, higher bias
# - Dropout: reduces co-adaptation → lower variance
# - More data: reduces variance (∝ 1/n), bias unchanged
# - Ensemble: averages predictions → lower variance
# - Early stopping: implicit regularisation → reduces variance

# Double descent: overparameterised models can return to low error
# Classical: train error ↓ → test error ↓ then ↑

# Generalisation bound (VC theory)
# R(h) ≤ R̂(h) + sqrt(d/n · log(n/d) + log(1/δ)/n)
# d=VC dimension, n=samples, δ=confidence

def vc_bound(train_error, vc_dim, n_samples, delta=0.05):
    complexity = np.sqrt((vc_dim * np.log(2*n_samples/vc_dim)
                          + np.log(4/delta)) / n_samples)
    return train_error + complexity

# Rademacher complexity bound
# R(h) ≤ R̂(h) + 2Rn(H) + sqrt(log(2/δ)/2n)
def rademacher_bound(train_error, rad_complexity, n, delta=0.05):
    return train_error + 2*rad_complexity + np.sqrt(np.log(2/delta)/(2*n))

# In practice: cross-validation is more useful than bounds
def k_fold_cv(model, X, y, k=5):
    n = len(X)
    idx = np.random.permutation(n)
    errors = []
    for fold in range(k):
        val_idx = idx[fold*n//k:(fold+1)*n//k]
        tr_idx  = np.concatenate([idx[:fold*n//k], idx[(fold+1)*n//k:]])
        model.fit(X[tr_idx], y[tr_idx])
        errors.append(np.mean((model.predict(X[val_idx])-y[val_idx])**2))
    return np.mean(errors), np.std(errors)

Reinforcement Learning Math

  

    MDP: (S, A, P, R, γ) — the RL framework
    States S, Actions A, Transition probabilities P(s'|s,a), Reward R(s,a), discount γ∈[0,1). The Bellman equation defines optimal value functions. Q-learning learns action values from experience without knowing P — model-free RL.
  

  

    

      
🎮
Bellman Equations & Q-Learning

      

        
Q*(s,a) = R + γ·max_{a'} Q*(s',a')  [Bellman optimality]

# Q-Learning (off-policy, model-free)
# Q(s,a) ← Q(s,a) + α[r + γ max Q(s',a') - Q(s,a)]

class QLearning:
    def __init__(self, n_states, n_actions, alpha=0.1, gamma=0.99, eps=0.1):
        self.Q   = np.zeros((n_states, n_actions))
        self.alpha, self.gamma, self.eps = alpha, gamma, eps

    def act(self, s):
        if np.random.rand() < self.eps: return np.random.randint(self.Q.shape[1])
        return self.Q[s].argmax()        # greedy

    def update(self, s, a, r, s_next, done):
        target = r if done else r + self.gamma * self.Q[s_next].max()
        self.Q[s, a] += self.alpha * (target - self.Q[s, a])

# Policy Gradient (REINFORCE)
# ∇J(θ) = E[∇log π_θ(a|s) · G_t]  (G_t = return from t)
def reinforce_update(log_probs, rewards, gamma=0.99):
    G, returns = 0, []
    for r in reversed(rewards):
        G = r + gamma * G; returns.insert(0, G)
    returns = np.array(returns)
    returns = (returns - returns.mean()) / (returns.std() + 1e-9)
    loss = -np.sum(np.array(log_probs) * returns) # PG loss
    return loss

def value_iteration(P, R, gamma=0.99, tol=1e-6):
    """P[s,a,s'] = transition prob, R[s,a] = reward"""
    n_states, n_actions = R.shape
    V = np.zeros(n_states)
    for _ in range(1000):
        Q = R + gamma * np.einsum('san,n->sa', P, V)
        V_new = Q.max(axis=1)        # Bellman operator
        if np.linalg.norm(V_new - V) < tol: break
        V = V_new
    policy = Q.argmax(axis=1)        # greedy policy
    return V, policy

# TD(λ) — eligibility traces
# e(s) ← γλe(s) + ∇V(s)    (trace decay)
# θ ← θ + α·δ·e             (update all visited)
# δ = r + γV(s') - V(s)     (TD error)

# PPO clip objective (RLHF standard)
def ppo_loss(ratio, advantage, clip_eps=0.2):
    # ratio = π_new(a|s) / π_old(a|s)
    clip = np.clip(ratio, 1-clip_eps, 1+clip_eps)
    return -np.mean(np.minimum(ratio*advantage, clip*advantage))

def forward_backward(x):
    # Forward: record ops
    u  = x*x               # u = x²
    y  = np.sin(u)        # y = sin(x²)
    # Backward: chain rule
    dy_du = np.cos(u)     # ∂y/∂u
    du_dx = 2*x            # ∂u/∂x
    dy_dx = dy_du * du_dx  # chain rule
    return y, dy_dx

# Cosine similarity: cos(θ) = a·b / (‖a‖‖b‖)
def cosine_sim(a, b):
    return np.dot(a, b) / (np.linalg.norm(a) * np.linalg.norm(b))

# Batch cosine similarity matrix
def cosine_matrix(A, B):
    # A: (n, d), B: (m, d) → (n, m)
    A_n = A / np.linalg.norm(A, axis=1, keepdims=True)
    B_n = B / np.linalg.norm(B, axis=1, keepdims=True)
    return A_n @ B_n.T     # (n, m)

# Contrastive loss (SimCLR style)
def nt_xent(z1, z2, temperature=0.07):
    z  = np.concatenate([z1, z2], axis=0)      # (2n, d)
    S  = cosine_matrix(z, z) / temperature
    n  = len(z1)
    np.fill_diagonal(S, -np.inf)                 # mask self
    labels = np.concatenate([np.arange(n, 2*n),
                               np.arange(n)])
    logZ = logsumexp(S)                           # log partition
    return -np.mean(S[np.arange(2*n), labels]) + logZ

def all_metrics(y_true, y_pred, y_score=None):
    TP = np.sum((y_pred==1)&(y_true==1))
    TN = np.sum((y_pred==0)&(y_true==0))
    FP = np.sum((y_pred==1)&(y_true==0))
    FN = np.sum((y_pred==0)&(y_true==1))

    acc  = (TP+TN)/(TP+TN+FP+FN)
    prec = TP/(TP+FP+1e-9)
    rec  = TP/(TP+FN+1e-9)
    spec = TN/(TN+FP+1e-9)  # true negative rate
    f1   = 2*prec*rec/(prec+rec+1e-9)
    mcc  = (TP*TN-FP*FN)/(np.sqrt((TP+FP)*(TP+FN)*(TN+FP)*(TN+FN))+1e-9)

    # AUC via trapezoidal rule
    if y_score is not None:
        thresholds = np.linspace(0,1,101)
        tprs=[]; fprs=[]
        for t in thresholds:
            yp=(y_score>=t).astype(int)
            tprs.append(np.sum((yp==1)&(y_true==1))/(TP+FN+1e-9))
            fprs.append(np.sum((yp==1)&(y_true==0))/(TN+FP+1e-9))
        auc = -np.trapz(tprs, fprs)
    return dict(acc=acc,prec=prec,rec=rec,spec=spec,f1=f1,mcc=mcc)

def reg_metrics(y, yhat):
    r  = y - yhat
    mse   = np.mean(r**2)

Transformers
Transformer Architecture Deep Dive

  

    The Transformer block: one decoder layer of GPT / one encoder layer of BERT
    Pre-LN architecture (used by GPT-2+): LayerNorm is applied BEFORE each sub-layer, not after. This stabilises training of very deep models. The residual stream runs through the entire block, ensuring gradients flow cleanly.
  


  

    

      
🔧
Transformer Block (NumPy)

      

        
transformer.py

        
def transformer_block(x, Wq, Wk, Wv, Wo, W1, b1, W2, b2,
                           g1, b_1, g2, b_2, n_heads):
    # x: (T, d_model)
    # ── Sub-layer 1: Self-Attention ──
    x_ln1 = layer_norm(x, g1, b_1)        # pre-LN
    attn, _ = multi_head_attention(
        x_ln1, Wq, Wk, Wv, Wo, n_heads)
    x = x + attn                            # residual

    # ── Sub-layer 2: Feed-Forward ──
    x_ln2 = layer_norm(x, g2, b_2)        # pre-LN
    h  = np.maximum(0, x_ln2 @ W1 + b1)  # GELU in practice
    ff = h @ W2 + b2
    x = x + ff                              # residual
    return x

# Scaled dot-product attention (single head)
def attention(Q, K, V, mask=None):
    d_k = Q.shape[-1]
    S   = Q @ K.swapaxes(-2,-1) / np.sqrt(d_k)
    if mask is not None:
        S = np.where(mask, S, -1e9)
    A = np.exp(S - S.max(axis=-1, keepdims=True))
    A /= A.sum(axis=-1, keepdims=True)
    return A @ V, A

Bayesian
Bayesian Inference: MLE vs MAP vs Full Bayes

  

    Posterior = Likelihood × Prior (normalised)
    With few observations, the prior dominates (regularisation effect). As n→∞, the posterior concentrates around the MLE. MAP is the posterior mode; Full Bayes is the entire posterior distribution — giving calibrated uncertainty rather than a point estimate.
  


  

    

      
🎲
Beta-Binomial Conjugate Model

      

        
Prior: Beta(α,β)  ×  Likelihood: Bin(n,θ)  =  Posterior: Beta(α+k, β+n-k)

        
bayesian.py

        
# Conjugate model: Beta prior + Binomial likelihood
# Prior: p(θ) = Beta(α,β)
# Likelihood: p(k|θ) = C(n,k) θ^k (1-θ)^(n-k)
# Posterior: p(θ|k) = Beta(α+k, β+n-k)  ← analytic!

alpha, beta_p = 2, 2   # prior Beta(2,2)
n, k = 20, 14          # 20 trials, 14 heads

# MLE: maximises likelihood alone
theta_mle = k / n                           # 0.70

# MAP: mode of posterior
theta_map = (alpha+k-1) / (alpha+beta_p+n-2)  # 0.68

# Full Bayes: posterior mean (minimum MSE estimator)
post_a = alpha + k
post_b = beta_p + n - k
theta_bayes = post_a / (post_a + post_b)   # 0.667

# Posterior std — measures remaining uncertainty
post_std = np.sqrt(post_a*post_b / ((post_a+post_b)**2*(post_a+post_b+1)))

# 95% credible interval
from scipy.stats import beta as beta_dist
lo, hi = beta_dist.ppf([0.025, 0.975], post_a, post_b)

# RBF / Gaussian kernel — most popular
def rbf_kernel(X1, X2, gamma=1.0):
    # X1:(n,d), X2:(m,d) → (n,m)
    diff = X1[:,None] - X2[None]      # (n,m,d)
    return np.exp(-gamma * np.sum(diff**2, axis=-1))

# Polynomial kernel
def poly_kernel(X1, X2, degree=2, c=1):
    return (X1 @ X2.T + c) ** degree

# Matérn 5/2 (smooth, popular in GPs)
def matern52(X1, X2, l=1.0):
    r = np.sqrt(np.sum((X1[:,None]-X2[None])**2,axis=-1))
    sr5 = np.sqrt(5) * r / l
    return (1 + sr5 + sr5**2/3) * np.exp(-sr5)

# Random Fourier Features (approx RBF kernel)
# k(x,x') ≈ φ(x)·φ(x') via random projections
def rff_features(X, D=500, gamma=1.0):
    d = X.shape[1]
    W = np.random.randn(d, D) * np.sqrt(2*gamma)
    b = np.random.uniform(0, 2*np.pi, D)
    return np.sqrt(2/D) * np.cos(X @ W + b)

# DFT features for time-series (period detection)
def fourier_ts_features(x, k=10):
    X_f = np.fft.rfft(x)
    mag = np.abs(X_f[:k])   # amplitude
    phi = np.angle(X_f[:k]) # phase
    return np.concatenate([mag, phi])

Monte Carlo Methods & Numerical Integration

  

    Monte Carlo: approximate integrals by random sampling
    E[f(X)] ≈ (1/n)Σf(xᵢ) where xᵢ~p(x). Error decays as 1/√n regardless of dimension — the key advantage over deterministic grids in high dimensions. Used in MCMC, policy gradient, variational inference, and diffusion models.

n   = 100_000

# Importance sampling: reduces variance
# E_p[f] = E_q[f·p/q]  where q is easier to sample
def importance_sampling(f, log_p, log_q, samples):
    log_w = log_p(samples) - log_q(samples)
    w = np.exp(log_w - log_w.max())
    w /= w.sum()
    return np.sum(w * f(samples))

# Metropolis-Hastings MCMC
def mh_sample(log_target, x0, n=10000, step=0.5):
    x, samples = x0, []
    for _ in range(n):
        x_prop = x + rng.normal(0, step, x.shape)
        log_alpha = log_target(x_prop) - log_target(x)
        if np.log(rng.uniform()) < log_alpha: x = x_prop
        samples.append(x.copy())
    return np.array(samples)

① Gradient Clipping

  

    Gradient clipping prevents exploding gradients
    Two variants: value clipping (clip each element to [-c,c]) and norm clipping (scale the entire gradient vector so ‖g‖≤c). Norm clipping is preferred because it preserves gradient direction. Essential for RNNs and large Transformer models (GPT uses clip=1.0).

# Value clipping — clips each element
def clip_by_value(grads, c=1.0):
    return [np.clip(g, -c, c) for g in grads]

# Norm clipping — preserves direction (preferred)
def clip_by_norm(grads, max_norm=1.0):
    total_norm = np.sqrt(
        sum(np.sum(g**2) for g in grads))
    clip_coef = max_norm / (total_norm + 1e-6)
    if clip_coef < 1:
        grads = [g * clip_coef for g in grads]
    return grads, total_norm

# Adaptive clipping (monitor norm history)
class GradClipper:
    def __init__(self, percentile=95):
        self.norms = []
        self.percentile = percentile
    def clip(self, grads):
        total = np.sqrt(sum(np.sum(g**2) for g in grads))
        self.norms.append(total)
        threshold = np.percentile(self.norms, self.percentile)
        return clip_by_norm(grads, threshold)

# Transformer LR schedule (Vaswani 2017)
# lr = d^-0.5 · min(step^-0.5, step·warmup^-1.5)
def transformer_lr(step, d_model=512, warmup=4000):
    step = max(1, step)
    arg1 = step ** -0.5
    arg2 = step * warmup ** -1.5
    return d_model**-0.5 * min(arg1, arg2)

# Cosine warmup (modern LLMs)
def cosine_warmup_lr(step, T=10000, warmup=1000,
                      lr_max=3e-4, lr_min=3e-5):
    if step < warmup:
        return lr_max * step / warmup
    t = (step - warmup) / (T - warmup)
    return lr_min + 0.5*(lr_max-lr_min)*(
           1 + np.cos(np.pi * t))

# GPT-3 schedule: warmup 375M tokens,
# cosine decay to 10% of peak LR over 300B tokens
